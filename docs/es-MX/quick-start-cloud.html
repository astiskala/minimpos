Instalar la aplicación

  1. En el dispositivo, abra el enlace de descarga directa o escanee este código con su cámara:
  2. Abra APK en el dispositivo y permita la instalación desde su navegador o administrador de archivos cuando Android lo solicite.
  3. Abra Mini mPOS, seleccione Conéctate a Adyen y toque Continuar.

importante

Instale todas las actualizaciones desde la misma fuente de firma. Un terminal rechaza una actualización firmada con una clave diferente. Para crear y firmar el suyo propio, consulte la guía para contribuyentes.

Conectar un terminal en la nube

Asistente de configuración (recomendado)
Abra el asistente de configuración, elija el entorno TEST o LIVE del terminal, mantenga Automático, ingrese la clave API y escanee los códigos. Si se encuentra más de un terminal, elija el suyo.
manuales
  1. en Configuración › Terminal, establecer Los pagos van a a Un terminal a través de internet (nube). bajo Entorno, elija TEST o LIVE para que coincida con el terminal.
  2. bajo Adyen API, ingrese la clave API de Adyen y la cuenta comercial, más el prefijo de URL LIVE para LIVE. Toque Buscar configuración del terminal para probar el acceso al API y elegir el terminal. Ingrese los detalles que faltan manualmente.
  3. Consulta o introduce el ID de terminal (POIID) y toque Probar conexión.
