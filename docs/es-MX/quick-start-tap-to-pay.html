Instalar la aplicación

  1. En el dispositivo, abra el enlace de descarga directa o escanee este código con su cámara:
  2. Abra APK en el dispositivo y permita la instalación desde su navegador o administrador de archivos cuando Android lo solicite.
  3. Abra Mini mPOS, seleccione Conéctate a Adyen y toque Continuar.

importante

Instale todas las actualizaciones desde la misma fuente de firma. Un terminal rechaza una actualización firmada con una clave diferente. Para crear y firmar el suyo propio, consulte la guía para contribuyentes.

Configura Tap to Pay

  1. Desde Google Play, instalar Adyen Payments Test para TEST o Adyen Payments para LIVE. Ambos pueden permanecer instalados.
  2. En Mini mPOS, abra Configuración › Terminal y seleccione Tap to Pay en este teléfono. Elige TEST o LIVE bajo Entorno; Mini mPOS abre solo la aplicación de ese entorno.
Asistente de configuración (recomendado)
Abra el asistente de configuración, elija TEST o LIVE, ingrese la clave API correspondiente y escanee los códigos. Tras Verificar e importar, Mini mPOS encuentra la cuenta de comerciante y la clave compartida, crea la credencial de registro del teléfono y abre la aplicación Payments para registrarlo.
manuales
  1. en Configuración › Terminal › Adyen API, ingrese la clave API de Adyen y la cuenta comercial. Para pagos en vivo, ingrese también el prefijo en vivo URL. Toque Prueba API .
  2. bajo Tap to Pay, opcionalmente toque Elige tienda o ingrese una ID de tienda. No se necesita ninguna clave API separada.
  3. Toque Configura Tap to Pay y completar el registro en la aplicación Adyen Payments.
  4. En Mini mPOS, ingrese la clave compartida.
