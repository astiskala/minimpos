Instalar la aplicación

Descarga el APK firmado minimpos-<version>.apk de la versión más reciente.

  1. En el Área de Clientes, abra Devices › Terminal apps, cargue el APK y espere a que muestre Ready; vea la guía de carga de Adyen. Su usuario necesita el rol Merchant POS Terminal Management Admin.
  2. Seleccione la aplicación y luego Install. Elija la versión y Schedule now, seleccione su terminal y confirme Schedule installation. Vea la guía de programación de Adyen.
  3. Mantenga el terminal encendido y en línea. Instala la aplicación en su siguiente llamada de mantenimiento, de forma predeterminada en un plazo de tres horas. Para intentar obtenerla antes, abra Ajustes › Configuración en el terminal, ingrese el código y seleccione Actualizar.
  4. Abra Mini mPOS en el terminal, seleccione Escanear códigos de configuración y toque Continuar.

importante

Instale todas las actualizaciones desde la misma fuente de firma. Un terminal rechaza una actualización firmada con una clave diferente. Para crear y firmar el suyo propio, consulte la guía para contribuyentes.

Conectar un terminal Adyen

Asistente de configuración (recomendado)
Abra el asistente de configuración, elija el entorno TEST o LIVE del terminal, mantenga Automático, ingrese la clave API y escanee los códigos.
manuales
  1. en Configuración › Terminal › Adyen API, ingrese la clave API de Adyen y la cuenta comercial, más el prefijo de URL LIVE para LIVE. Toque Buscar configuración del terminal para probar el acceso a API y completar la clave compartida automáticamente.
  2. Verifique o ingrese la clave compartida y toque Probar conexión.
