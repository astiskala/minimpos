¿Dónde se ejecuta Mini mPOS y adónde van los pagos?
¿Qué entorno de Adyen?

TEST o LIVE se incluyen en cada código de configuración para su revisión. Para un terminal de red/nube o Tap to Pay, configura el entorno de la aplicación. Un terminal Adyen todavía utiliza su certificado de dispositivo para la conexión.

¿Cómo quieres configurar?

Sigue el Requisitos previos de Tap to Pay e instale la aplicación Adyen Payments primero. Mini mPOS utiliza su clave Adyen API para crear la credencial de registro del teléfono automáticamente. Ingrese la clave compartida aquí; Mini mPOS no lo busca. El registro es una acción explícita en el teléfono antes de que finalice la importación.

Clave API de Adyen

Crear una credencial en Developers › API credentials y generar su clave API. Esta clave maneja el proceso de pago y proporciona la credencial de registro independiente del teléfono. Cada configuración requiere las mismas funciones de credenciales principales; ver el requisitos de credenciales.

Tap to Pay

Mini mPOS crea automáticamente una credencial separada con Adyen Payments App role y una clave de cliente. Sin clave adicional para ingresar o transferir. Ver Solución de problemas de Tap to Pay y el Guía de la aplicación Adyen Payments.

Para configurar el teléfono para una tienda: su ID (no su referencia) de Devices › Stores.

Detalles del recibo (opcional)

Cuando está desactivado, no se importa ningún texto de recibo ni detalles comerciales de Adyen.

Detalles del recibo

Elija la importación de Adyen o la entrada manual para cada campo comercial.

Sólo el texto manual proporcionado cambia los valores guardados. Los campos en blanco mantienen el texto existente. El número de identificación fiscal, el título y el pie de página se ingresan manualmente, no se importan desde Adyen. Ver configuración del recibo .

  1. En Mini mPOS, abra Configuración › Terminal y toque Escanear códigos de configuración en Configuración rápida, o el ícono de escaneo QR en la parte superior derecha.

¿Problema de importación? · ¿Problema de conexión?

Es bueno saberlo

  • Las credenciales permanecen en su navegador. El asistente genera códigos localmente y no envía ni guarda las credenciales ingresadas. El sitio también carga servicios de seguridad y rendimiento de Cloudflare.
  • Las llaves están selladas. Las contraseñas y claves de los códigos se cifran con la transferencia. código, que se muestra solo aquí, por lo que una foto de los códigos por sí sola no los revela.
  • Mantenga el código de transferencia en privado. Cualquiera que tenga tanto los códigos como el código de transferencia puede Abre las llaves. Generar una nueva transferencia cuando sea necesario; cierre esta página cuando haya terminado.
  • ¿Necesita las instrucciones completas? Seguir Inicio rápido; para un problema de importación o conexión, consulte Solución de problemas.
