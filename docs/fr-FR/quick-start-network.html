Préparer le réseau

Demandez à l'administrateur réseau du site d'autoriser les éléments suivants :

Internet
HTTPS sortant sur TCP 443 depuis l'appareil et le terminal vers *.adyen.com et *.adyenpayments.com. Autorisez-les par nom de domaine, pas l'adresse IP, car les adresses IP d'Adyen changent.
Réseau local (pour les terminaux réseau)
La tablette ou le téléphone doit atteindre l'adresse IP du terminal sur TCP 8443. Connectez les deux au même réseau et assurez-vous que l'isolation du client Wi-Fi (commune sur les réseaux invités) ne les sépare pas.

Attribuez à chaque terminal réseau une adresse IP fixe avec une réservation DHCP dans votre routeur. Les données mobiles fonctionnent pour la tablette ou le téléphone dans les configurations cloud et Tap to Pay, mais pas avec un terminal réseau. Pour les exigences propres au terminal, voir le Guide de configuration du réseau Adyen.

Installez l'application

  1. Sur l’appareil, ouvrez le lien de téléchargement direct ou scannez ce code avec son appareil photo :
  2. Ouvrez l’APK sur l'appareil et autorisez l'installation à partir de votre navigateur ou de votre gestionnaire de fichiers lorsque Android vous le demande.
  3. Ouvrez Mini mPOS, sélectionnez Connectez-vous à Adyen et appuyez sur Continuer.

Important

Installez chaque mise à jour à partir de la même source de signature. Un terminal rejette une mise à jour signée avec une clé différente. Pour créer et signer le vôtre, consultez le guide du contributeur.

Associez un terminal sur votre réseau

Aide à la configuration (recommandé)
Ouvrez l’aide à la configuration, choisissez l’environnement TEST ou LIVE du terminal, gardez Automatique, saisissez la clé API et scannez les codes. Si plusieurs terminaux sont trouvés, choisissez le vôtre.
Manuel
  1. Dans Paramètres › Terminal, définir Les paiements vont à à Un terminal sur votre réseau. Sous Environnement, choisissez TEST ou LIVE pour correspondre au terminal.
  2. Sous Adyen API, saisissez la clé API Adyen et le compte marchand, ainsi que le préfixe d’URL LIVE pour LIVE. Appuyez sur Rechercher la configuration du terminal pour tester l'accès à l’API et choisir le terminal. Saisissez manuellement les détails manquants.
  3. Vérifiez ou saisissez l'adresse IP du terminal et ID du terminal (POIID). Les deux se trouvent sur l’écran d’informations sur l’appareil du terminal.
  4. Vérifiez ou saisissez la clé partagée et appuyez sur Tester la connexion.
