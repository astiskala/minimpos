Installez l'application

  1. Sur l’appareil, ouvrez le lien de téléchargement direct ou scannez ce code avec son appareil photo :
  2. Ouvrez l’APK sur l'appareil et autorisez l'installation à partir de votre navigateur ou de votre gestionnaire de fichiers lorsque Android vous le demande.
  3. Ouvrez Mini mPOS, sélectionnez Connectez-vous à Adyen et appuyez sur Continuer.

Important

Installez chaque mise à jour à partir de la même source de signature. Un terminal rejette une mise à jour signée avec une clé différente. Pour créer et signer le vôtre, consultez le guide du contributeur.

Configurer Tap to Pay

  1. Depuis Google Play, installez Adyen Payments Test pour TEST ou Adyen Payments pour LIVE. Les deux peuvent rester installés.
  2. Dans Mini mPOS, ouvrez Paramètres › Terminal et sélectionnez Tap to Pay sur ce téléphone. Choisissez TEST ou LIVE sous Environnement; Mini mPOS ouvre uniquement l'application de cet environnement.
Aide à la configuration (recommandé)
Ouvrez l’aide à la configuration, choisissez TEST ou LIVE, saisissez la clé API correspondante et scannez les codes. Après Vérifier et importer, Mini mPOS trouve le compte marchand et la clé partagée, crée les identifiants d’enregistrement du téléphone et ouvre l’application Payments pour l’enregistrer.
Manuel
  1. Dans Paramètres › Terminal › Adyen API, saisissez la clé API Adyen et le compte marchand. Pour les paiements LIVE, saisissez également le préfixe d’URL LIVE. Appuyez sur Test API.
  2. Sous Tap to Pay, appuyez éventuellement sur Choisir un magasin ou entrez un identifiant de magasin. Aucune clé API distincte n’est nécessaire.
  3. Appuyez sur Configurer Tap to Pay et complétez l'inscription dans l'application Adyen Payments.
  4. Dans Mini mPOS, saisissez la clé partagée.
