Installez l'application

Téléchargez l’APK signé minimpos-<version>.apk depuis la dernière version.

  1. Dans le Customer Area, ouvrez Devices › Terminal apps, téléchargez l’APK et attendez qu’il affiche Ready ; voir le guide de téléchargement Adyen. Votre utilisateur doit avoir le rôle Merchant POS Terminal Management Admin.
  2. Sélectionnez l’application, puis Install. Choisissez la version et Schedule now, sélectionnez votre terminal et confirmez Schedule installation. Voir le guide de planification Adyen.
  3. Laissez le terminal allumé et en ligne. Il installe l’application lors de son prochain appel de maintenance, par défaut sous trois heures. Pour essayer de l’obtenir plus tôt, ouvrez Réglages › Configuration sur le terminal, saisissez le code et sélectionnez Mettre à jour.
  4. Ouvrez Mini mPOS sur le terminal, sélectionnez Scanner les codes de configuration et appuyez sur Continuer.

Important

Installez chaque mise à jour à partir de la même source de signature. Un terminal rejette une mise à jour signée avec une clé différente. Pour créer et signer le vôtre, consultez le guide du contributeur.

Aide à la configuration (recommandé)
Ouvrez l’aide à la configuration, choisissez l’environnement TEST ou LIVE du terminal, gardez Automatique, saisissez la clé API et scannez les codes.
Manuel
  1. Dans Paramètres › Terminal › Adyen API, saisissez la clé API Adyen et le compte marchand, ainsi que le préfixe d’URL LIVE pour LIVE. Appuyez sur Rechercher la configuration du terminal pour tester l'accès à API et renseigner automatiquement la clé partagée.
  2. Vérifiez ou saisissez la clé partagée et appuyez sur Tester la connexion.
