Aide à la configuration

Configurer un appareil depuis votre ordinateur

Saisir de longues clés API sur un terminal est difficile. Renseignez les données ici, à côté de votre Customer Area, puis scannez les codes QR dans Mini mPOS.

Nouveau sur Mini mPOS ? Choisissez votre configuration et préparez vos identifiants avant de remplir ce formulaire.

Les liens Customer Area s'ouvrent dans un nouvel onglet afin que vous puissiez garder ce formulaire ouvert.

L'assistant de configuration a besoin de JavaScript. Activez-le pour cette page ou entrez le détails dans l'application comme guide de démarrage rapide décrit.

Où fonctionne Mini mPOS et où vont les paiements ?
Quel environnement Adyen ?

TEST ou LIVE est inclus dans chaque code de configuration pour examen. Pour un terminal réseau/cloud ou Tap to Pay, il définit l’environnement de l’application. Un terminal Adyen utilise toujours son certificat d'appareil pour la connexion.

Comment voulez-vous vous installer ?

Suivez le Prérequis Tap to Pay et installez d'abord l'application Adyen Payments. Mini mPOS utilise votre clé API Adyen pour créer automatiquement les informations d'identification du téléphone. Entrez la clé partagée ici ; Mini mPOS ne le recherche pas. L'enregistrement est une action explicite sur le téléphone avant la fin de l'importation.

Clé Adyen API

Créer un identifiant dans Developers › API credentials et générer sa clé API. Cette clé gère le paiement et fournit les informations d'identification d'enregistrement distinctes du téléphone. Chaque configuration nécessite les mêmes rôles d'identification principaux ; voir le exigences en matière de identifiants.

Compte marchand
Le terminal sur votre réseau

Les deux se trouvent sur l’écran d’informations sur l’appareil du terminal.

Le terminal dans le cloud

Recherchez-le sur l'écran Informations sur l'appareil du terminal ou dans Appareils > Terminaux dans le Customer Area.

Clé partagée

Dans le Customer Area : Devices › Device settings › Terminal API, sous Clé de cryptage (sélectionnez l’icône en forme de crayon pour la voir).

Préfixe d’URL LIVE

Dans Developers › API URLs.

Tap to Pay

Mini mPOS crée automatiquement un identifiant distinct avec le rôle Adyen Payments App role et une clé client. Aucune clé supplémentaire pour entrer ou transférer. Voir Dépannage Tap to Pay et le Guide de l'application Adyen Payments.

Pour paramétrer le téléphone pour un magasin : son identifiant (et non sa référence) de Devices › Stores.

Détails du reçu (facultatif)

Lorsqu'elle est désactivée, aucun texte de reçu ni aucun détail commercial Adyen n'est importé.

Détails du reçu

Choisissez l’import Adyen ou la saisie manuelle pour chaque champ métier.

Seul le texte manuel fourni modifie les valeurs enregistrées. Les champs vides conservent le texte existant. Le numéro d'identification fiscale, le titre et le pied de page sont saisis manuellement et ne sont pas importés depuis Adyen. Voir configuration du reçu.

Reçus par courrier électronique (facultatif)

Vérifier configuration de la messagerie et exigences du fournisseur d'abord ; l'assistant ne peut pas tester le serveur.

Serveur SMTP

Seuls les champs fournis changent. Les champs facultatifs vides conservent les valeurs enregistrées ; effacez-les dans Paramètres › Reçus par e-mail si nécessaire. Le mot de passe est scellé avec les autres secrets.

Scannez ces codes avec l'appareil

Code de transfert

  1. Dans Mini mPOS, ouvrez Paramètres › Terminal et appuyez sur Scanner les codes de configuration sous Configuration rapide ou sur l'icône de numérisation QR en haut à droite.
  2. Pointez sa caméra vers les codes. A plusieurs, ils changent tout seuls.
  3. Passez en revue la destination et l’environnement. Entrez le requis Code de transfert et appuyez sur Vérifier et importer.

Si vous avez inclus les paramètres SMTP, vérifiez Paramètres › Reçus par e-mail et envoyez un e-mail de test.

Bon à savoir

  • Rien ne quitte cette page. Les codes sont créés dans votre navigateur ; la page n'envoie rien n'importe où et ne stocke rien. Fermez-le lorsque vous avez terminé.
  • Les clés sont scellées. Les mots de passe et les clés des codes sont cryptés lors du transfert code, qui est affiché uniquement ici, donc une photo des codes à elle seule ne les révèle pas.
  • Gardez le code de transfert privé. Toute personne possédant à la fois les codes et le code de transfert peut ouvrez les clés. Générez un nouveau transfert en cas de besoin ; fermez cette page lorsque vous avez terminé.
  • Besoin des instructions complètes ? Suivre Démarrage rapide; pour un problème d'importation ou de connexion, voir Dépannage.
