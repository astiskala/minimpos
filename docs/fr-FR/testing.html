Validez votre configuration TEST

  1. Dans Paramètres › Terminal, vérifiez que l'environnement est TEST. Terminez par Tester la connexion pour vérifier l’accès à l’API et les vérifications de connexion prises en charge.
    • Terminal physique : exécuter Tester la connexion et vérifiez que ça passe.
    • Tap to Pay : confirmez que le téléphone est enregistré dans Adyen Payments Test. Le contrôle de connexion valide uniquement le paramétrage : il n'y a pas de diagnostic du terminal. Utilisez le paiement test ci-dessous pour vérifier le comportement de paiement.
  2. Dans Paramètres › Paiements, vérifiez la devise. Dans Paramètres › Taxe, vérifiez les tarifs et si les prix incluent les taxes.
  3. Sur Accueil, appuyez sur Nouvelle vente, ajoutez un Article personnalisé et appuyez sur Débiter. Nommez l’article personnalisé « Vente de test » et saisissez le montant du scénario de votre carte.
  4. Appuyez sur Payer et suivez le Guide de test Adyen POS pour un paiement réussi.
  5. Vérifiez que le résultat est approuvé et que le reçu contient le montant, la devise et la taxe corrects. Ouvrir la vente dans Historique. Faites correspondre son Référence PSP au paiement dans le TEST Customer Area.
  6. Rembourser le paiement et vérifiez le résultat final du remboursement dans le TEST Customer Area. Remboursement demandé n’est pas une confirmation définitive.
  7. Répétez la vente avec un scénario de refus de paiement du Guide de test Adyen POS. Vérifiez que Mini mPOS affiche un refus et non une approbation ; voir paiements refusés.

Avertissement

Si le résultat est inconnu, ne payez plus. Suivez le étapes de récupération d'abord.

Préparer l’activité pour LIVE

  • Vérifiez la devise et les taxes avant de fixer les prix.
  • Vérifiez les coordonnées de l’entreprise et chaque mode de remise des reçus utilisé.
  • Configurez les PIN du personnel et les actions nécessitant l’approbation d’un responsable.
  • Activez et testez uniquement les fonctions de paiement facultatives nécessaires.

Allez en direct

Avertissement

Le basculement entre TEST, LIVE et le simulateur supprime tout l'historique des paiements sur l'appareil, y compris les données de récupération des paiements inachevés. Résolvez chaque paiement sous A besoin d’attention d'abord.

  1. Basculez vers le terminal LIVE ou l’application Adyen Payments LIVE, avec les informations d'identification LIVE. Pour un terminal réseau/cloud ou Tap to Pay, choisissez LIVE sous Environnement. Entrez le Préfixe d’URL LIVE; voir le Guide des points de terminaison en direct Adyen. Tap to Pay doit être à nouveau enregistré dans l'environnement sélectionné.
  2. Dans Paramètres › Terminal, vérifiez que l'environnement est LIVE. Terminez par Tester la connexion pour vérifier l’accès à l’API et les vérifications de connexion prises en charge.
    • Terminal physique : exécuter Tester la connexion et vérifiez que ça passe.
    • Tap to Pay : confirmez que le téléphone est enregistré dans le LIVE Adyen Payments application. Le contrôle de connexion valide uniquement le paramétrage : il n'y a pas de diagnostic du terminal.

Pour les contrôles quotidiens et le rapprochement, voir Clôturer la journée.

Vérifier le premier paiement LIVE

Suivez les instructions de test LIVE d’Adyen avec votre destination et votre mode de remise des reçus. Vérifiez le montant, la devise, le reçu et le paiement dans le Customer Area LIVE. Le test de connexion ne suffit pas à valider les paiements.
