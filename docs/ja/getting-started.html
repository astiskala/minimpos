アカウントなしで、まず試す

最新リリースから minimpos-<version>.apk をダウンロードし、Android 9 以降のスマートフォンやエミュレーターで開きます。Android の案内に従い、ブラウザーやファイルマネージャーからのインストールを許可してください。

Adyen 端末以外では、初期状態でシミュレーターを使い、カードに請求しません。設定 › シミュレーターで承認、拒否、使用中、タイムアウトの結果、待ち時間、プリンターの有無を選べます。領収書は画面に表示され、予約金、チップ、キャプチャも試せます。支払いリンクはシミュレーションできません。

ソースからビルドする場合は、貢献者向けガイドを参照してください。

構成を選ぶ

デバイスが Mini mPOS を動かし、端末がカードを読み取ります。同じ機器でも構いません。

Adyen 端末で動かす
1 台で会計を完結できます。Android 9 以降の Adyen Android 端末（S1F2、S1F4Pro、S1E4Pro、S1E2L、AMS1、S1U2、SFO1 など）が必要です。
タブレットやスマートフォンとネットワーク上の端末
カウンターのタブレットにおすすめです。Android 9 以降のデバイスと端末を同じネットワークに接続します。その端末への Mini mPOS のインストールは不要です。
タブレットやスマートフォンとクラウドの端末
別々のネットワークで使う構成です。Adyen Cloud device API を通して端末に決済を送ります。
スマートフォンの Tap to Pay
別の端末は不要です。Google 認定の NFC 対応 Android 12 以降のスマートフォン、Adyen Payments アプリ、Adyen サポートによる有効化が必要です。Adyen の要件と対応国・決済方法を確認してください。

印刷にはプリンター搭載端末、バーコード・領収書・設定コードの読み取りにはカメラが必要です。Tap to Pay にはプリンターがないため、領収書をメール送信または共有してください。

Mini mPOS は独立したプロジェクトで、Adyen による製品、推奨、サポートではありません。本番決済には必要なサービスが有効な Adyen アカウント、Customer Area へのアクセス、Checkout API の認証情報が必要です。アカウントやプラットフォームの手順はリンク先の Adyen 文書に従ってください。

アプリをインストールする

すべての構成で、最新リリースの署名済み APK を使います。

  • Adyen 端末：Adyen のアプリ配布ガイドに従い、Customer Area でアップロード・配布します。ユーザーにはアプリのアップロード・配布権限が必要です。
  • タブレットやスマートフォン：デバイスで APK を開き、インストールを許可します。Adyen 経由の配布は不要です。

更新時も同じ署名元を使ってください。端末が受け付ける後続バージョンは、同じキーで署名したものだけです。自分でビルドして署名する場合は、貢献者向けガイドを参照してください。

Adyen に接続する

該当する構成の手順だけを進めます。タブレットやスマートフォンでは、まず設定 › 端末 › 決済先を選びます。アプリの番号付き手順に必要事項が表示され、ホームには不足項目が表示されます。

認証情報を用意する

通常の販売を含め、すべての実決済構成で Checkout API が必要です。Developers › API credentials で Checkout webservice role の認証情報を作成し、APIキーを生成します。Adyen の認証情報ガイドを参照してください。クラウドでは、同じ認証情報に Cloud Device API ロールも必要です。

この端末、ネットワーク上の端末、Tap to Pay では共有キーも用意します。Devices › Device settings › Integrations › Terminal API › Encryption key から識別子、パスフレーズ、バージョンを取得します。Adyen のローカル統合ガイドを参照してください。クラウドではこのキーは使いません。

パソコンからキーを入力する

信頼できるパソコンでセットアップヘルパーを開き、構成を選んで入力し、QRコードを作成をクリックします。アプリの設定 › データ › 別のデバイスから設定で全コードを読み取り、表示された転送コードを入力してインポートします。その後、下の手順で接続を完了し、テストします。設定 › 端末に直接入力しても構いません。

Adyen 端末で動かす

先にアプリをインストールし、認証情報を用意してください。

  1. 設定 › 端末に共有キーを入力し、保存してテストをタップします。アドレス、端末 ID（POIID）、TEST／LIVE 環境は自動検出されます。
  2. Checkout API の手順にマーチャントアカウントと APIキーを入力し、APIキーを保存してテストをタップします。

ネットワーク上の端末を使う

先にアプリをインストールし、認証情報を用意してください。

  1. ネットワーク上の端末を選び、端末の Device info 画面にある IP アドレスと POIID を入力します。
  2. 共有キーを入力し、接続をテストします。
  3. Checkout API の手順にマーチャントアカウントと APIキーを入力し、APIキーを保存してテストをタップします。

インターネット経由で端末を使う

先にアプリをインストールし、認証情報を用意してください。

  1. クラウドの決済先を選び、Adyenアカウントにマーチャントアカウントと必要な両ロールを持つ APIキーを入力します。
  2. 接続中の端末を検索から端末を選ぶか、POIID を入力します。接続をテストで端末と Checkout API を確認します。

キーから環境とデータセンターを自動検出します。クラウド決済はローカル決済より端末の応答を長く待つ場合があります。

Tap to Pay を使う

先にアプリをインストールし、認証情報を用意してください。

  1. Adyen サポートに Tap to Pay on Android と Adyen Payments app role の有効化を依頼します。TEST では Adyen Payments Test、LIVE では Adyen Payments をインストールし、両方は入れないでください。アプリに Google Play へのリンクがあります。
  2. このスマートフォンでTap to Payを選び、スマートフォンを登録するマーチャントアカウントの Checkout API を接続します。
  3. Tap to Pay に別のPaymentsアプリのAPIキー（Adyen Payments app role のみ）と、任意の店舗 ID を入力します。Tap to Payを設定から Payments アプリで登録を完了します。
  4. Payments アプリへの決済を暗号化する共有キーを入力します。Adyen のPayments アプリガイドに従ってください。

決済時は Payments アプリが開き、Mini mPOS に戻ります。インストールしたアプリが TEST／LIVE を決めます。後で登録を解除するにはこのスマートフォンを削除を使います。

APIキーはこのデバイスに暗号化して保存します。Adyen はサーバーでの保管を推奨していますが、Mini mPOS にはサーバーがありません。必要最小限の権限を持つ、このデバイスや端末群専用の認証情報を使い、管理者PINを設定してください。漏えいや紛失時は認証情報を無効にします。セキュリティポリシーも確認してください。

最初の TEST 決済を行う

  1. 設定 › アプリ情報で、検出された環境が TEST であることを確認します。
  2. 設定 › 決済で Adyen アカウントが受け付ける通貨を、設定 › 税で税率と税込・税抜設定を確認します。
  3. 新規販売から任意の金額を入力して会計に進み、決済ボタンをタップして Adyen のテストカードを使います。
  4. 結果、領収書、取引履歴を確認し、返金も試します。結果が不明な場合は、別の決済を試す前に復旧手順に従ってください。

本番決済の前に

  • 予約金、チップ、支払いリンクなど、使うすべてのフローをテストしてください。シミュレーターは Adyen でのテストの代わりにはなりません。
  • プリンターがあれば実際のテスト領収書を印刷し、メール送信を使う場合はテストメールも送ります。
  • 管理者PINと、必要ならマネージャーPINを設定します。店舗設定を確認してください。
  • LIVE デバイスにインストールし、LIVE 認証情報を使います。Checkout には Developers › API URLs の live URL prefix が必要です。Adyen のLIVE エンドポイントを参照してください。アプリでは LIVE 検出後に入力欄が表示されます。
  • 接続と API をテストし、設定 › アプリ情報で LIVE を確認します。ヘルパーの TEST／LIVE 選択は欄と Customer Area リンクを切り替えるだけで、アプリの検出環境は変更できません。

困った場合はトラブルシューティングへ。
