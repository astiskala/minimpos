アプリをインストールする

  1. デバイスで直接ダウンロードリンクを開くか、カメラでこのコードを読み取ります。
  2. デバイスで APK を開き、Android の案内に従ってブラウザーやファイルマネージャーからのインストールを許可します。
  3. Mini mPOS を開き、Adyen に接続を選んで続けるをタップします。

重要

更新は毎回同じ署名元からインストールしてください。端末は別のキーで署名した更新を拒否します。自分でビルドして署名する場合は 貢献者向けガイド を参照してください。

クラウドの端末を接続する

セットアップヘルパー（推奨）
セットアップヘルパーを開き、端末の TEST または LIVE 環境を選んで自動のまま APIキーを入力し、コードを読み取ります。複数の端末が見つかった場合は、使う端末を選びます。
手動
  1. 設定 › 端末で決済先をインターネット経由の端末（クラウド）にします。環境 で端末に合う TEST または LIVE を選びます。
  2. Adyen APIで Adyen APIキーとマーチャントアカウントを入力し、LIVE では LIVE URLプレフィックスも入力します。 端末の設定を検索をタップすると、APIアクセスをテストして端末を選べます。不足する情報を手動で入力してください。
  3. 端末ID（POIID）を確認または入力し、接続をテストをタップします。
