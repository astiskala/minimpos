アプリをインストールする

最新リリースから署名済みの minimpos-<version>.apk をダウンロードします。

  1. Customer Area で Devices › Terminal apps を開き、APK をアップロードして Ready と表示されるまで待ちます。Adyen のアップロードガイドを参照してください。ユーザーには Merchant POS Terminal Management Admin ロールが必要です。
  2. アプリを選択して Install を選びます。バージョンと Schedule now を選び、端末を選択して Schedule installation で確定します。Adyen のスケジュールガイドを参照してください。
  3. 端末の電源を入れ、オンラインのままにします。次回のメンテナンスコール(既定では 3 時間以内)にアプリがインストールされます。早く取得するには、端末で Settings › Configuration を開き、パスコードを入力して Update を選択してみてください。
  4. 端末で Mini mPOS を開き、設定コードを読み取るを選んで続ける をタップします。

重要

更新は毎回同じ署名元からインストールしてください。端末は別のキーで署名した更新を拒否します。自分でビルドして署名する場合は 貢献者向けガイド を参照してください。

Adyen 端末を接続する

セットアップヘルパー（推奨）
セットアップヘルパーを開き、端末の TEST または LIVE 環境を選んで自動のまま APIキーを入力し、コードを読み取ります。
手動
  1. 設定 › 端末 › Adyen APIで Adyen APIキーとマーチャントアカウントを入力し、LIVE では LIVE URLプレフィックスも入力します。 端末の設定を検索をタップすると、APIアクセスをテストして共有キーを自動で補完します。
  2. 共有キーを確認または入力し、接続をテストをタップします。
