利用環境を選ぶ

設置日より前に確認してください。デバイスが Mini mPOS を動かし、端末がカードを読み取ります。同じ機器でも構いません。

Adyen 端末で動かす
1 台で会計を完結できます。Android 9 以降の Adyen Android 決済端末が必要です。現在のモデルは Adyen Android 端末ガイド で確認してください。
スマートフォンの Tap to Pay
別の端末は不要です。近距離無線通信（NFC）に対応したスマートフォンと、Adyen サポートが有効化した Adyen Payments アプリを使います。 Adyen のスマートフォン要件と Adyen の対応国・決済方法を確認してください。

別の決済端末を使う

タブレットやスマートフォンとネットワーク上の端末
カウンターにおすすめです。Android 9 以降のタブレットやスマートフォンを Adyen 端末と同じローカルネットワークに接続します。その端末への Mini mPOS のインストールは不要です。
タブレットやスマートフォンとクラウドの端末
デバイスと端末が別々のネットワークにある場合の構成です。どちらもインターネット接続が必要で、決済は Adyen を経由して端末に届きます。

構成 接続 領収書 機能の制限
Adyen 端末で動かす インターネットと端末内のローカル接続 内蔵プリンター、メール ローカルのオフライン処理を設定可能。別のお客様向け画面はありません。
タブレットやスマートフォンとネットワーク上の端末 同じネットワークの TCP 8443 とインターネット 端末のプリンター、メール、共有 別のお客様向け画面に対応。ローカルのオフライン処理を設定可能。
タブレットやスマートフォンとクラウドの端末 両方のデバイスでインターネット 端末のプリンター、メール、共有 別のお客様向け画面に対応。クラウド経由のオフライン処理はできません。
スマートフォンの Tap to Pay インターネットと対応する NFC スマートフォン メール、共有。プリンターなし 端末でのチップ、お客様向け画面、MOTO/MKE、オフライン処理、端末精算には非対応。

端末の機能は、機種、決済方法、Adyen の設定によって異なります。必要な操作を実機でテストしてください。 Adyen機能を確認.

  • 印刷にはプリンター内蔵の端末が必要です。プリンターがない場合は、領収書をメール送信または共有できます。
  • バーコード、返金用 QR コード、設定コードの読み取りにはカメラが必要です。

Adyen の認証情報を用意する

実際の決済には Checkout API へのアクセスが必要です。送信先の加盟店アカウントにアクセスできる会社アカウントの API 認証情報を使ってください。

認証情報を作成・編集するには、Customer Area のユーザーに Manage API credentials または Merchant admin が必要です。これらはユーザー権限であり、APIキーのロールではありません。

Adyen の支払い方法設定ガイドに従って、受け付ける POS 決済方法を有効にしてください。Mini mPOS は端末に設定された決済方法を使います。

  1. Customer Area の Developers › API credentials で Mini mPOS 用の認証情報を作成し、APIキーを生成します。 Adyen の API 認証情報ガイドを参照してください。
  2. LIVE では Developers › API URLs の LIVE URLプレフィックスを控えます。
  3. すべての構成で、メインの API 認証情報に上記のロールが必要です。Tap to Pay では、Mini mPOS が Adyen Payments App role とクライアントキーを持つ加盟店単位の別の認証情報を自動作成します。Adyen サポートに Tap to Pay の有効化と会社の認証情報からのロール割り当てを依頼してください。
API 認証情報に必要なロール

どの利用環境でも、主 API 認証情報に必要なロールは同じです。

デフォルトで有効

  • Merchant PAL webservice role
  • Checkout webservice role
  • Management API - API credentials read and write
  • Management API - Payment methods read
  • Management API - Stores read
  • Management API - Accounts read
  • Merchant Recurring role

追加するロール

  • Management API - Terminal actions read
  • Management API - Terminal settings read and write
  • Management API - Terminal settings Advanced read and write
  • Cloud Device API role
  • API tokenise payment details

Adyen: API roles

ロールが不足している場合は、Mini mPOS が最初にキーを確認するときに、会社の ws 認証情報がそのロールを持っていれば追加を提案します。

デバイスを手動で設定する場合：
  • マーチャントアカウントを控えます。
  • Adyen 端末、ネットワーク上の端末、Tap to Pay では、Devices › Device settings › Integrations › Terminal API › Encryption key で共有キー（識別子、パスフレーズ、バージョン）を確認します。クラウドの端末では使いません。

共有キーはローカルの決済端末や Payments アプリとの通信を暗号化します。クラウド端末では使いません。

重要

Mini mPOS にはサーバーがないため、APIキーはデバイスに暗号化して保存します。ご自身の構成に必要な API ロールだけを持つ Mini mPOS 専用の認証情報を作成してください。管理者PINを設定してください。デバイスを紛失したら認証情報を無効にします。 セキュリティポリシーも確認してください。

不足している暗号化キーを作成する

物理端末に暗号化キーがまだない場合、認証情報とアカウントの確認後に暗号化キーを作成が表示されます。

  1. 表示された端末IDと環境を確認してから確定します。作成中は、他の場所でこの端末の設定を変更しないでください。
  2. 接続がまだ確認されていない場合は、端末の設定を更新します。キー設定の復旧を参照してください。
  3. 作成が中断した場合はキー設定を再開をタップします。QR 設定では、同じコードとその転送コードをもう一度読み取ります。
