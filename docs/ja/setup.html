セットアップヘルパー

パソコンからデバイスを設定

長い APIキーを端末のキーパッドで入力するのは大変です。Customer Area を見ながらここに入力し、QR コードで Mini mPOS に読み取らせましょう。

セットアップヘルパーには JavaScript が必要です。このページで有効にするか、はじめにガイドのとおりアプリで入力してください。

1. Mini mPOS をどこで動かし、決済をどこに送りますか？
2. どの Adyen 環境ですか？

環境はアプリが接続時に自動で判別します。この選択は、下のリンクで開く Customer Area と、LIVE URLプレフィックスの入力欄にだけ影響します。

ネットワーク上の端末

どちらも端末の Device info 画面に表示されます。

クラウドの端末

空欄にすると、アプリで接続中の端末から選べます。

共有キー

Customer Area の Devices › Device settings › Terminal API の Encryption key にあります（鉛筆アイコンで表示）。

Checkout API

Developers › API credentials で Checkout webservice role を持つ Cloud Device API role と Checkout webservice role を持つ API 認証情報を作成し、APIキーを生成してください。

LIVE URLプレフィックス

Developers › API URLs にあります。

Tap to Pay

Adyen Payments app role のみを持つ API 認証情報です。このロールは Adyen サポートが有効にします。Adyen の Payments アプリガイドを参照してください。

スマートフォンを 1 店舗用に設定する場合：Devices › Stores にあるその店舗の ID（reference ではありません）。

デバイスでこのコードを読み取る

  1. デバイスの Mini mPOS で設定 › データ › 別のデバイスから設定を開きます。
  2. カメラで下のコードを読み取ります。複数ある場合は自動で切り替わります。
  3. 転送コードを入力し、インポートをタップします。デバイスでは、ここで入力した項目だけが変わります。
  4. 設定 › 端末で接続を確認します。Tap to Pay の場合は、そこでTap to Payを設定をタップします。

転送コード

知っておきたいこと

  • 入力内容はこのページの外に出ません。コードはブラウザー内で作成され、このページは何も送信・保存しません。終わったらページを閉じてください。
  • キーは暗号化されます。コード内のパスワードとキーは、ここにだけ表示される転送コードで暗号化されるため、コードの写真だけでは読み取れません。
  • 転送コードは秘密にしてください。QR コードと転送コードの両方があればキーを復号できます。必要に応じて新しい転送を作り、終わったら閉じてください。
  • 接続だけを設定します。商品、領収書やほかの店舗設定はコピーしません。それらはアプリの別のデバイスに共有を使います。
  • 全体の手順は？はじめにを参照し、取り込みや接続の問題はトラブルシューティングで確認してください。
