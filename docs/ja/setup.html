セットアップヘルパー

パソコンからデバイスを設定

長い APIキーを端末のキーパッドで入力するのは大変です。Customer Area を見ながらここに入力し、QR コードで Mini mPOS に読み取らせましょう。

初めて使う場合は、入力前に構成を選び、認証情報を用意してください。

Customer Area のリンクは新しいタブで開くので、このフォームを開いたままにできます。

セットアップヘルパーには JavaScript が必要です。このページで有効にするか、クイックスタートガイドのとおりアプリで入力してください。

Mini mPOS をどこで動かし、決済をどこに送りますか？
どの Adyen 環境ですか？

ネットワークやクラウドの端末では、この選択をアプリの環境としてインポートします。Adyen端末やTap to Payでは、デバイスまたはインストールしたPaymentsアプリが環境を決めます。

どの方法で設定しますか？

先にTap to Payの準備手順に従い、Paymentsアプリをインストールしてください。登録用のマーチャントアカウントと別のPaymentsアプリのAPIキーを入力します。共有キーはここで入力してください。Mini mPOSは共有キーを取得しません。インポート完了前にスマートフォンで明示的な登録操作が必要です。登録トークンをコピーする必要はありません。

Adyen APIキー

Developers › API credentialsで認証情報を作成し、APIキーを生成してください。クラウド決済にはCloud Device API roleを追加します。このキーはCheckout操作用で、Paymentsアプリの登録用ではありません。このメインの認証情報には特定のロールが必要です。認証情報の要件を参照してください。

マーチャントアカウント
ネットワーク上の端末

どちらも端末の Device info 画面に表示されます。

クラウドの端末

端末のDevice info画面またはCustomer AreaのDevices › Terminalsで確認できます。

共有キー

Customer Area の Devices › Device settings › Terminal API の Encryption key にあります（鉛筆アイコンで表示）。

LIVE URLプレフィックス

Developers › API URLs にあります。

Tap to Pay

スマートフォン登録用の別のAPI認証情報で、Adyen Payments app roleのみを持ちます。Adyen Paymentsアプリガイドを参照してください。

スマートフォンを 1 店舗用に設定する場合：Devices › Stores にあるその店舗の ID（reference ではありません）。

領収書の情報（任意）

オフの場合、領収書の文面や Adyen の事業者情報はインポートしません。

領収書の情報

各事業者情報は Adyen からの取得または手入力を選べます。

入力した手動の文面だけが保存済みの値を変更します。空欄は既存の文面を残します。税務番号、タイトル、フッターは手入力で、Adyen から取得しません。領収書の設定を参照してください。

領収書メール（任意）

先にメール設定とプロバイダーの要件を確認してください。ヘルパーからサーバーはテストできません。

SMTPサーバー

入力した欄だけが変わります。空の任意欄は保存済みの値を残します。削除が必要なら設定 › メールで行ってください。パスワードはほかの秘密情報とともに暗号化します。

デバイスでこのコードを読み取る

転送コード

  1. Mini mPOS の設定 › 端末を開き、かんたんセットアップの設定コードを読み取るか右上のQRスキャンアイコンをタップします。決済先や環境を先に選ぶ必要はありません。
  2. カメラでコードを読み取ります。複数ある場合は自動で切り替わります。
  3. 決済先と環境、特にLIVEを確認し、必須の転送コードを入力して確認してインポートをタップします。
  4. 確認済みインポート手順に従います。

SMTP設定を含めた場合は設定 › メールを確認し、テストメールを送ります。

取り込み後は最初の TEST 決済を行ってください。

取り込みの問題 · 接続の問題

知っておきたいこと

  • 入力内容はこのページの外に出ません。コードはブラウザー内で作成され、このページは何も送信・保存しません。終わったらページを閉じてください。
  • キーは暗号化されます。コード内のパスワードとキーは、ここにだけ表示される転送コードで暗号化されるため、コードの写真だけでは読み取れません。
  • 転送コードは秘密にしてください。QR コードと転送コードの両方があればキーを復号できます。必要に応じて新しい転送を作り、終わったら閉じてください。
  • 全体の手順は？クイックスタートを参照し、取り込みや接続の問題はトラブルシューティングで確認してください。
