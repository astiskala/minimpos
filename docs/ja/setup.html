セットアップヘルパー

パソコンからデバイスを設定

長い APIキーを端末のキーパッドで入力するのは大変です。Customer Area を見ながらここに入力し、QR コードで Mini mPOS に読み取らせましょう。

初めて使う場合は、入力前に構成を選び、認証情報を用意してください。

Customer Area のリンクは新しいタブで開くので、このフォームを開いたままにできます。

セットアップヘルパーには JavaScript が必要です。このページで有効にするか、はじめにガイドのとおりアプリで入力してください。

1. Mini mPOS をどこで動かし、決済をどこに送りますか？
2. どの Adyen 環境ですか？

ネットワークやクラウドの端末では、この選択をアプリの環境としてインポートします。Adyen端末やTap to Payでは、デバイスまたはインストールしたPaymentsアプリが環境を決めます。同じ環境の認証情報を使ってください。この選択でCustomer AreaのリンクとLIVE URLプレフィックス欄も切り替わります。

3. どの方法で設定しますか？

LIVEではどちらもLIVE URLプレフィックスが必要です。自動取得ができない場合や情報が不足する場合は、デバイスで補うか、ここで手動を選んでください。

先にTap to Payの準備手順に従い、Paymentsアプリをインストールしてください。登録用のマーチャントアカウントと別のPaymentsアプリのAPIキーを入力します。共有キーはここで入力するか、後でスマートフォンで入力してください。Mini mPOSは共有キーを取得しません。登録トークンをコピーする必要はありません。

Adyen APIキー

Developers › API credentialsで認証情報を作成し、APIキーを生成してください。クラウド決済にはCloud Device API roleを追加します。このキーはCheckout操作用で、Paymentsアプリの登録用ではありません。自動設定には設定ガイドの取得用ロールが必要です。このヘルパーはオフラインです。情報取得はインポート後にデバイスで行います。

Adyenアカウント
ネットワーク上の端末

どちらも端末の Device info 画面に表示されます。

クラウドの端末

端末のDevice info画面またはCustomer AreaのDevices › Terminalsで確認できます。

共有キー

Customer Area の Devices › Device settings › Terminal API の Encryption key にあります（鉛筆アイコンで表示）。

LIVE URLプレフィックス

Developers › API URLs にあります。

Tap to Pay

スマートフォン登録用の別のAPI認証情報で、Adyen Payments app roleのみを持ちます。AdyenのPaymentsアプリガイドを参照してください。

スマートフォンを 1 店舗用に設定する場合：Devices › Stores にあるその店舗の ID（reference ではありません）。

領収書メール（任意）

どちらの設定モードでも使えます。先にメール設定とプロバイダーの要件を確認してください。ヘルパーからサーバーはテストできません。

SMTPサーバー

入力した欄だけが変わります。空の任意欄は保存済みの値を残します。削除が必要なら設定 › メールで行ってください。パスワードはほかの秘密情報とともに暗号化します。

デバイスでこのコードを読み取る

  1. Mini mPOS の設定 › 端末を開き、かんたんセットアップの設定コードを読み取るか右上のQRスキャンアイコンをタップします。決済先や環境を先に選ぶ必要はありません。
  2. カメラで下のコードを読み取ります。複数ある場合は自動で切り替わります。
  3. 決済先と環境、特にLIVEを確認します。転送コードを入力し、インポートをタップします。デバイスでは、ここで入力した項目だけが変わります。
  4. 自動では設定を続けるをタップします。デバイスがこの端末を見つけるか、選択用の一覧を表示します。情報を確認し、不足を補ってください。手動では設定を確認をタップします。保存済みの情報は折りたたまれ、手順をタップすると確認・編集できます。設定 › 端末で接続とAPIキーをテストします。Tap to Payでは共有キーの不足項目を入力し、Tap to Payを設定でスマートフォンを登録します。登録では共有キーを取得しません。

SMTP設定を含めた場合は設定 › メールを確認し、テストメールを送ります。メール取得と自動送信は別の設定です。メール設定を参照してください。

取り込み後は最初の TEST 決済を行ってください。

取り込みの問題 · 接続の問題

転送コード

知っておきたいこと

  • 入力内容はこのページの外に出ません。コードはブラウザー内で作成され、このページは何も送信・保存しません。終わったらページを閉じてください。
  • キーは暗号化されます。コード内のパスワードとキーは、ここにだけ表示される転送コードで暗号化されるため、コードの写真だけでは読み取れません。
  • 転送コードは秘密にしてください。QR コードと転送コードの両方があればキーを復号できます。必要に応じて新しい転送を作り、終わったら閉じてください。
  • 接続と任意のSMTP欄だけを設定します。商品、領収書のレイアウトやほかの店舗設定はコピーしません。それらはアプリの別のデバイスに共有を使います。
  • 全体の手順は？はじめにを参照し、取り込みや接続の問題はトラブルシューティングで確認してください。
