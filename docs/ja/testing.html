TEST の構成を確認する

  1. 設定 › 端末で、環境が TEST であることを確認します。最後の接続をテストで API アクセスと対応する接続チェックを確認します。
    • 物理端末：接続をテストを実行し、成功を確認します。
    • Tap to Pay：スマートフォンが Adyen Payments Test に登録されていることを確認します。接続チェックは設定のみを確認し、端末診断には対応していません。以下のテスト決済で決済の動作を確認します。
  2. 設定 › 決済で通貨を、設定 › 税で税率と税込・税抜の設定を確認します。
  3. ホームで新規販売をタップし、任意の商品を追加して会計ボタンをタップします。 カスタム商品名を「テスト販売」にし、テストカードのシナリオに合う金額を入力します。
  4. 決済ボタンをタップし、Adyen の POS テストガイド に従って成功する決済を行います。
  5. 結果が承認済みで、領収書の金額、通貨、税額が正しいことを確認します。取引履歴で販売を開き、PSP参照IDで TEST Customer Area の決済と照合します。
  6. この決済を返金し、TEST Customer Area で最終結果を確認します。返金要求済みは最終確認ではありません。
  7. Adyen の POS テストガイド の拒否シナリオで販売をもう一度試します。Mini mPOS が拒否を表示することを確認します。決済の拒否 を参照してください。

警告

結果が不明な場合は、もう一度決済しないでください。先に復旧手順に従います。

LIVE に向けて店舗を準備する

  • 商品価格を設定する前に、通貨と税を確認します。
  • 店舗情報を確認し、利用するレシートの提供方法をそれぞれテストします。
  • スタッフの PIN と、マネージャー承認が必要な操作を確認します。
  • 利用する追加の決済機能だけを有効にしてテストします。

本番運用を始める

警告

TEST、LIVE、シミュレーターを切り替えると、未完了の決済の復旧データを含め、デバイスのすべての決済履歴が削除されます。先に要確認の決済をすべて解決してください。

  1. LIVE の端末または LIVE 版 Payments アプリと、LIVE の認証情報に切り替えます。ネットワークやクラウドの端末、Tap to Pay では環境で LIVE を選びます。LIVE URLプレフィックスを入力します。 Adyen の LIVE エンドポイントガイド を参照してください。Tap to Pay は選択した環境で再登録が必要です。
  2. 設定 › 端末で、環境が LIVE であることを確認します。最後の接続をテストで API アクセスと対応する接続チェックを確認します。
    • 物理端末：接続をテストを実行し、成功を確認します。
    • Tap to Pay：スマートフォンが LIVE 版 Adyen Payments アプリに登録されていることを確認します。接続チェックは設定のみを確認し、端末診断には対応していません。

日々の確認と照合は締め作業を参照してください。

最初の LIVE 決済を確認する

実際に使う送信先とレシート提供方法で、Adyen の LIVE テスト手順に従います。LIVE Customer Area で金額、通貨、レシート、決済を確認してください。接続確認だけでは決済が動作する証明にはなりません。
