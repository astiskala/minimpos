Preparar a rede

Peça ao administrador de rede do site para permitir o seguinte:

Internet
Saída HTTPS em TCP 443 do dispositivo e terminal para *.adyen.com e *.adyenpayments.com. Permitir estes por nome de domínio, não endereço IP, porque os endereços IP da Adyen mudam.
Líquido local (para terminais de rede)
O tablet ou telefone deve alcançar o endereço IP do terminal em TCP 8443. Conecte ambos à mesma rede, e certifique-se de que o isolamento do cliente Wi-Fi (comum em redes convidadas) não os separe.

Dê a cada terminal de rede um endereço IP fixo com uma reserva DHCP em seu roteador. Os dados móveis funcionam para tablet ou telefone em configurações de nuvem e Tap to Pay, mas não com um terminal de rede. Para os próprios requisitos do terminal, consulte o Guia de configuração de rede Adyen.

Instale o aplicativo

  1. No dispositivo, abra o link de download direto ou leia este código com a câmera:
  2. Abra o APK no dispositivo e permita a instalação a partir do seu navegador ou gerenciador de arquivos quando o Android solicitar.
  3. Abra Mini mPOS, selecione Conectar-se à Adyen e toque em Continuar.

Importante

Instale todas as atualizações da mesma fonte de assinatura. Um terminal rejeita uma atualização assinada com uma chave diferente. Para construir e assinar o seu próprio, consulte o guia do contribuidor.

Emparelhar um terminal na sua rede

Auxiliar de configuração (recomendado)
Abra o auxiliar de configuração, escolha o ambiente TEST ou LIVE do terminal, mantenha Automático, insira a chave API e leia os códigos. Se mais de um terminal for encontrado, escolha o seu.
Manual
  1. Em Configurações › Terminal, conjunto Os pagamentos vão para para Um terminal na sua rede. Abaixo Ambiente, escolha TEST ou LIVE para corresponder ao terminal.
  2. Abaixo Adyen API, insira a chave Adyen API e a conta do comerciante, além do prefixo URL ativo para LIVE. Toque em Buscar configuração do terminal para testar o acesso API e escolher o terminal. Insira quaisquer detalhes ausentes manualmente.
  3. Verifique ou insira o endereço IP do terminal e ID do Terminal (POIID). Ambos estão na tela de informações do dispositivo do terminal.
  4. Verifique ou insira a chave compartilhada e toque em Testar conexão.
