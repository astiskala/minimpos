Instale o aplicativo

  1. No dispositivo, abra o link de download direto ou leia este código com a câmera:
  2. Abra o APK no dispositivo e permita a instalação a partir do seu navegador ou gerenciador de arquivos quando o Android solicitar.
  3. Abra Mini mPOS, selecione Conectar-se à Adyen e toque em Continuar.

Importante

Instale todas as atualizações da mesma fonte de assinatura. Um terminal rejeita uma atualização assinada com uma chave diferente. Para construir e assinar o seu próprio, consulte o guia do contribuidor.

Configurar Tap to Pay

  1. No Google Play, instale Adyen Payments Test para TEST ou Adyen Payments para LIVE. Ambos podem permanecer instalados.
  2. No Mini mPOS, abra Configurações › Terminal e selecione Tap to Pay neste telefone. Escolha TEST ou LIVE sob Ambiente; Mini mPOS abre apenas o aplicativo desse ambiente.
Auxiliar de configuração (recomendado)
Abra o auxiliar de configuração, escolha TEST ou LIVE, insira a chave API correspondente e leia os códigos. Após Verificar e importar, o Mini mPOS encontra a conta de comerciante e a chave compartilhada, cria a credencial de registro do telefone e abre o aplicativo Payments para registrá-lo.
Manual
  1. Em Configurações › Terminal › Adyen API, insira a chave Adyen API e a conta do comerciante. Para pagamentos em tempo real, insira também o prefixo URL em tempo real. Toque Teste API.
  2. Abaixo Tap to Pay, opcionalmente toque em Escolher loja ou insira um ID de loja. Nenhuma chave API separada é necessária.
  3. Toque Configurar Tap to Pay e realizar o cadastro no aplicativo Adyen Payments.
  4. Em Mini mPOS, inserir a chave compartilhada.
