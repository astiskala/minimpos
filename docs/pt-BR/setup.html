O que criar
Onde o Mini mPOS é executado e para onde vão os pagamentos?
Qual ambiente Adyen?

TEST ou LIVE está incluído em cada código de configuração para revisão. Para um terminal de rede/nuvem ou Tap to Pay, ele define o ambiente do aplicativo. Um terminal Adyen ainda usa o certificado do dispositivo para a conexão.

Como você deseja configurar?

Siga o Pré-requisitos Tap to Pay e instale primeiro o aplicativo Adyen Payments. Mini mPOS usa sua chave API da Adyen para criar automaticamente a credencial de registro do telefone. Insira a chave compartilhada aqui; Mini mPOS não procura. O registro é uma ação explícita no telefone antes do término da importação.

Chave Adyen API

Crie uma credencial em Developers › API credentials e gerar sua chave API. Essa chave trata do Checkout e provisiona a credencial de registro separada do telefone. Cada configuração requer as mesmas funções de credenciais principais; veja o requisitos de credenciais.

Chave compartilhada

Em Developers › API URLs.

Tap to Pay

Mini mPOS cria automaticamente uma credencial separada com o Adyen Payments App role e uma chave de cliente. Nenhuma chave extra para entrar ou transferir. Veja Solução de problemas Tap to Pay e o Guia do aplicativo Adyen Payments.

Para configurar o telefone para uma loja: seu ID (não sua referência) de Devices › Stores.

Configurações opcionais de recibos e e-mail
Detalhes do recibo (opcional)

Quando desativado, nenhum texto de recibo ou detalhes comerciais da Adyen são importados.

Detalhes do recebimento

Escolha importação Adyen ou entrada manual para cada área de negócio.

Somente o texto manual fornecido altera os valores salvos. Os campos em branco mantêm o texto existente. A identificação fiscal, o título e o rodapé são inseridos manualmente, não importados da Adyen. Veja configuração de recibo.

Recibos de e-mail (opcional)

Verificar configuração de e-mail e requisitos do provedor primeiro; o auxiliar não pode testar o servidor.

Servidor SMTP

Apenas os campos fornecidos mudam. Os campos opcionais em branco mantêm os valores salvos; limpe-os em Configurações › Recibos de e-mail, se necessário. A senha é selada com os demais segredos.

Configurações de e-mail
  1. No Mini mPOS, abra Configurações › Terminal e toque em Digitalizar códigos de configuração em Configuração rápida ou no ícone de digitalização QR no canto superior direito.
  2. Aponte sua câmera para os códigos. Com mais de um, eles mudam sozinhos.

Se você incluiu configurações SMTP, revise Configurações › Recibos por e-mail e enviar um e-mail de teste.

Problema de importação? · Problema de conexão?

É bom saber

  • As credenciais ficam no navegador. O assistente gera os códigos localmente e não envia nem salva as credenciais digitadas. O site também carrega serviços de segurança e desempenho da Cloudflare.
  • As chaves são seladas. As senhas e chaves nos códigos são criptografadas com a transferência código, que é mostrado apenas aqui, portanto, uma foto dos códigos por si só não os revela.
  • Mantenha o código de transferência privado. Qualquer pessoa com os códigos e o código de transferência pode abra as chaves. Gere uma nova transferência quando necessário; feche esta página quando terminar.
  • Precisa das instruções completas? Seguir Início rápido; para um problema de importação ou conexão, consulte Solução de problemas.
