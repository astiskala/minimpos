Install the app

  1. On the device, open the direct download link, or scan this code with its camera:
  2. Open the APK on the device and allow installation from your browser or file manager when Android asks.
  3. Open Mini mPOS, select Connect to Adyen and tap Continue.

Important

Install every update from the same signing source. A terminal rejects an update signed with a different key. To build and sign your own, see the contributor guide.

Connect a cloud terminal

Setup helper (recommended)
Open the setup helper, choose the terminal's TEST or LIVE environment, keep Automatic, enter the API key and scan the codes. If more than one terminal is found, choose yours.
Manual
  1. In Settings › Terminal, set Payments go to to A terminal over the internet (cloud). Under Environment, choose TEST or LIVE to match the terminal.
  2. Under Adyen API, enter the Adyen API key and merchant account, plus the live URL prefix for LIVE. Tap Find terminal setup to test API access and choose the terminal. Enter any missing details manually.
  3. Check or enter the Terminal ID (POIID) and tap Test connection.
