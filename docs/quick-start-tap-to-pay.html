Install the app

  1. On the device, open the direct download link, or scan this code with its camera:
  2. Open the APK on the device and allow installation from your browser or file manager when Android asks.
  3. Open Mini mPOS, select Connect to Adyen and tap Continue.

Important

Install every update from the same signing source. A terminal rejects an update signed with a different key. To build and sign your own, see the contributor guide.

Set up Tap to Pay

  1. From Google Play, install Adyen Payments Test for TEST or Adyen Payments for LIVE. Both can stay installed.
  2. In Mini mPOS, open Settings › Terminal and select Tap to Pay on this phone. Choose TEST or LIVE under Environment; Mini mPOS opens only that environment's app.
Setup helper (recommended)
Open the setup helper, choose TEST or LIVE, enter the matching API key and scan the codes. After Verify and import, Mini mPOS finds the merchant account and shared key, creates the phone's registration credential and opens the Payments app to register it.
Manual
  1. In Settings › Terminal › Adyen API, enter the Adyen API key and merchant account. For live payments, also enter the live URL prefix. Tap Test API.
  2. Under Tap to Pay, optionally tap Choose store or enter a store ID. No separate API key is needed.
  3. Tap Set up Tap to Pay and complete registration in the Payments app.
  4. In Mini mPOS, enter the shared key.
