Install the app

Download the signed minimpos-<version>.apk from the latest release.

  1. In the Customer Area, open Devices › Terminal apps, upload the APK and wait until it shows Ready; see the Adyen upload guide. Your user needs the Merchant POS Terminal Management Admin role.
  2. Select the app, then Install. Choose the version and Schedule now, select your terminal and confirm Schedule installation. See the Adyen scheduling guide.
  3. Keep the terminal on and online. It installs the app at its next maintenance call, by default within three hours. To try to get it sooner, open Settings › Configuration on the terminal, enter the passcode and select Update.
  4. Open Mini mPOS on the terminal, select Scan setup codes and tap Continue.

Important

Install every update from the same signing source. A terminal rejects an update signed with a different key. To build and sign your own, see the contributor guide.

Connect an Adyen terminal

Setup helper (recommended)
Open the setup helper, choose the terminal's TEST or LIVE environment, keep Automatic, enter the API key and scan the codes.
Manual
  1. In Settings › Terminal › Adyen API, enter the Adyen API key and merchant account, plus the live URL prefix for LIVE. Tap Find terminal setup to test API access and fill in the shared key automatically.
  2. Check or enter the shared key and tap Test connection.
