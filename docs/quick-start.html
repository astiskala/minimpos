Choose your setup

Check these requirements before you install the app. The device runs Mini mPOS; the payment terminal takes the card. They can be the same device.

On an Adyen terminal
The complete checkout on one device. Use an Adyen Android payment terminal with Android 9 or later. Check the current models in the Adyen Android terminal guide.
Tap to Pay on a phone
No separate terminal. Use a phone with near-field communication (NFC) and the Adyen Payments app, activated by Adyen Support. Check the Adyen phone requirements and Adyen supported countries and payment methods.

With a separate terminal

Tablet or phone with a network terminal
Recommended for a counter. An Android 9+ tablet or phone on the same local network as an Adyen terminal. Mini mPOS is not installed on that terminal.
Tablet or phone with a cloud terminal
For a device and terminal on different networks. Both need internet access; payments reach the terminal through Adyen.

Physical-terminal features depend on the terminal, payment method and Adyen configuration. Test the workflows you need. Check Adyen capabilities.

  • Printing needs a terminal with a built-in printer. If there is none, email or share receipts.
  • Scanning barcodes, refund QR codes or setup codes needs a camera.

Prepare Adyen credentials

Every real-payment setup needs Checkout API access. Use a company-level API credential with access to the destination’s merchant account.

To create or edit credentials, your Customer Area user needs Manage API credentials or Merchant admin. These are user permissions, not roles for the API key.

Enable the POS payment methods you plan to accept; follow the Adyen payment method setup guide. Mini mPOS uses the terminal's configured methods.

  1. In the Customer Area, go to Developers › API credentials. Create a credential for Mini mPOS and generate its API key; see the Adyen API credential guide.
  2. For LIVE, note the Live URL prefix from Developers › API URLs.
  3. For Tap to Pay, Mini mPOS automatically creates a separate merchant-scoped credential with the Adyen Payments App role and a client key. Adyen Support must enable Tap to Pay and make this role assignable from your company credential.
Required API credential roles

The same primary credential roles are required for every setup.

Enabled by default

  • Merchant PAL webservice role
  • Checkout webservice role
  • Management API - API credentials read and write
  • Management API - Payment methods read
  • Management API - Stores read
  • Management API - Accounts read
  • Merchant Recurring role

Add these roles

  • Management API - Terminal actions read
  • Management API - Terminal settings read and write
  • Management API - Terminal settings Advanced read and write
  • Cloud Device API role
  • API tokenise payment details

Adyen: API roles

Missing a role? When Mini mPOS first checks a key that lacks one, it offers to add it for you, if your company’s ws credential holds that role.

If you want to configure the device manually:
  • Note the Merchant account.
  • For an Adyen terminal, network terminal or Tap to Pay, find the Shared key (identifier, passphrase and version) under Devices › Device settings › Integrations › Terminal API › Encryption key. Cloud terminals do not use it.

The shared key encrypts communication with a local terminal or the Payments app. Cloud terminals do not use it.

Important

Mini mPOS has no server, so API keys are stored encrypted on the device. Create credentials only for Mini mPOS with only the API roles needed for your setup. Set an admin PIN, and revoke the credentials if a device is lost. See the security policy.

Create a missing encryption key

If a physical terminal has no encryption key yet, setup offers Create encryption key after the credential and account checks pass.

  1. Check the terminal ID and environment shown, then confirm. Do not change this terminal's settings elsewhere while the key is created.
  2. If the connection is not verified yet, update the terminal's configuration; see key setup recovery.
  3. If creation is interrupted, tap Resume key setup. For QR setup, scan the same codes again with their transfer code.
