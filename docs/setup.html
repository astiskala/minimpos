Setup helper

Set up a device from your computer

Long API keys are hard to type on a terminal's keypad. Fill them in here, next to your Customer Area, and scan the result into Mini mPOS as QR codes.

New to Mini mPOS? Choose your setup and prepare your credentials before filling in this form.

Customer Area links open in a new tab so you can keep this form open.

The setup helper needs JavaScript. Switch it on for this page, or enter the details in the app as the getting started guide describes.

1. Where does Mini mPOS run, and where do payments go?
2. Which Adyen environment?

For a network or cloud terminal, this choice is imported as the app’s environment. On an Adyen terminal or with Tap to Pay, the device or installed Payments app determines it instead. Use matching credentials; this choice also selects Customer Area links and the live URL prefix field.

3. How do you want to set up?

Both modes need the LIVE URL prefix for LIVE. If automatic lookup is unavailable or incomplete, enter the missing details on the device or use Manual here.

Follow the Tap to Pay prerequisites and install the Payments app first. Enter the merchant account and separate Payments app API key for registration. Enter the shared key here or later on the phone; Mini mPOS does not look it up. You do not need to copy boarding tokens.

Adyen API key

Create a credential in Developers › API credentials and generate its API key. Add the Cloud Device API role for cloud payments. This key is for Checkout operations, not Payments app registration. Automatic setup needs the lookup roles in the setup guide. This helper stays offline; discovery runs on the device after import.

SMTP server

Only supplied fields change. Blank optional fields keep saved values; clear them in Settings › Email if needed. The password is sealed with the other secrets.

Scan these codes with the device

  1. In Mini mPOS, open Settings › Terminal and tap Scan setup codes under Quick setup, or the QR scan icon at the top right. You do not need to choose a destination or environment first.
  2. Point its camera at the codes below. With more than one, they change by themselves.
  3. Review the destination and environment, especially LIVE. Type the transfer code and tap Import. Only what you filled in here changes on the device.
  4. Tap Continue setup for Automatic: the device finds this terminal or offers a list to choose from. Review the details and enter anything missing. For Manual, tap Review setup. Test the connection and API key under Settings › Terminal. Saved details start collapsed; tap a step to review or edit them. With Tap to Pay, enter any missing shared-key fields, then tap Set up Tap to Pay to register the phone. Registration does not retrieve the shared key.

If you included SMTP settings, review Settings › Email and send a test email. Email collection and automatic delivery are configured separately; see email setup.

After importing, make your first TEST payment.

Transfer code

Good to know

  • Nothing leaves this page. The codes are made in your browser; the page sends nothing anywhere and stores nothing. Close it when you are done.
  • The keys are sealed. Passwords and keys in the codes are encrypted with the transfer code, which is shown only here, so a photo of the codes alone does not reveal them.
  • Keep the transfer code private. Anyone with both the codes and the transfer code can open the keys. Generate a fresh transfer when needed; close this page when finished.
  • This sets the connection and optional SMTP fields only. It does not copy products, receipt layouts or other business settings. For those, use Share with another device in the app.
  • Need the full instructions? Follow Getting started; for an import or connection problem, see Troubleshooting.
