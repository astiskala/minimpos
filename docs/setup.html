Where does Mini mPOS run, and where do payments go?
Which Adyen environment?

TEST or LIVE is included in every setup code for review. For a network/cloud terminal or Tap to Pay, it sets the app’s environment. An Adyen terminal still uses its device certificate for the connection.

How do you want to set up?

Follow the Tap to Pay prerequisites and install the Payments app first. Mini mPOS uses your Adyen API key to create the phone’s registration credential automatically. Enter the shared key here; Mini mPOS does not look it up. Registration is an explicit action on the phone before import finishes.

Adyen API key

Create a credential in Developers › API credentials and generate its API key. This key handles Checkout and provisions the phone’s separate registration credential. Every setup requires the same main credential roles; see the credential requirements.

Import problem? · Connection problem?

Good to know

  • Credentials stay in your browser. The helper makes codes locally and does not send or save entered credentials. The hosted site also loads Cloudflare security and performance services.
  • The keys are sealed. Passwords and keys in the codes are encrypted with the transfer code, which is shown only here, so a photo of the codes alone does not reveal them.
  • Keep the transfer code private. Anyone with both the codes and the transfer code can open the keys. Generate a fresh transfer when needed; close this page when finished.
  • Need the full instructions? Follow Quick start; for an import or connection problem, see Troubleshooting.
