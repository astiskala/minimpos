先体验，无需账户

首次启动时，选择使用示例数据试用模拟器、从另一台设备设置以导入设置二维码，或设置终端。选择模拟器会添加示例商品和只读演示记录，无需 Adyen 账户。示例记录及其收据会标为演示，不计入每日总额。

在设置 › 数据中可添加示例数据或删除示例数据。删除会包括已编辑的示例商品，但保留您自己的商品、记录、税率和设置，以及您的商品使用的示例分类。在此添加示例不会改变支付目标。

从最新发布版本下载 minimpos-<version>.apk，在 Android 手机或模拟器上打开（Android 9 或更高版本）。按 Android 提示允许浏览器或文件管理器安装应用。

不在 Adyen 终端上运行时，Mini mPOS 默认使用支付模拟器，不会扣款。在设置 › 模拟器中可选择成功、拒绝、忙碌或超时的结果、延迟以及是否有打印机。模拟收据显示在屏幕上；也可体验订金、小费和扣款。离线演示链接请参阅支付链接。

要从源码构建？请参阅贡献者指南。

选择配置方式

设备运行 Mini mPOS，终端读取银行卡。两者可以是同一台设备。

在 Adyen 终端上运行
一台设备完成整个收银流程。需要 Android 9 或更高版本的 Adyen Android 终端，例如 S1F2、S1F4Pro、S1E4Pro、S1E2L、AMS1、S1U2 或 SFO1。
平板或手机搭配同一网络中的终端
柜台平板的推荐方式。Android 9+ 设备和终端必须在同一网络。终端上无需安装 Mini mPOS。
平板或手机搭配云端终端
适用于不同网络中的设备和终端。付款通过 Adyen Cloud device API 发送到终端。
在手机上使用 Tap to Pay
无需独立终端。需要通过 Google 认证、支持 NFC 的 Android 12+ 手机、Adyen Payments 应用，以及 Adyen 支持团队开通服务。请检查 Adyen 的要求与支持的国家和付款方式。

打印需要配有打印机的终端。扫描条形码、收据或设置二维码需要摄像头。Tap to Pay 没有打印机，请发送电子收据或分享收据。

Mini mPOS 是独立项目，并非 Adyen 制作、背书或支持的产品。真实付款需要已开通相关服务的 Adyen 账户、商户后台访问权限和 Checkout API 凭据。账户及平台操作请遵循链接中的 Adyen 文档。

安装应用

所有配置方式均使用最新发布版本提供的已签名 APK。

  • Adyen 终端：按照 Adyen 的应用部署指南，在商户后台上传并部署。用户需有上传和部署应用的权限。
  • 平板或手机：在设备上打开 APK 并允许安装，无需通过 Adyen 部署。

更新时保持同一签名来源：终端只接受同一密钥签名的后续版本。自行构建和签名请参阅贡献者指南。

连接 Adyen

只需遵循下方与您对应的配置步骤。打开设置 › 终端，通过二维码快速设置。在平板或手机上手动输入时，选择支付目标。应用中的编号步骤会列出所需信息，首页会提示缺少的项目。

准备凭据

在 Developers › API credentials 中创建凭据并生成 API 密钥；参见 Adyen 的凭据指南。Checkout webservice role 默认分配。仅添加配置所需的额外角色：

  • Cloud Device API role：云端付款必需。
  • Management API — Terminal actions read：所有真实付款设置的主 Adyen API 凭据都必须具有此权限，包括手动方式和 Tap to Pay。凭据须属于终端的 Company 账户，并能访问对应商家账户和终端。
  • Management API — Terminal settings read：本终端或同一网络中的终端的可选共享密钥设置查询。
  • Management API — Terminal settings Advanced read and write：上述目标的可选共享密钥口令查询。

本终端、同一网络中的终端和 Tap to Pay 还需要共享密钥：在 Devices › Device settings › Integrations › Terminal API › Encryption key 中获取标识符、口令和版本。参见 Adyen 的本地集成指南。云端配置不使用此密钥。

同一网络中的终端和云端终端以环境为步骤 1：测试卡选择 TEST，真实付款选择 LIVE。终端、账户和凭据必须属于同一环境。Mini mPOS 不会在另一环境尝试 API 密钥。在 Adyen 终端上运行时，应用读取本设备经过验证的证书；Tap to Pay 则使用已安装的 Payments 应用的环境。

完成当前步骤后才显示下一步。在 Adyen API 中一起输入 API 密钥和商家账户；LIVE 还需输入实时 URL 前缀。点击测试 API（输入密钥时点击保存并测试 API），测试成功后显示下一步。已获取的信息会保持可见、可编辑，再次打开设置时也一样；部分填写的设置也会显示。

实体终端在输入的密钥、商家账户及实时 URL 前缀通过 API 测试后，才会在 Adyen API 下显示获取设置，用于查询该环境的终端信息。应用只读取信息，不会修改 Adyen 的设置或密钥。参阅 Adyen 的终端列表与终端设置 API 文档。终端访问验证失败时不能继续设置；请更正凭据的 Company 账户、权限或访问范围后重试。仅共享密钥查询是可选的：访问验证通过后，可手动输入共享密钥并测试连接。查询到的地址可能过时，请先检查。Tap to Pay 会检查主凭据所需角色，但不查询实体终端。

从电脑输入密钥

在可信电脑上打开设置助手，选择支付目标及 TEST/LIVE。自动（推荐）需输入 API 密钥；具有查询权限时，设备会查找终端的商家账户、地址及共享密钥。在手机或平板电脑上选择终端并检查结果。手动需在电脑上输入全部连接信息。LIVE 环境下两种方式都需要 live URL prefix。Tap to Pay 需手动输入共享密钥；安装与手机注册仍在设备上完成。请参阅其设置步骤。

还可选填电子收据的 SMTP 设置。服务商要求请参阅邮件设置。导入后检查设置 › 电子邮件并发送测试邮件。

点击生成二维码。在应用的设置 › 终端点按扫描设置二维码或右上角的扫描图标。扫描全部二维码，检查支付目标和环境，再输入单独显示的 12 位传输码；连字符会自动插入。每次传输都必须输入传输码，包括只传输商品目录或设置时。

点击验证并导入。自动查询可补全连接信息，仅有多个合适终端时才需选择。凭据、账户和连接验证通过后才会导入。仍缺少必需信息时，请在助手中选择手动并生成完整的新二维码。被拒绝的导入不会更改当前设置或商品目录。Tap to Pay 会明确提示注册手机，并使用其支持的检查而非诊断测试。

验证后的导入可在保存中断后继续，不会重复替换商品目录或注册手机。已获取的设置默认展开，可再次编辑。新设置会从已分配门店补充空白的收据商家信息，已有文本保持不变；参见收据设置。返回会进入首页，不再显示首次设置选项。也可直接在“设置 › 终端”中配置。

在 Adyen 终端上运行

请先安装应用并准备凭据。

设置助手（推荐）
在可信电脑上打开设置助手，选择在 Adyen 终端上运行、终端的 TEST/LIVE 环境及自动。填写 Adyen API 密钥，LIVE 还需填写实时 URL 前缀。按照验证后导入二维码的步骤操作。Mini mPOS 会匹配本终端，获取商家账户和共享密钥，在保存前完成测试。无法获取完整必需信息时，请在助手中选择手动并生成完整二维码。
手动
  1. 在设置 › 终端 › Adyen API中输入 Adyen API 密钥和商家账户，LIVE 还需输入实时 URL 前缀。API 测试成功后，可点击获取设置补充终端信息。应用无需共享密钥即可读取本设备证书，确定 TEST/LIVE。测试 API 后显示共享密钥步骤。
  2. 检查或输入共享密钥，点击测试连接（输入口令时点击保存并测试）。地址与 POIID 从设备检测。

搭配同一网络中的终端

请先安装应用并准备凭据。

设置助手（推荐）
在可信电脑上打开设置助手，选择平板或手机搭配同一网络中的终端、终端的 TEST/LIVE 环境及自动。填写 Adyen API 密钥，LIVE 还需填写实时 URL 前缀。按照验证后导入二维码的步骤操作。仅有多个合适候选时选择终端；账户分配、地址、共享密钥和连接会在保存前检查。查询无法提供完整信息时，在助手中选择手动。
手动
  1. 选择同一网络中的终端，在步骤 1 的环境中选择与终端一致的 TEST 或 LIVE。
  2. 在 Adyen API 中输入 Adyen API 密钥和商家账户，LIVE 还需输入实时 URL 前缀。API 测试成功后显示终端步骤及获取设置，可从查询列表选择终端。
  3. 检查或输入 IP 地址和 POIID；终端的“Device info”界面显示这两项。填写完整后显示共享密钥步骤。
  4. 检查或输入共享密钥并测试连接。

连接会验证终端证书是否与所选环境一致。不一致时会拒绝连接，而不会自动更改环境。

通过互联网连接终端

请先安装应用并准备凭据。

设置助手（推荐）
在可信电脑上打开设置助手，选择平板或手机通过互联网连接终端（云端）、终端的 TEST/LIVE 环境及自动。填写具有 Cloud Device API role 的 Adyen API 密钥，LIVE 还需填写实时 URL 前缀。按照验证后导入二维码的步骤操作。仅在必要时选择终端；账户、POIID、API 访问和连接会在保存前检查。在助手中选择手动可自行填写信息。
手动
  1. 选择云端支付目标，在步骤 1 的环境中选择与终端一致的 TEST 或 LIVE。
  2. 在 Adyen API 中输入具有 Cloud Device API role 的 Adyen API 密钥和商家账户，LIVE 还需输入实时 URL 前缀。API 测试成功后显示终端步骤及获取设置，可从查询列表选择终端。
  3. 检查或输入终端 POIID，点击测试连接，同时重新测试 API。

应用会在所选环境中查找数据中心。云端付款等待终端响应的时间可能比本地付款更长。

使用 Tap to Pay

使用 Tap to Pay on Android 需要 Adyen 为您的公司开通该服务及 Adyen Payments app role。请先联系 Adyen 支持团队。

请先安装应用并准备凭据。

  1. 从 Google Play 安装 TEST 用的 Adyen Payments Test 或 LIVE 用的 Adyen Payments，不要同时安装。
  2. 在 Mini mPOS 中打开设置 › 终端，选择在本手机上使用 Tap to Pay。

选择如何输入已安装 Payments 应用所属环境的凭据：

设置助手（推荐）
在可信电脑上打开设置助手，选择 Tap to Pay 和匹配的 TEST/LIVE 环境。填写 Adyen API 密钥、商家账户及独立的 Payments 应用 API 密钥。请在此输入完整共享密钥。LIVE 还需填写实时 URL 前缀，可选填门店 ID。按照验证后导入二维码的步骤操作，在导入完成前按明确提示注册手机。
手动

在设置 › 终端 › Adyen API中一起输入 Adyen API 密钥和商家账户，LIVE 还需输入实时 URL 前缀。API 测试成功后显示 Tap to Pay。输入独立的Payments 应用 API 密钥（仅有 Adyen Payments app role），可选填门店 ID（不是 reference）。

两种方式都需先测试 API，再点击设置 Tap to Pay，在 Payments 应用中完成注册。Checkout 与手机注册使用同一商家账户。注册后显示共享密钥步骤。

Mini mPOS 不会查询 Tap to Pay 共享密钥。请在助手中输入标识符、口令和版本；直接在设备上手动设置时，也可在设置中输入。Payments 应用不支持诊断连接测试：Mini mPOS 会验证注册、账户访问和必需字段，但无法对共享密钥进行诊断测试。已获取的字段会保持可见、可编辑。

Mini mPOS 会执行 Adyen Payments 应用指南中的注册流程：检查注册状态、请求一次性注册令牌，再将其发送到 Payments 应用。无需手动复制注册令牌。Payments 应用 API 密钥用于授权注册，独立的 Adyen API 密钥用于 Checkout 操作。共享密钥按 Adyen 要求加密支付消息，注册不能替代它。

付款会打开 Payments 应用，再返回 Mini mPOS。已安装的应用决定 TEST 或 LIVE 环境。以后要注销手机，请使用移除本手机。

API 密钥会加密保存在本设备上。Adyen 建议将其保存在服务器上，但 Mini mPOS 没有服务器。使用仅具所需权限、专用于 Mini mPOS 的凭据，设置管理员 PIN，并撤销泄露或丢失设备的凭据。请阅读安全政策。

完成第一笔 TEST 付款

  1. 检查设置 › 终端，所选或检测到的环境应为 TEST。完成连接与 API 测试。
  2. 在设置 › 支付中确认 Adyen 账户接受的币种，在设置 › 税中确认税率和价格是否含税。
  3. 点击新建销售，输入自定义金额并进入结账。点击支付，使用 Adyen 的测试卡。
  4. 检查结果、收据和交易记录，也测试退款。如果结果未知，请先按恢复说明处理，再尝试其他付款。

接下来参阅使用 Mini mPOS，添加商品、自定义收据、设置员工权限并启用所需流程。

接受真实付款之前

  • 测试所有计划使用的流程，包括订金、小费和支付链接。模拟器测试不能替代 Adyen 测试。
  • 有打印机时打印实体测试收据；使用电子收据时发送测试邮件。
  • 设置管理员 PIN，需要时另设经理 PIN。检查业务设置。
  • 使用 LIVE 终端或 Payments 应用及其 LIVE 凭据。同一网络中的终端或云端终端需在步骤 1 选择 LIVE。Checkout 需要 Developers › API URLs 中的 live URL prefix，参见 Adyen 的LIVE 端点。选择或检测到 LIVE 后显示该字段。
  • 运行连接和 API 测试，确认“设置 › 终端”中显示 LIVE。设置助手会为网络和云端终端导入环境选择，但不能覆盖 Adyen 终端的证书或已安装的 Payments 应用的环境。

需要帮助？请参阅故障排查。
