先体验，无需账户

从最新发布版本下载 minimpos-<version>.apk，在 Android 手机或模拟器上打开（Android 9 或更高版本）。按 Android 提示允许浏览器或文件管理器安装应用。

不在 Adyen 终端上运行时，Mini mPOS 默认使用支付模拟器，不会扣款。在设置 › 模拟器中可选择成功、拒绝、忙碌或超时的结果、延迟以及是否有打印机。模拟收据显示在屏幕上；也可体验订金、小费和扣款。支付链接不支持模拟。

要从源码构建？请参阅贡献者指南。

选择配置方式

设备运行 Mini mPOS，终端读取银行卡。两者可以是同一台设备。

在 Adyen 终端上运行
一台设备完成整个收银流程。需要 Android 9 或更高版本的 Adyen Android 终端，例如 S1F2、S1F4Pro、S1E4Pro、S1E2L、AMS1、S1U2 或 SFO1。
平板或手机搭配同一网络中的终端
柜台平板的推荐方式。Android 9+ 设备和终端必须在同一网络。终端上无需安装 Mini mPOS。
平板或手机搭配云端终端
适用于不同网络中的设备和终端。付款通过 Adyen Cloud device API 发送到终端。
在手机上使用 Tap to Pay
无需独立终端。需要通过 Google 认证、支持 NFC 的 Android 12+ 手机、Adyen Payments 应用，以及 Adyen 支持团队开通服务。请检查 Adyen 的要求与支持的国家和付款方式。

打印需要配有打印机的终端。扫描条形码、收据或设置二维码需要摄像头。Tap to Pay 没有打印机，请发送电子收据或分享收据。

Mini mPOS 是独立项目，并非 Adyen 制作、背书或支持的产品。真实付款需要已开通相关服务的 Adyen 账户、商户后台访问权限和 Checkout API 凭据。账户及平台操作请遵循链接中的 Adyen 文档。

安装应用

所有配置方式均使用最新发布版本提供的已签名 APK。

  • Adyen 终端：按照 Adyen 的应用部署指南，在商户后台上传并部署。用户需有上传和部署应用的权限。
  • 平板或手机：在设备上打开 APK 并允许安装，无需通过 Adyen 部署。

更新时保持同一签名来源：终端只接受同一密钥签名的后续版本。自行构建和签名请参阅贡献者指南。

连接 Adyen

只需遵循下方与您对应的配置步骤。在平板或手机上，先选择设置 › 终端 › 支付目标。应用中的编号步骤会列出所需信息，首页会提示缺少的项目。

准备凭据

在 Developers › API credentials 中创建凭据并生成 API 密钥；参见 Adyen 的凭据指南。Checkout webservice role 默认分配。仅添加配置所需的额外角色：

  • Cloud Device API role：云端付款必需。
  • Management API — Terminal actions read：可选的自动终端查询，包括账户和最近上报的网络地址。
  • Management API — Terminal settings read：本终端或同一网络中终端的可选自动共享密钥设置查询。
  • Management API — Terminal settings Advanced read and write：本终端或同一网络中终端的可选自动共享密钥口令查询。

本终端、同一网络中的终端和 Tap to Pay 还需要共享密钥：在 Devices › Device settings › Integrations › Terminal API › Encryption key 中获取标识符、口令和版本。参见 Adyen 的本地集成指南。云端配置不使用此密钥。

同一网络中的终端和云端终端以环境为步骤 1：测试卡选择 TEST，真实付款选择 LIVE。终端、账户和凭据必须属于同一环境。Mini mPOS 不会在另一环境尝试 API 密钥。在 Adyen 终端上运行时，应用读取本设备经过验证的证书；Tap to Pay 则使用已安装的 Payments 应用的环境。

实体终端可在Adyen API 密钥下点击保存并获取设置，加密保存密钥并在该环境查询终端。应用只读取信息，不会修改 Adyen 的设置或密钥。参阅 Adyen 的终端列表与终端设置 API 文档。查询被拒绝、不可用或信息不完整时，密钥仍保持已保存，可手动补充缺失项。手动设置无需 Management 权限。查询到的地址可能过时，请先检查。Tap to Pay 只保存密钥，不查询实体终端。

从电脑输入密钥

在可信电脑上打开设置助手，选择支付目标及 TEST/LIVE。自动（推荐）仅需输入 API 密钥；具有查询权限时，设备会查找终端的商家账户、地址及共享密钥。在手机或平板电脑上选择终端并检查结果。手动需在电脑上输入全部连接信息。LIVE 环境下两种方式都需要 live URL prefix。Tap to Pay 使用手动方式；安装与手机注册仍在设备上完成。

点击生成二维码。在应用中打开设置 › 数据 › 从另一台设备设置，扫描所有二维码，输入传输码，再点击导入。自动方式点击继续设置，手动方式点击检查设置。补充缺失信息后，按下方说明测试连接及 API 密钥。无法查询时，导入的密钥仍会保存，可在设备上填写信息，或使用设置助手的手动方式。也可直接在“设置 › 终端”中输入所有信息。

在 Adyen 终端上运行

请先安装应用并准备凭据。

  1. 在设置 › 终端 › Adyen API 密钥中保存密钥。应用无需共享密钥即可读取本设备证书，确定 TEST/LIVE。具有查询权限时，应用会匹配本终端并填写商家账户和共享密钥。
  2. 检查或输入共享密钥，点击测试连接（输入口令时点击保存并测试）。地址与 POIID 从设备检测。
  3. 检查或输入 Checkout API 中的商家账户，然后点击测试 API 密钥。

搭配同一网络中的终端

请先安装应用并准备凭据。

  1. 选择同一网络中的终端，在步骤 1 的环境中选择与终端一致的 TEST 或 LIVE。
  2. 保存该环境的Adyen API 密钥。查询可用时，从列表中选择终端。
  3. 检查 POIID、商家账户、IP 地址及共享密钥，手动补充缺失项。终端的“Device info”界面显示当前地址与 POIID。
  4. 使用共享密钥测试连接，再检查 Checkout API 中的商家账户并点击测试 API 密钥。

连接会验证终端证书是否与所选环境一致。不一致时会拒绝连接，而不会自动更改环境。

通过互联网连接终端

请先安装应用并准备凭据。

  1. 选择云端支付目标，在步骤 1 的环境中选择与终端一致的 TEST 或 LIVE。
  2. 保存该环境中具有 Cloud Device API role 的Adyen API 密钥。查询可用时，从列表中选择终端。
  3. 检查或输入Adyen 账户中的商家账户。LIVE 环境还需输入 Checkout 实时 URL 前缀。
  4. 检查或输入终端 POIID，点击测试连接，同时测试终端和 Checkout API。

应用会在所选环境中查找数据中心。云端付款等待终端响应的时间可能比本地付款更长。

使用 Tap to Pay

请先安装应用并准备凭据。

  1. 选择在本手机上使用 Tap to Pay。步骤 1 为 Adyen Payments 应用：请 Adyen 支持团队开通 Tap to Pay on Android 和 Adyen Payments app role，然后安装 TEST 用的 Adyen Payments Test 或 LIVE 用的 Adyen Payments，不要同时安装。应用提供 Google Play 链接。
  2. 保存已安装应用所属环境的Adyen API 密钥。无需查询实体终端。
  3. 在 Checkout API 中输入商家账户，LIVE 环境还需输入实时 URL 前缀，然后点击测试 API 密钥。注册手机时使用同一账户。
  4. 在 Tap to Pay 下输入独立的Payments 应用 API 密钥（仅有 Adyen Payments app role），可选填门店 ID。点击设置 Tap to Pay，在 Payments 应用中完成注册。
  5. 输入共享密钥，用于加密向 Payments 应用发送的付款。遵循 Adyen 的Payments 应用指南。

付款会打开 Payments 应用，再返回 Mini mPOS。已安装的应用决定 TEST 或 LIVE 环境。以后要注销手机，请使用移除本手机。

API 密钥会加密保存在本设备上。Adyen 建议将其保存在服务器上，但 Mini mPOS 没有服务器。使用仅具所需权限、专用于本设备或终端群的凭据，设置管理员 PIN，并撤销泄露或丢失设备的凭据。请阅读安全政策。

完成第一笔 TEST 付款

  1. 检查设置 › 终端，所选或检测到的环境应为 TEST。完成连接与 API 测试。
  2. 在设置 › 支付中确认 Adyen 账户接受的币种，在设置 › 税中确认税率和价格是否含税。
  3. 点击新建销售，输入自定义金额并进入结账。点击支付，使用 Adyen 的测试卡。
  4. 检查结果、收据和交易记录，也测试退款。如果结果未知，请先按恢复说明处理，再尝试其他付款。

接下来参阅使用 Mini mPOS，添加商品、自定义收据、设置员工权限并启用所需流程。

接受真实付款之前

  • 测试所有计划使用的流程，包括订金、小费和支付链接。模拟器测试不能替代 Adyen 测试。
  • 有打印机时打印实体测试收据；使用电子收据时发送测试邮件。
  • 设置管理员 PIN，需要时另设经理 PIN。检查业务设置。
  • 使用 LIVE 终端或 Payments 应用及其 LIVE 凭据。同一网络中的终端或云端终端需在步骤 1 选择 LIVE。Checkout 需要 Developers › API URLs 中的 live URL prefix，参见 Adyen 的LIVE 端点。选择或检测到 LIVE 后显示该字段。
  • 运行连接和 API 测试，确认“设置 › 终端”中显示 LIVE。设置助手会为网络和云端终端导入环境选择，但不能覆盖 Adyen 终端的证书或已安装的 Payments 应用的环境。
