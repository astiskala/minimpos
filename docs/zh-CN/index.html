免费开源 · 直接运行在 Adyen Android 支付终端上

完整收银流程，就在支付终端上。

Mini mPOS 直接运行在 Adyen Android 支付终端上，一台设备即可选购商品、收款、打印或发送电子收据，并通过扫描收据完成退款。无需单独的收银机、平板或应用订阅。更喜欢用平板电脑或手机？Mini mPOS 同样可以在上面运行，配合您的终端或 Tap to Pay 收款。

  • 支持 Adyen 处理的所有币种
  • 内置模拟器，方便试用
  • 支持英语、简体中文和日语

内置于 Adyen 支付终端

安装在终端上后，Mini mPOS 无需其他硬件，也无需运行后端。在平板电脑或手机上，它可配合您的终端或 Tap to Pay 使用。

  • 卡片数据留在 Adyen。Mini mPOS 仅接收掩码卡片信息和支付识别号。
  • 您的业务，就在您的设备上。在设备上管理商品、设置和交易记录，无需云端账户。
  • 柜台内外都适用。适配 AMS1 等小型终端、内置打印机的机型，以及平板电脑和手机。

常见问题

哪种配置适合我？

直接在 Adyen Android 终端完成整个收银流程，或用 Android 平板、手机搭配网络终端、云端终端或 Tap to Pay。参阅要求和配置选择。打印需要打印机，扫描需要摄像头。

费用是多少？

应用免费，采用 MIT 许可证开源。Adyen 的支付处理费用仍适用。

这是 Adyen 的产品吗？

不是。Mini mPOS 并非 Adyen 制作、背书或支持的产品。正式上线前请在 Adyen TEST 环境测试。应用和 Adyen 问题参见获取帮助。

设备共享后台吗？

不共享。商品、设置和交易记录保存在各设备上。二维码传输复制商品和设置，不复制交易记录或持续同步更改。参见设备和数据。

需要服务器或 API 密钥吗？

无需服务器，但所有真实付款配置都需要 Checkout API 凭据。其他密钥取决于支付目标。密钥加密保存在设备上，这与 Adyen 的服务器端建议存在取舍。请按连接设置及其中的安全建议操作。
