安装应用

  1. 在设备上打开直接下载链接，或用相机扫描此二维码：
  2. 在设备上打开 APK，按 Android 提示允许浏览器或文件管理器安装应用。
  3. 打开 Mini mPOS，选择连接 Adyen，点按继续。

重要

每次更新都要使用同一签名来源。终端会拒绝以不同密钥签名的更新。自行构建和签名请参阅 贡献者指南。

连接云端终端

设置助手（推荐）
打开设置助手，选择终端的 TEST 或 LIVE 环境，保持自动，输入 API 密钥，然后扫描二维码。找到多台终端时，请选择您的终端。
手动
  1. 在设置 › 终端中，将支付目标设为通过互联网连接的终端（云端）。在环境 中选择与终端一致的 TEST 或 LIVE。
  2. 在 Adyen API 中输入 Adyen API 密钥和商家账户，LIVE 还需输入 LIVE URL 前缀。点按查找终端设置 以测试 API 访问并选择终端。手动补充缺失的信息。
  3. 检查或输入终端 ID（POIID），点按测试连接。
