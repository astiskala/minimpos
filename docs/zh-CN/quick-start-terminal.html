安装应用

从最新发布版本下载已签名的 minimpos-<version>.apk。

  1. 在商户后台打开 Devices › Terminal apps，上传 APK，并等待状态变为 Ready；参见Adyen 上传指南。用户需要 Merchant POS Terminal Management Admin 角色。
  2. 选择应用，然后选择 Install。选择版本和 Schedule now，选择您的终端并确认 Schedule installation。参见Adyen 计划安装指南。
  3. 保持终端开机并联网。它会在下一次维护呼叫时安装应用，默认三小时内。若想尽快获取，请尝试在终端上打开 Settings › Configuration，输入密码并选择 Update。
  4. 在终端上打开 Mini mPOS，选择扫描设置二维码，点按继续。

重要

每次更新都要使用同一签名来源。终端会拒绝以不同密钥签名的更新。自行构建和签名请参阅 贡献者指南。

连接 Adyen 终端

设置助手（推荐）
打开设置助手，选择终端的 TEST 或 LIVE 环境，保持自动，输入 API 密钥，然后扫描二维码。
手动
  1. 在设置 › 终端 › Adyen API中输入 Adyen API 密钥和商家账户，LIVE 还需输入 LIVE URL 前缀。点按查找终端设置 以测试 API 访问并自动补充共享密钥。
  2. 检查或输入共享密钥，点按测试连接。
