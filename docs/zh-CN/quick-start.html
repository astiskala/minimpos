检查前提条件

请在安装当天之前确认以下内容。设备运行 Mini mPOS，终端读取银行卡；两者可以是同一台设备。

选择设备配置

在 Adyen 终端上运行
一台设备完成整个收银流程。需要 Android 9 或更高版本的 Adyen Android 支付终端。当前型号请参阅 Adyen Android 终端指南。
平板或手机搭配网络终端
柜台推荐方式。Android 9+ 平板或手机与 Adyen 终端位于同一局域网。终端上无需安装 Mini mPOS。
平板或手机搭配云端终端
适用于位于不同网络的设备和终端。两者都需要互联网连接，付款通过 Adyen 发送到终端。
在手机上使用 Tap to Pay
无需独立终端。使用支持近场通信（NFC）的手机和 Adyen Payments 应用，并由 Adyen 支持团队开通。请检查 Adyen 手机要求与 Adyen 支持的国家和付款方式。
  • 打印需要内置打印机的终端。AMS1 终端和 Tap to Pay 手机没有打印机，请改为发送电子收据或分享收据。
  • 扫描条形码、退款二维码或设置二维码需要摄像头。

准备网络

请门店的网络管理员放行以下连接：

互联网（所有真实付款配置）
允许设备和终端通过 TCP 443 向 *.adyen.com 和 *.adyenpayments.com 发起 HTTPS 出站连接。请按域名放行，而不是按 IP 地址，因为 Adyen 的 IP 地址会变化。
局域网（网络终端）
平板或手机必须能通过 TCP 8443 访问终端的 IP 地址。请将两者连接到同一网络，并确保 Wi-Fi 客户端隔离（访客网络常见）不会隔开它们。
电子收据（可选）
允许出站访问您的 SMTP 服务器，通常为 TCP 587（STARTTLS）或 465（SSL/TLS）。

请在路由器中为每台网络终端设置 DHCP 保留，固定其 IP 地址。云端和 Tap to Pay 配置中的平板或手机可使用移动数据，但搭配网络终端时不行。终端本身的网络要求请参阅 Adyen 网络配置指南。

准备 Adyen 凭据

通过 Adyen 验证配置需要有效的测试商家账户、已开通的线下付款服务及商户后台（Customer Area）访问权限。先使用 TEST 凭据及 TEST 终端或 Adyen Payments Test。上线时改用对应的 LIVE 账户、凭据及终端或 Payments 应用。每种真实付款配置都需要 Checkout API 访问权限，包括普通销售。

创建或编辑凭据时，商户后台用户需有 Manage API credentials 或 Merchant admin 权限。这些是用户权限，不是 API 密钥的角色。

请按照 Adyen 支付方式设置指南开通计划接受的 POS 支付方式。Mini mPOS 使用终端已配置的支付方式。

  1. 在商户后台进入 Developers › API credentials，为 Mini mPOS 创建凭据并生成 API 密钥；参见 Adyen API 凭据指南。
  2. 为主 API 密钥启用以下角色：
    • Merchant PAL webservice role — 支付 API 访问
    • Checkout webservice role — API 检查、扣款、金额调整和支付链接
    • Management API — Terminal actions read — 终端访问检查
    • Management API — Terminal settings read and write — 终端设置和共享密钥创建
    • Management API — Terminal settings Advanced read and write — 敏感设置，包括共享密钥
    • Cloud Device API role — 仅云端终端
    每种真实付款配置都会由 Mini mPOS 检查这三个 Management 角色，包括手动输入、云端和 Tap to Pay。凭据须属于您的 Company 账户，并能访问支付目标的商家账户。参见 Adyen API 角色指南。
  3. 可选：如需通过支付链接保存卡片，还需启用 Merchant Recurring role。参见 Adyen 在线支付令牌化指南。
  4. 可选：如需导入收据商家信息，还可添加 Management API — Stores read（门店名称、地址和电话）或 Management API — Account read（仅法人名称）。
  5. 可选：如需商家扫描钱包付款码，添加 Management API — Payment methods read。此只读权限仅影响钱包查询，不影响普通支付。
  6. 记下商家账户。LIVE 还需记下 Developers › API URLs 中的 LIVE URL 前缀。
  7. 在 Devices › Device settings › Integrations › Terminal API › Encryption key 中找到共享密钥（标识符、口令和版本）。实体终端可通过自动设置获取；Tap to Pay 需手动输入。云端终端不使用共享密钥。
  8. 仅限 Tap to Pay：另建一个只有 Adyen Payments app role 的凭据，用于注册手机。

重要

Mini mPOS 没有服务器，API 密钥会加密保存在设备上。请创建仅供 Mini mPOS 使用、只含您的配置所需 API 角色的凭据。设置管理员 PIN，设备丢失时撤销凭据。请阅读安全政策。

说明

Mini mPOS 是独立项目，并非 Adyen 制作、背书或支持的产品。账户及平台操作请遵循链接中的 Adyen 文档。

安装应用

从最新发布版本下载已签名的 minimpos-<version>.apk。

Adyen 终端
  1. 在商户后台上传 APK 并部署到终端；参见 Adyen 应用部署指南。用户需有上传和部署应用的权限。
  2. 在终端上打开 Mini mPOS，选择设置终端。
平板或手机
  1. 在设备上打开 APK，按 Android 提示允许浏览器或文件管理器安装应用。
  2. 打开 Mini mPOS，选择设置终端。

重要

每次更新都要使用同一签名来源。终端会拒绝以不同密钥签名的更新。自行构建和签名请参阅贡献者指南。

连接 Adyen

连接会将 Mini mPOS 与其终端或 Adyen Payments 应用绑定（终端绑定），并检查 Adyen API 密钥。只需按照您的配置操作。每种配置都有两种方式：设置助手（推荐），或在设置 › 终端中手动输入。

在设置 › 终端中，步骤会逐个显示：测试成功后显示下一步。获取设置可从 Adyen 补充终端信息，仅在通过 API 测试后显示。首页会列出仍缺少的项目。

从电脑扫描设置二维码

  1. 在可信电脑上打开设置助手。它离线运行，不发送任何数据。
  2. 选择 Mini mPOS 的运行位置和环境：TEST 或 LIVE。
  3. 选择自动（推荐）只需输入 Adyen API 密钥，其余由设备查询；选择手动则输入全部连接信息。LIVE 环境下两种方式都需要 LIVE URL 前缀。
  4. 可选：包含收据信息和电子邮件（SMTP）设置。
  5. 点击生成二维码。请保持页面打开：页面会显示 12 位传输码。
  6. 在 Mini mPOS 中打开设置 › 终端，点按扫描设置二维码或右上角的二维码图标，扫描全部二维码。
  7. 检查支付目标和环境，输入传输码，点按验证并导入。
  8. 如有提示，选择您的终端，或为 Tap to Pay 注册手机。全部检查通过前不会保存任何内容；通过后应用返回首页，除非需要显示 Tap to Pay 或商家信息提示。

如果导入提示缺少信息，请用手动生成新二维码。如果包含了 SMTP 设置，请发送测试邮件；参见邮件设置。

连接 Adyen 终端

前提条件

  • Mini mPOS 已部署到终端
  • 与终端同一环境的 Adyen API 密钥
  • 终端可访问互联网
设置助手（推荐）
在设置助手中选择在 Adyen 终端上运行、终端的 TEST 或 LIVE 环境及自动。输入 API 密钥，然后扫描二维码。Mini mPOS 会找到本终端的商家账户和共享密钥。
手动
  1. 在设置 › 终端 › Adyen API中输入 Adyen API 密钥和商家账户，LIVE 还需输入 LIVE URL 前缀。点按测试 API，然后可点按获取设置补充共享密钥。
  2. 检查或输入共享密钥，点按测试连接。

终端 ID、地址和环境会自动检测。

绑定同一网络中的终端

前提条件

  • Mini mPOS 已安装在平板或手机上
  • 与终端同一环境的 Adyen API 密钥
  • 设备和终端位于同一网络，且两者之间开放 TCP 8443
设置助手（推荐）
在设置助手中选择在平板电脑或手机上运行、配合同一网络中的终端，以及终端的 TEST 或 LIVE 环境和自动。输入 API 密钥，然后扫描二维码。找到多台终端时，请选择您的终端。
手动
  1. 在设置 › 终端中，将支付目标设为同一网络中的终端。在环境中选择与终端一致的 TEST 或 LIVE。
  2. 在 Adyen API 中输入 Adyen API 密钥和商家账户，LIVE 还需输入 LIVE URL 前缀。点按测试 API，然后可点按获取设置并选择终端。
  3. 检查或输入终端的 IP 地址和终端 ID（POIID）。两者都显示在终端的“Device info”界面。
  4. 检查或输入共享密钥，点按测试连接。

如果终端的环境与您的选择不一致，连接会被拒绝。

连接云端终端

前提条件

  • Mini mPOS 已安装在平板或手机上
  • 与终端同一环境、具有 Cloud Device API role 的 Adyen API 密钥
  • 设备和终端都可访问互联网
设置助手（推荐）
在设置助手中选择在平板电脑或手机上运行、配合通过互联网连接的终端（云端），以及终端的 TEST 或 LIVE 环境和自动。输入具有 Cloud Device API role 的 API 密钥，然后扫描二维码。找到多台终端时，请选择您的终端。
手动
  1. 在设置 › 终端中，将支付目标设为通过互联网连接的终端（云端）。在环境中选择与终端一致的 TEST 或 LIVE。
  2. 在 Adyen API 中输入 Adyen API 密钥和商家账户，LIVE 还需输入 LIVE URL 前缀。点按测试 API，然后可点按获取设置并选择终端。
  3. 检查或输入终端 ID（POIID），点按测试连接。

云端付款到达终端所需的时间可能比本地付款稍长。

设置 Tap to Pay

前提条件

  • Adyen 已为您的公司开通 Tap to Pay 和 Adyen Payments app role；请联系 Adyen 支持团队
  • Mini mPOS 已安装在受支持的手机上
  • Adyen API 密钥、独立的 Payments 应用 API 密钥和共享密钥
  1. 从 Google Play 安装 TEST 用的 Adyen Payments Test 或 LIVE 用的 Adyen Payments，不要同时安装。
  2. 在 Mini mPOS 中打开设置 › 终端，选择在本手机上使用 Tap to Pay。
设置助手（推荐）
在设置助手中选择在手机上运行、使用 Adyen Payments 应用的 Tap to Pay，以及已安装应用的 TEST 或 LIVE 环境。输入 Adyen API 密钥、商家账户、Payments 应用 API 密钥和共享密钥，可选填门店 ID。扫描二维码，并在提示时注册手机。
手动
  1. 在设置 › 终端 › Adyen API中输入 Adyen API 密钥和商家账户。LIVE 还需输入 LIVE URL 前缀。点按测试 API。
  2. 在 Tap to Pay 中输入 Payments 应用 API 密钥，仅具有 Adyen Payments app role。可选填门店 ID。
  3. 点按设置 Tap to Pay，在 Payments 应用中完成注册。
  4. 在 Mini mPOS 中输入共享密钥。

Mini mPOS 会替您在 Adyen 注册手机，无需手动复制注册令牌。共享密钥仍用于加密支付消息，注册不能替代它。

Payments 应用无法进行连接测试，请通过一笔 TEST 付款确认设置。付款时会打开 Payments 应用，完成后返回 Mini mPOS。以后要注销手机，请使用移除本手机。

创建缺失的加密密钥

如果实体终端还没有加密密钥，凭据和账户检查通过后，设置会提供创建加密密钥。

  1. 检查显示的终端 ID 和环境，然后确认。创建期间，请勿在其他位置更改此终端的设置。
  2. 如果连接尚未验证，请更新终端配置；参见密钥设置恢复。
  3. 如果创建中断，请点按继续密钥设置。二维码设置请重新扫描同一组二维码并输入其传输码。

Mini mPOS 会沿用 Adyen 上已有的密钥，绝不替换。云端终端和 Tap to Pay 不使用此选项。

验证 TEST 配置

  1. 在设置 › 终端中，确认环境为 TEST。运行测试 API并确认通过。
    • 实体终端：运行测试连接并确认通过。
    • Tap to Pay：确认手机已在 Adyen Payments Test 中注册。此应用没有连接测试；下方付款用于验证配置。
  2. 在设置 › 支付中检查币种，在设置 › 税中检查税率和价格是否含税。
  3. 在首页点按新建销售，添加自定义商品，然后点按收款。
  4. 点按支付，按照 Adyen POS 测试指南完成一笔成功付款。
  5. 确认结果为批准，且收据上的金额、币种和税额正确。在交易记录中打开销售记录，用其 PSP 识别号核对 TEST 商户后台中的付款。
  6. 为该付款退款，并在 TEST 商户后台确认最终退款结果。已请求退款并非最终确认。
  7. 按照 Adyen POS 测试指南的拒付场景再次测试销售。确认 Mini mPOS 显示拒付，而非批准；参见付款被拒绝。

警告

如果结果未知，请勿再次付款。请先按恢复步骤处理。

接下来，请在使用 Mini mPOS中设置商品、收据和员工权限。

正式上线

  1. 在 TEST 中测试计划使用的可选流程：订金、收据小费、支付链接或扫描钱包。订金和收据小费会冻结资金，直至扣款。请在商户后台确认最终扣款结果。模拟器不能替代 Adyen 测试。
  2. 测试计划使用的收据交付方式：用实体打印机打印、发送测试邮件或分享收据。
  3. 设置管理员 PIN，需要时另设经理 PIN；参见员工权限。
  4. 改用 LIVE 终端或 LIVE 版 Payments 应用及 LIVE 凭据。网络或云端终端请在环境中选择 LIVE。输入 LIVE URL 前缀；参见 Adyen LIVE 端点指南。
  5. 在设置 › 终端中运行测试 API并确认通过。确认环境为 LIVE。
    • 实体终端：运行测试连接并确认通过。
    • Tap to Pay：确认手机已在 LIVE 版 Adyen Payments 应用中注册。此应用没有连接测试。

警告

在 TEST、LIVE 和模拟器之间切换会删除设备上的全部交易记录，包括未完成付款的恢复数据。请先处理需处理中的所有付款。

日常检查和对账请参阅日终结算。应用或 Adyen 问题请参阅支持范围。

试用模拟器

无需 Adyen 账户或终端即可体验 Mini mPOS，不会扣款。

  1. 在 Android 9+ 手机或模拟器上安装应用。
  2. 在欢迎界面选择使用示例数据试用模拟器。其他选项为从另一台设备设置（导入设置二维码）和设置终端。
  3. 在设置 › 模拟器中选择支付结果、延迟以及是否有打印机。

示例商品和交易记录会标为演示。示例计入演示每日合计和报告，并非真实付款。在设置 › 数据中可添加示例数据或删除示例数据；删除会保留您自己的商品、交易记录和设置。离线演示链接请参阅支付链接。要从源码构建，请参阅贡献者指南。
