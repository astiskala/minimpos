设置助手

在电脑上设置设备

在终端键盘上输入冗长的 API 密钥既费时又容易出错。请在这里对照商户后台填写，再以二维码形式扫描到 Mini mPOS 中。

设置助手需要 JavaScript。请为此页面启用 JavaScript，或按照快速入门指南在应用中输入。

1. Mini mPOS 在哪里运行，支付发往哪里？
2. 使用哪个 Adyen 环境？

应用连接时会自动判断环境；此选项只用于打开下方对应的商户后台，并决定是否要求填写 LIVE URL 前缀。

同一网络中的终端

两者都可在终端的 Device info（设备信息）界面查看。

云端终端

留空则可在应用中从已连接的终端中选择。

共享密钥

在商户后台的 Devices › Device settings › Terminal API 中的 Encryption key 下（点击铅笔图标查看）。

Checkout API

在 Developers › API credentials 中创建具有 Checkout webservice role 的具有 Cloud Device API role 和 Checkout webservice role 的 API 凭据，并生成其 API 密钥。

LIVE URL 前缀

见 Developers › API URLs。

Tap to Pay

仅具有 Adyen Payments app role 的 API 凭据，该角色需由 Adyen 支持团队开通；参见 Adyen 的 Payments 应用指南。

如只为一家门店设置本手机：填写 Devices › Stores 中该门店的 ID（不是其 reference）。

用设备扫描这些二维码

  1. 在设备上的 Mini mPOS 中打开设置 › 数据 › 从另一台设备设置。
  2. 用摄像头扫描下方的二维码。有多个二维码时会自动轮换。
  3. 输入传输码，然后点击导入。设备上只会更改您在这里填写的内容。
  4. 在设置 › 终端中检查连接。使用 Tap to Pay 时，请在那里点击设置 Tap to Pay。

须知

  • 数据不会离开此页面。二维码在您的浏览器中生成；页面不会发送或保存任何内容。完成后请关闭页面。
  • 密钥经过加密。二维码中的密码和密钥使用传输码加密，传输码只在这里显示，因此仅拍摄二维码不会泄露它们。
  • 请保密传输码。同时持有二维码和传输码的人可解密密钥。按需生成新传输，完成后关闭页面。
  • 仅设置连接。不复制商品、收据或其他业务设置。请用应用中的共享至另一台设备复制这些设置。
  • 需要完整说明？参阅快速入门；导入或连接问题参见故障排查。
