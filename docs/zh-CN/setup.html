设置助手

在电脑上设置设备

在终端键盘上输入冗长的 API 密钥既费时又容易出错。请在这里对照商户后台填写，再以二维码形式扫描到 Mini mPOS 中。

初次使用 Mini mPOS？填写前请先选择配置方式并准备凭据。

商户后台链接会在新标签页中打开，方便保留此表单。

设置助手需要 JavaScript。请为此页面启用 JavaScript，或按照快速入门指南在应用中输入。

1. Mini mPOS 在哪里运行，支付发往哪里？
2. 使用哪个 Adyen 环境？

对于网络或云端终端，此选项会作为应用环境导入。在 Adyen 终端上运行或使用 Tap to Pay 时，环境由本设备或已安装的 Payments 应用决定。请使用对应环境的凭据；此选项也会切换商户后台链接和 LIVE URL 前缀字段。

3. 如何设置？

LIVE 环境下两种方式都需要 LIVE URL 前缀。无法自动查询或结果不完整时，可在设备上补充信息，或在此选择手动。

请先遵循Tap to Pay 准备步骤并安装 Payments 应用。两种方式都需商家账户和独立的 Payments 应用 API 密钥进行注册。自动方式在注册后使用 Adyen API 密钥查询共享密钥，手动方式在此填写。无需复制注册令牌。

Adyen API 密钥

在 Developers › API credentials 中创建凭据并生成 API 密钥。云端付款需添加 Cloud Device API role。此密钥用于 Checkout 操作，而非 Payments 应用注册。自动设置需要设置指南中的查询角色。设置助手保持离线；查询在导入后的设备上执行。

Adyen 账户
同一网络中的终端

两者都可在终端的 Device info（设备信息）界面查看。

云端终端

可在终端的 Device info 界面或商户后台的 Devices › Terminals 中查看。

共享密钥

在商户后台的 Devices › Device settings › Terminal API 中的 Encryption key 下（点击铅笔图标查看）。

LIVE URL 前缀

见 Developers › API URLs。

Tap to Pay

用于手机注册的独立 API 凭据，仅具有 Adyen Payments app role；参见 Adyen 的 Payments 应用指南。

如只为一家门店设置本手机：填写 Devices › Stores 中该门店的 ID（不是其 reference）。

电子收据（可选）

两种设置方式均可使用。请先检查邮件设置及服务商要求；设置助手无法测试服务器。

SMTP 服务器

只更改已填写字段。可选项留空会保留已保存值；如需清除，请在“设置 › 电子邮件”中操作。密码与其他秘密信息一同加密。

用设备扫描这些二维码

  1. 在 Mini mPOS 中打开设置 › 终端，点按快速设置下的扫描设置二维码，或右上角的二维码扫描图标。无需先选择支付目标或环境。
  2. 用摄像头扫描下方的二维码。有多个二维码时会自动轮换。
  3. 检查支付目标和环境，尤其是 LIVE。输入传输码，然后点击导入。设备上只会更改您在这里填写的内容。
  4. 自动设置时点击继续设置：设备会匹配本终端或提供终端列表供选择。请检查信息并补充缺失项。手动设置时点击检查设置。在设置 › 终端中测试连接及 API 密钥。使用 Tap to Pay 时，请在那里点击设置 Tap to Pay，应用随后查询商家或门店的共享密钥。无法查询时可手动输入；查询共享密钥可重试查询，无需重新注册。

如包含 SMTP 设置，请检查设置 › 电子邮件并发送测试邮件。邮箱采集与自动发送需单独配置，参见邮件设置。

导入后请完成第一笔 TEST 付款。

须知

  • 数据不会离开此页面。二维码在您的浏览器中生成；页面不会发送或保存任何内容。完成后请关闭页面。
  • 密钥经过加密。二维码中的密码和密钥使用传输码加密，传输码只在这里显示，因此仅拍摄二维码不会泄露它们。
  • 请保密传输码。同时持有二维码和传输码的人可解密密钥。按需生成新传输，完成后关闭页面。
  • 仅设置连接及可选 SMTP 字段。不复制商品、收据布局或其他业务设置。请用应用中的共享至另一台设备复制这些设置。
