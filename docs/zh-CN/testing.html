验证 TEST 配置

  1. 在设置 › 终端中，确认环境为 TEST。完成最后的测试连接步骤，验证 API 访问和受支持的连接检查。
    • 实体终端：运行测试连接并确认通过。
    • Tap to Pay：确认手机已在 Adyen Payments Test 中注册。连接检查仅验证设置，不支持终端诊断。使用下方测试付款检查支付行为。
  2. 在设置 › 支付中检查币种，在设置 › 税中检查税率和价格是否含税。
  3. 在首页点按新建销售，添加自定义商品，然后点按收款。 将自定义商品命名为“测试销售”，输入测试卡场景要求的金额。
  4. 点按支付，按照 Adyen POS 测试指南完成一笔成功付款。
  5. 确认结果为批准，且收据上的金额、币种和税额正确。在交易记录中打开销售记录，用其 PSP 识别号核对 TEST 商户后台中的付款。
  6. 为该付款退款，并在 TEST 商户后台确认最终退款结果。已请求退款并非最终确认。
  7. 按照 Adyen POS 测试指南的拒付场景再次测试销售。确认 Mini mPOS 显示付款被拒绝；参见付款被拒绝。

警告

如果结果未知，请勿再次付款。请先按恢复步骤处理。

为 LIVE 收款做好准备

  • 设置商品价格前，确认币种和税率。
  • 核对商户信息，并测试计划使用的每种收据交付方式。
  • 设置员工 PIN，并确认需要经理批准的操作。
  • 仅启用并测试计划使用的可选支付功能。

正式上线

警告

在 TEST、LIVE 和模拟器之间切换会删除设备上的全部交易记录，包括未完成付款的恢复数据。请先处理需处理中的所有付款。

  1. 改用 LIVE 终端或 LIVE 版 Payments 应用及 LIVE 凭据。网络或云端终端及 Tap to Pay 请在环境中选择 LIVE。输入 LIVE URL 前缀；参见 Adyen LIVE 端点指南。Tap to Pay 需要在所选环境中重新注册。
  2. 在设置 › 终端中，确认环境为 LIVE。完成最后的测试连接步骤，验证 API 访问和受支持的连接检查。
    • 实体终端：运行测试连接并确认通过。
    • Tap to Pay：确认手机已在 LIVE 版 Adyen Payments 应用中注册。连接检查仅验证设置，不支持终端诊断。

日常检查和对账请参阅日终结算。

验证首笔 LIVE 付款

请使用实际支付目标和收据交付方式，按照 Adyen 的 LIVE 测试指南验证。在 LIVE Customer Area 中核对金额、币种、收据和付款。仅通过连接检查并不能证明付款功能正常。
