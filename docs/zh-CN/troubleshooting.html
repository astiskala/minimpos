付款或退款显示“结果未知”

警告

不要仅因应用没有响应就再次收款或退款。请求可能已到达 Adyen。

  1. 打开交易记录，筛选需处理，打开原付款或退款。
  2. 点按重新查询结果。对于终端，应用会向终端查询该交易的结果。
  3. 如果结果仍未知，请按识别号、时间和金额在商户后台 › Payments › Payment list中查找该付款。确认后再决定下一步。

崩溃或重启后，中断的操作会以未知状态保留在交易记录中。不要通过清除应用数据来移除它。

使用 Tap to Pay 时，重新查询结果先使用已收到的迟到回复，再向所选 Payments 应用查询原始结果。状态查询需要 1.8.0 或更高版本；请向 Adyen 确认测试版使用权限。未收到回调或返回 NotFound 时，结果仍未知。再次收款前，请检查商户后台 › “Payments” › “Payment list”。

付款被拒绝或未处理

结果界面会显示状态、Adyen 给出的原因和建议。请按建议操作：

“请勿使用此卡重试。请购物者使用其他卡片或付款方式。”

解决请购物者改用其他卡片或付款方式。购物者的银行可以说明拒绝原因； Adyen 拒绝原因解释了显示的原因。

原因

发卡行因不会改变的原因拒绝了此卡（如卡片被冻结、受限或疑似欺诈），或此卡不允许用于本次付款。

“可以重试。”

解决点按重试，或请购物者换一张卡。

原因

付款被取消、PIN 输入错误，或卡片因可能不会重复的原因被拒绝（如余额不足）。

“终端正在处理其他交易或显示管理菜单。”

解决完成另一笔付款或退出菜单后重试。如果界面提供取消终端当前交易，仅在确实要停止该交易时使用，并在重试前查询其结果。

原因

终端正在处理另一笔付款或显示管理菜单。

“终端暂时不可用。”

解决稍候，确认终端已开机并已连接，然后重试。参见网络中断。

原因

终端或其读卡器暂时不可用。

“终端未接受请求。重试前，请检查终端设置。”

解决在设置 › 终端中运行测试；参见终端绑定和设置。如果测试通过，请联系 Adyen 检查终端配置。

原因

终端拒绝了所发送的请求，通常是设置问题。

“终端或您的 Adyen 账户不支持此请求。请联系 Adyen 支持团队确认已开通，然后重试。”

解决请联系 Adyen 支持团队确认商家账户已开通该功能。对于 Tap to Pay，请确认除 Adyen Payments App role 外，也已开通 Tap to Pay on Android。然后重试。

原因

终端或 Adyen 不提供此付款所需的功能，通常是因为账户尚未开通。

“请勿再次收款：此次支付已成功。”

解决请勿再次收款。如果购物者不应付款，请为其退款。

原因

虽然终端报告了取消，但付款已获批准。

可选终端功能不可用或总额存在差异

终端功能未显示或被拒绝

检查收款目标和 Adyen 功能，刷新终端设置，并确认 API 角色和 Adyen 账户配置。本地结账开关不会在 Adyen 开通服务。Tap to Pay 不提供实体终端流程。小费请比较终端小费和 收据小费。

只有部分金额获批

从结果页面按部分付款流程操作。不要再次收取原合计金额。若后续付款结果未知，请先 查询结果再继续收款。

终端总额与 Mini mPOS 不符

按终端对账 说明检查终端周期、使用同一终端的其他设备、本地保留记录和未解决交易。结束周期不会修复差异，也不代表结算完成。

离线销售缺少 PSP 识别号或仍有未确认批次

按离线付款检查步骤操作。恢复终端与 Adyen 的连接，并在商户后台核对上传的付款。不要仅因缺少 PSP 识别号就再次收取已批准的付款。

返回目录

没有扫描钱包按钮或扫描失败

没有扫描钱包按钮

打开设置 › 终端，点按刷新扫码钱包。成功查询后没有符合条件的 POS 钱包时，按钮会保持隐藏。核对终端门店、当前币种和API 密钥角色。Tap to Pay 和预授权不提供此功能。

钱包查询报错

错误仅显示在设置中，不会阻止银行卡付款。请在设置中修正凭据、环境或读取权限后 刷新。临时失败会保留最近验证的钱包。

付款码无效或未收到付款码

请使用购物者的付款码，而非个人资料、设置转移或收据二维码，并选择正确的 钱包。终端扫描 30 秒后结束：点按重新扫描或使用摄像头。

保存被拒绝或未创建令牌

即使未保存令牌，已批准的付款仍然有效。被拒绝后，关闭保存卡片， 如有需要再重新扫描。结果未知时请查询原交易。

请参阅钱包支付步骤。

返回目录

终端绑定或设置失败

先查看首页的提示，再打开设置 › 终端，完成最后的测试连接步骤，验证 API 访问和此集成支持的连接检查。网络和云端设置使用 查找要设置的终端测试 API 访问并列出终端；设备本机终端和 Tap to Pay 提供测试 API。完整步骤请参阅 连接 Adyen。

所有集成都可打开设置 › 帮助与故障排除 › 故障排查详情。结果包括设置缺失项、API 访问、受支持的连接检查、时间和设备信息，并标明不支持的检查。这些检查不保证付款、退款或打印成功，也不会发起付款、注册手机或更改密钥。使用分享已脱敏的报告 分享显示的详情：保留商户、终端、安装实例和凭据 ID；排除秘密值、非结构化消息和顾客数据。

首页提示“尚未完成收款设置”

解决点按完成收款设置。在设置 › 终端中填写缺少的信息或重新输入密钥，然后点按测试连接。

原因

必填字段为空、本设备无法读取已保存的密钥，或设置更改后尚未通过连接测试。在此之前，支付、退款、打印和其他 Adyen 操作会显示此说明，而不会执行。

API 测试失败，或设置提示访问问题

解决按照凭据要求检查凭据的角色和访问范围。LIVE 请检查 LIVE URL 前缀。

原因

API 密钥、商家账户或 LIVE URL 前缀有误，缺少角色，或凭据属于其他 Company 账户或环境。

“商家账户与终端当前分配的账户不一致。”

解决输入终端所分配的商家账户，或在商户后台重新分配终端。

原因

终端在 Adyen 中被分配到其他商家账户。

Adyen 终端或网络终端的连接测试失败

解决将共享密钥的标识符、口令和版本与商户后台核对。网络终端还需在终端的“Device info”界面核对 IP 地址和 POIID。

原因

共享密钥不一致，或 IP 地址、终端 ID（POIID）已过时。

连接因环境不一致被拒绝

解决网络或云端终端及 Tap to Pay 请在设置 › 终端中检查环境。在 Adyen 终端上运行时，请使用正确环境的设备。

原因

混用了 TEST 和 LIVE：终端、账户和 API 密钥必须属于同一环境。

无法连接云端终端

解决确认终端已开机并在线，再检查 POIID 和凭据的角色。

原因

终端离线、POIID 有误，或 API 密钥缺少 Cloud Device API role。

未安装所选环境的 Payments 应用

解决检查设置 › 终端 › 环境，从 Google Play 安装对应应用。两者可以同时安装。完成注册，输入对应的共享密钥，再完成一笔 TEST 付款。

原因

未安装所选 TEST 或 LIVE 环境的 Payments 应用。

Tap to Pay 在出示卡片前返回 UnavailableService

Payments 应用无法完成请求。此通用错误不能证明 Adyen 服务中断或缺少客户端密钥。

在设置 › 终端中运行测试连接。要查看简洁的检查结果表格或分享脱敏报告，请展开设置 › 帮助与故障排除 › 故障排查详情。

设置 Tap to Pay会使用主 API 密钥自动创建注册凭据和客户端密钥。如被拒绝，请检查 所需角色。新密钥需要几分钟生效，然后再次测试连接。如仍无法恢复，请稍后重试或请 Adyen 支持团队检查对应的 TEST Customer Area 或 LIVE Customer Area。参见 Adyen Payments 应用要求 。

客户端密钥必须属于注册所用的同一凭据。

寻求帮助时，请使用分享已脱敏的报告。

“新密钥已保存。请更新此终端的配置”

解决在终端上打开 Admin menu › Config › Update，然后返回 Mini mPOS 点按再次检查。如果创建中断，请点按继续密钥设置，不会创建第二个密钥。参见密钥创建及 Adyen 配置更新指南。

原因

加密密钥已在 Adyen 创建，但终端尚未加载。

旧付款的操作被阻止

解决恢复处理该付款时的配置，或在商户后台处理。不要用另一个账户处理它。

原因

该付款之后更换了商家账户、环境或终端。

返回目录

连接中断或终端未响应

重要

如果连接中断时有付款正在进行，再次收款前请查询其结果。

“终端未响应”，或网络终端时好时坏

解决

  1. 在终端的“Device info”界面查看 IP 地址，并在设置 › 终端中更新。
  2. 将设备和终端连接到同一网络。避免使用访客 Wi-Fi，它通常会隔离设备。
  3. 请网络管理员放行两者之间的 TCP 8443，并为终端保留 IP 地址；参见网络要求。
原因

终端的 IP 地址已变化、设备换到了其他网络，或网络阻止了连接。

所有配置的付款或 API 测试都失败

解决检查互联网连接，并确认已放行到 Adyen 域名的 TCP 443 HTTPS 连接。

原因

设备或终端无法访问互联网，或防火墙阻止了 Adyen。

云端付款超时

解决检查终端的 Wi-Fi、以太网或移动数据，然后运行测试连接。

原因

终端失去了互联网连接。

返回目录

扣款或调整失败或结果未知

在交易记录中打开原记录并查看原因。如果缺少 Checkout API 设置，请补全；如果账户或环境已更改，请恢复原配置。

扣款失败或扣款结果未知

解决点按重试扣款。它会安全地重新发送同一扣款请求；不要创建新的付款。

金额调整未解决

解决使用相同金额重试。不同金额是独立请求，可能需先解决第一个请求。

小费未保存

解决输入较少的小费，或点按无小费。

原因

小费超过 20% 时，发卡行拒绝增加冻结金额。

已请求扣款或已请求退款一直不变

解决请在商户后台确认最终结果。

原因

这表示 Adyen 已接受请求。Mini mPOS 没有服务器，无法收到最终确认。

冻结金额会到期，请及时处理。正常步骤请参阅订金和收据小费。

返回目录

付款链接未显示或不更新

结账时没有创建付款链接

解决在设置 › 终端中完成 Checkout API 设置。链接仅用于销售。模拟器无需设置即可提供演示链接。

原因

Checkout API 设置未完成，或本次结账是预授权或收据小费。

已支付的链接仍显示待支付

解决在交易记录中打开该记录，点按查询支付状态。

原因

应用仅在链接界面打开时查询。

创建链接时中断

解决打开原记录并点按查询支付状态，会使用原请求重试；不要仅为获取链接创建另一笔销售。

已支付的链接请在商户后台 › Payments › Payment list中退款。

返回目录

打印机或电子收据无法使用

无法打印，或没有打印收据

解决

  1. 在设置 › 关于中确认打印机显示可用。否则请在设置 › 终端中运行测试连接。
  2. 在设置 › 收据中将打印机设为自动检测，并检查自动打印。
  3. 点按打印测试收据。如果仍无法打印，请检查终端的收据纸卷。
原因

终端没有打印机、未检测到打印机，或连接中断。AMS1 终端和 Tap to Pay 手机没有打印机。

排版被截断或换行异常

解决在设置 › 收据中更改每行字符宽度，然后打印测试收据。

测试邮件发送失败

解决在设置 › 电子收据中检查服务器、端口、STARTTLS 或 SSL/TLS、用户名和密码。服务商可能要求开通 SMTP 或使用应用密码；参见邮件设置。

原因

服务器、端口、安全方式或密码有误，或服务商禁止 SMTP 或密码登录。

测试邮件正常，但购物者收不到收据

解决在设置 › 电子收据中检查何时询问电子邮件以及是否自动发送收据。

标志没有打印

在设置 › 收据中检查预览并打印测试收据。如果终端拒绝打印标志，Mini mPOS 仍可打印正文，并在首次拒绝时显示提示。纸张问题、没有打印机或打印请求没有回应时会停止打印。请参阅收据标志设置，尝试更简单的图片或移除标志。

返回目录

PIN 和设置传输问题

员工忘记了经理 PIN

解决管理员可在设置 › 安全中更换或移除。管理员 PIN 和经理 PIN 保护不同的操作，其中一个不会解锁另一个。

忘记了管理员 PIN

原因没有 PIN 恢复功能。

如需在没有管理员 PIN 的情况下重新开始，请按照存储恢复步骤操作。重置前请阅读数据丢失警告。

传输码被拒绝，或导入后缺少密钥

解决使用与这些二维码一起显示的传输码，而不是新生成的码。每次传输都需要传输码。错误的码或留空都不会导入任何内容。复制后，请检查新设备的支付目标和凭据；参见 更多设备。

原因

传输码与这些二维码不匹配，或未填写。

各 PIN 保护的操作请参阅员工 PIN。

返回目录

无法读取或保存已存储的设置或凭据

Mini mPOS 会停止运行，而不是替换无法读取的设置或凭据，以保留文件，包括未完成设置或付款的恢复记录。

警告

清除存储空间或卸载会删除全部本地商品、设置、凭据、PIN、交易记录和未完成操作的恢复记录。设置传输无法恢复交易记录或这些恢复记录。重置不会撤销已发送到 Adyen 的付款、退款或捕获。

  1. 重启设备并重新打开 Mini mPOS。如果设备存储空间已满，请先清理 Mini mPOS 以外的空间。仅清除应用缓存不会重置已保存的设置。
  2. 重置前，请保留所需记录，并处理未完成的付款、退款、捕获和调整。如果无法打开应用，请在 Customer Area 确认结果；参见结果未知 。如果结果仍不确定，请保留应用数据并先与 Adyen 核对。不要因为无法打开应用就再次发送操作。
  3. 如果问题持续，且您接受丢失全部本地数据，可重置 Mini mPOS。在手机或平板电脑上，打开 Android 设置 › 应用 › Mini mPOS › 存储和缓存 › 清除存储空间 （名称因设备而异），或卸载 Mini mPOS 并从最新版本 重新安装。在 Adyen 终端上，请由终端应用管理员安排重置或卸载后重新安装；参见 Adyen 应用部署指南。
  4. 重新设置 Mini mPOS，或导入可信的设置传输，然后完成测试连接，再进行真实付款。参见连接 Adyen 。

覆盖安装更新不会重置应用存储。如果错误再次出现，请在 GitHub 报告应用问题，不要附上已保存的配置文件或凭据。

返回目录

终端无法安装应用

INSTALL_PARSE_FAILED_NO_CERTIFICATES

解决上传最新发布版本中已签名的 minimpos-<version>.apk。

原因

APK 未签名。

INVALID_SIGNING_CERTIFICATE_MISMATCH

解决保持原签名来源。确需更换时，请向 Adyen 支持团队咨询移除旧版本。

原因

APK 的签名密钥与之前上传的不同。

不支持的 Android 版本

解决使用受支持的终端；参见安装。

Mini mPOS 需要 Android 9 或更高版本；旧款 S1E 运行 Android 7.1。

出现错误消息

每条消息都会说明问题及需要检查的内容。括号中的详细信息（如 IP 地址、HTTP 状态或 Adyen 的原文）有助于 Adyen 支持团队排查，寻求帮助时请一并提供。如果有付款正在进行，请先 查询其结果，再处理其他问题。

错误消息
“无法连接终端。请确认终端已开机、位于同一网络，且 IP 地址正确。”

解决请参阅连接中断。

原因

Mini mPOS 无法连接到所保存 IP 地址上的网络终端。

“此地址不是所选环境中的 Adyen 终端。请检查 IP 地址以及 TEST 或 LIVE。”

解决在终端的“Device info”屏幕上核对 IP 地址，并检查设置 › 终端中的环境。

原因

该地址有设备响应，但不是所选环境中的 Adyen 终端：该地址已分配给其他设备，或混用了 TEST 和 LIVE。

“终端拒绝了共享密钥。请在终端设置中检查密钥标识、版本和密码短语。”

解决与商户后台中的设置进行核对，或重新设置密钥。

原因

共享密钥的标识、版本或密码短语与终端上的不一致。

“无法验证终端的回复。请在终端设置中检查共享密钥。”

解决再次收款前请先查询结果，然后修正共享密钥。

原因

终端使用了不同的共享密钥回复，因此请求可能已送达终端。

“终端未连接到 Adyen。请确认终端已开机并已联网。”

解决检查终端的 Wi-Fi、以太网或移动数据，然后运行测试连接。

原因

云终端已关机或没有互联网连接。

“Adyen 未接受 API 密钥。请在终端设置中检查。”

解决重新输入密钥，并对照凭据要求检查。

原因

API 密钥有误、已被撤销，或属于另一个环境。

“此 API 密钥缺少所需角色或对此商户账户的访问权限。请在商户后台检查 API 凭据。”

解决在商户后台中添加该角色或账户访问权限；请参阅凭据要求。

原因

凭据缺少某个角色或对此商户账户的访问权限。已知缺少的角色时，括号中会注明。

“Adyen 繁忙或暂时不可用。”

解决稍候片刻再重试。如果是付款、扣款或付款链接，请先查询其结果。

原因

Adyen 正在限制请求，或暂时不可用。

“未在规定时间内收到响应。”

解决请查询结果。在确认结果前，请勿再次收款。

原因

请求已发出，但未收到响应，因此结果未知。

“Payments 应用的结果仍未知。请更新所选 Payments 应用，向 Adyen 确认状态查询权限，并在再次收款前检查商户后台。”

解决再次收款前，请在商户后台中查找此次付款。

原因

Tap to Pay 结果恢复.

“无法打开 Adyen Payments 应用。请确认已安装该应用。”

解决安装与您的环境对应的 Payments 应用，然后重试。请参阅连接 Adyen。

原因

Payments 应用未安装或已被移除。

“邮件服务器未接受用户名或密码。请在“设置 › 电子收据”中检查。”

解决更正后发送一封测试邮件。

原因

SMTP 用户名或密码有误，或邮件服务商要求使用应用专用密码。

“此设备的安全存储无法使用。请重试或重启设备。”

解决如果重启后问题仍然存在，请重新输入密钥和密码。

原因

Android 密钥库无法加密或读取已保存的密钥信息。
