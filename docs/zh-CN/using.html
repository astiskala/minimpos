准备商品、税费和员工权限

真实收款前，请完成连接 Adyen 的设置。需要支付终端或 Adyen Payments 应用。然后一次性准备商品、税费和员工权限。

设置币种和税费

  1. 在设置 › 支付中选择商家账户接受线下付款的币种。
  2. 在设置 › 税中检查税率、价格含税还是结账时加税，以及新商品的默认税率。

每个商品都有税率，不征税的商品使用 0% 税率。关闭收取税费会停止征税，但保留税率。

重要

更改币种会保留价格中的数值，不会按汇率换算。更改后请检查商品价格。

添加商品

  1. 打开商品，点按 +。
  2. 输入名称、价格和税率。可选添加分类和条形码（输入或扫描）。
  3. 订金商品请开启预授权商品，使其只出现在预授权中。

设置员工 PIN

  1. 在设置 › 安全中点按设置管理员 PIN。它保护设置和商品管理。选择应用多久后重新锁定。
  2. 可选：点按设置经理 PIN。之后退款、取消、扣款、金额调整和录入小费都需要输入它。

如需更换或移除管理员 PIN，请使用更改管理员 PIN或移除管理员 PIN；移除它也会移除经理 PIN。多次输错会暂时锁定 PIN 输入。忘记 PIN 时请参阅 PIN 问题。

银行卡收款

  1. 在首页点按新建销售。点按商品、点按扫描条码，或添加自定义商品。
  2. 点按收款。核对商品、税费和合计，并填写识别号或邮箱字段。
  3. 点按支付。终端（或 Tap to Pay 的 Adyen Payments 应用）会提示顾客付款。
  4. 等待结果。结果显示前请勿开始另一笔付款。
  5. 通过打印收据、发送电子收据或分享收据向顾客提供收据（已自动发送时除外）。

说明

银行卡由终端读取，Mini mPOS 不会获得完整卡号信息。根据终端和商家账户的不同，顾客可插卡、挥卡，或用手机、手表感应付款。非接触式（NFC）付款时，卡片或手机须保持靠近非接触标志，直到终端确认。使用 Tap to Pay 时，请按 Adyen Payments 应用中的说明操作。

警告

结果未知不表示付款失败。再次收款前，请查询原付款。

客户识别号、保存卡片和小费均可选；参见识别号和保存卡片。如需让顾客在自己的手机上付款，请使用支付链接。付款被拒绝时，请参阅付款被拒绝。

扫描顾客的钱包付款码

在销售结账时使用扫描钱包读取顾客钱包应用中的付款码。这与扫描商品条码或退款收据不同。此功能需要实体支付终端，不适用于 Tap to Pay；钱包查询需要只读权限。

  1. 核对合计和结账字段后点按扫描钱包。若已选择收据小费，请确认不使用该选项：钱包会立即收取合计，而不是进行预授权。
  2. 选择顾客的钱包。只有一个可用钱包时会自动选择。仅显示单独配置的钱包；Alipay+ 不代表 GCash、DANA、Kakao Pay 或 TrueMoney 已分别启用。
  3. 终端确认配备内置扫描器时，按下该终端的扫描按钮。它可能是网络或云端终端，而非运行 Mini mPOS 的设备。要改用设备摄像头，请点按使用摄像头。
  4. 扫描顾客的付款二维码或付款条码。一个有效扫描会立即开始支付。等待普通支付结果并提供收据。

取消会保留购物车和结账字段。无效码不会付款：请重新扫描或更换钱包。终端扫描最多持续 30 秒；之后可点按重新扫描或使用摄像头。离开应用会停止扫描，返回后需明确重新开始。不能手动输入或粘贴付款码。

顾客识别号和授权允许时，保存卡片会尝试保存支付信息，是否支持取决于钱包。只有返回保存的支付令牌才表示成功保存；没有令牌的已批准付款仍然有效。请参阅钱包查询和支付问题；不要通过再次扫码替代结果未知的原付款。

请使用 Adyen 钱包指南和 Adyen PayPal 和 Venmo 指南核对钱包开通情况和 TEST 行为。

退款或撤销付款

退款
适用于已扣款的付款，退还全部或部分金额。
撤销（取消）
适用于尚未扣款的冻结付款：订金点按取消预授权，待填写小费的销售点按取消支付。这会释放冻结金额。

退款步骤：

  1. 在首页点按退款并扫描收据上的退款二维码，或在交易记录中打开原销售。
  2. 选择全额、指定金额或按商品退款。按商品退款要求本设备保留原销售。
  3. 确认退款，如有提示则输入经理 PIN。

每笔退款都关联原付款，不支持无原付款的退款。已支付的支付链接请在商户后台退款。

重要

已请求退款表示 Adyen 已收到请求，不表示顾客已收到款项。请在商户后台确认最终结果。退款结果未知时，重试前请先查询。

打印、发送电子收据或分享收据

在付款结果或交易记录中点按打印收据或发送电子收据。平板和手机还可点按分享收据，通过 Android 分享菜单发送图片。打印需要配有打印机的终端。

自定义并测试收据

  1. 在设置 › 收据中填写商家信息、抬头和页脚。也可点按从 Adyen 导入商家信息，从 Adyen 门店补充空白字段。
  2. 选择支付后自动打印、何时打印商家联，以及是否显示退款二维码。
  3. 点按打印测试收据并检查打印效果。屏幕预览无法显示打印机的确切排版。

其他选项：

显示税额
显示总额中包含或另行加收的税额，不改变实际收取的税额。
显示税额明细
按税率列出税额。价格含税时，显示所含税额需要开启此项。
按税率显示应税金额
按税率汇总商品金额，包括 0%。
显示识别号
默认开启。打印商家识别号及已输入的客户识别号，便于将收据与付款对应。
标记的税率（%）
用商品标记及其说明标出该税率的商品。留空则不标记。
每行字符宽度
默认为 32，适用于较窄的收据纸卷。请通过测试打印选择适合打印机的宽度。

设置语言

应用支持英语、简体中文和日语。Android 12 及更早版本跟随设备语言；Android 13 及更高版本请在 Android 的单应用语言设置中选择。Adyen 的银行卡收据行跟随终端自身的收据语言。

设置电子收据

  1. 打开设置 › 电子邮件（SMTP）。选择服务商，或填写 SMTP 服务器、端口、发件人和登录信息。使用 STARTTLS 或 SSL/TLS。
  2. 发送测试邮件。
  3. 在设置 › 支付 › 电子收据中选择何时询问顾客邮箱，以及是否自动发送收据。

请按服务商说明开通 SMTP 并获取正确的密码：

  • Gmail
  • Microsoft 365
  • iCloud Mail
  • Yahoo Mail
  • Fastmail
  • Zoho Mail
  • Proton Mail

收据无法打印或发送时，请参阅打印机和邮件问题。

查询付款并完成每日平账

交易记录按日列出付款和退款，并显示每日合计。

  • 按销售、待填写小费、预授权、退款或需处理筛选，并用付款方式筛选卡品牌或钱包。
  • 可按识别号、授权码、客户识别号或邮箱、卡号后四位、品牌、钱包或确切金额搜索。每个词都需匹配：visa 34 可查找金额为 34 的 Visa 付款。

屏幕上的合计受搜索和筛选影响。冻结的付款（如订金和收据小费）在扣款被受理当日计入销售。

每日平账

  1. 打开交易记录，筛选需处理并逐一处理；参见结果未知。
  2. 检查待填写小费和预授权筛选。录入小费，并在冻结到期前为订金扣款或取消。
  3. 点按日期旁的打印图标，打印本地每日汇总。
  4. 与商户后台中的 Adyen 报告对账；参见 Adyen 结算对账指南。

汇总忽略筛选，涵盖整日的销售、已含小费、已受理退款、净额、新增冻结和未解决操作，按币种分列。TEST 和模拟器活动会标明。已支付的支付链接和日期未知的扣款会作为无日期活动单独列出。

重要

本地每日汇总只包含本设备保存的付款，不是 Adyen 的最终结算，也不包含其他设备。以商户后台为准。

警告

在 LIVE、TEST 和模拟器之间切换会永久删除本设备上的所有交易记录和报告数据。存在未完成付款时，应用会再次警告：Adyen 上的任何操作都不会被取消，但本地恢复和安全重试数据将丢失。商品和设置保留。

使用识别号并保存卡片

商家交易识别号
如需记录预订或订单号，请开启设置 › 支付 › 要求输入商家交易识别号。此号码用于在 Adyen 中识别付款。留空时会生成唯一识别号。
购物者识别号
在设置 › 支付中选择购物者识别号：结账时输入的客户识别号（默认）、顾客邮箱或无。它会随每笔付款发送给 Adyen。邮箱识别号默认经过哈希处理；所有设备请使用相同的盐值。
保存卡片
设置购物者识别号后，开启提供保存卡片选项，并选择适合您 Adyen 配置的循环扣款模式。勾选保存卡片以供今后支付前须取得顾客同意。Mini mPOS 无法使用已保存的卡片扣款。

通过链接收款

前提条件

  • LIVE 使用前，商家账户已满足 Adyen Pay by Link 要求，包括条款和条件
  1. 在销售结账时点按创建支付链接。
  2. 展示二维码，或点按通过邮件发送链接、打印链接，在平板或手机上还可点按分享链接。
  3. 保持链接界面打开以查看到账，或稍后在交易记录中点按查询支付状态。
  4. 不再需要链接时，点按取消链接。

链接被支付、过期或取消前，记录显示待支付。在设置 › 支付 › 支付链接中设置链接有效时长。链接仅用于销售，不用于订金或收据小费。

重要

有效期内任何持有真实链接的人均可付款。已支付的链接请在商户后台 › Payments › Payment list中退款，应用无法为其退款。

链接未显示或不更新时，请参阅支付链接问题。

冻结并收取订金

前提条件

  • Adyen 支持团队已为您的付款方式开通预授权；参见 Adyen 预授权指南

预授权在卡上冻结金额，不立即扣款。无需将整个账户改为手动扣款：Mini mPOS 仅对此类付款请求手动扣款。

  1. 在首页点按新建预授权。选择预授权商品、扫描其条形码或输入金额。每笔预授权包含一个商品。
  2. 结账时点按预授权。收据会显示冻结金额。
  3. 准备好后，在交易记录中打开该记录并选择操作：
扣款
收取应付金额。较少金额会释放剩余部分；较多金额会先请求发卡行增加冻结金额。请求扣款后即可退款。
调整金额
更改冻结金额，不扣款。提交相同金额会续期授权。
取消预授权
释放冻结金额。如果已在商户后台扣款，Adyen 会改为全额退款。

已请求扣款不是最终确认，请检查商户后台。如需立即获得金额调整结果，请按 Adyen 授权调整指南启用 Return adjust authorisation data。

警告

冻结金额会到期。请每天检查预授权筛选，并及时扣款或取消。操作失败或结果未知时，请参阅扣款问题。

收取顾客在收据上填写的小费

前提条件

  • 配有打印机的终端
  • Adyen 支持团队已开通预授权和超额扣款（overcapture）；参见 Adyen 收据小费指南

在设置 › 支付 › 小费中选择启用（默认关闭）或启用（默认开启），决定结账开关的初始状态。默认的禁用会隐藏该开关。部分借记卡和钱包不支持此流程。

  1. 在销售结账时开启在收据上填写小费，点按支付。账单金额只冻结，不扣款。
  2. 打印收据。收据有空白的小费和合计栏，商家联有签名栏。
  3. 顾客填写后，在结果界面或交易记录的待填写小费筛选中点按输入小费。
  4. 输入小费或合计，或点按无小费，然后确认。

应用会扣款账单加小费的总额。超过 20% 的小费需要发卡行先增加冻结金额；若被拒绝，请输入较少的小费或不加小费。小费保存后不能更改。录入小费前应取消付款而不是退款；录入后的退款包括小费。

警告

请及时录入每笔小费（包括零小费），以便在冻结到期前完成扣款。扣款失败或结果未知时，请参阅扣款问题。

设置更多设备并管理数据

  1. 在已配置的设备上打开设置 › 数据 › 共享至另一台设备。选择商品目录、设置和／或密码与密钥，然后点按显示二维码。
  2. 在新设备上选择从另一台设备设置，按任意顺序扫描所有二维码。选择合并或替换其商品目录。
  3. 如需复制密码和密钥，请输入第一台设备显示的传输码。点按导入。
  4. 检查价格和税费，在设置 › 终端中测试连接，并打印测试收据。

新设备保留自己的支付目标、终端、环境和 Tap to Pay 注册。只有 Adyen 为另一台终端分配了相同密钥时，共享密钥才可用于该终端。

重要

这是一次性复制，不是同步，也不是交易记录备份。各设备保留各自的付款。在 Android 中清除应用数据会删除设备上的全部商品、设置和交易记录。

在设置 › 数据中设置交易保留时长或点按清除已完成的交易记录；未解决的付款始终保留。请从最新发布版本安装更新，方式与原安装相同。

导入问题请参阅 PIN 和传输问题。
