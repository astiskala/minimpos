准备商品、定价和员工权限

先按快速入门连接付款，再在添加商品目录前检查以下内容。

币种和税费

在设置 › 支付中选择 Adyen 账户接受的币种；自动选择跟随设备所在地区。在设置 › 税中检查税率、价格含税或结账加税的方式，以及新商品和自定义商品的默认税率。每个商品都有税率，不征税的商品使用 0%。关闭收取税费会停止征税，但保留税率。

更改币种或税费定价方式需确认。更改币种会保留价格的数值，并按新币种精度舍入，不会按汇率换算。请检查预览和更改后的商品价格。

添加商品

打开商品，点击 +，输入名称、价格和税率。按需添加分类或条形码，条形码可输入或扫描。分类标签页用于对销售界面分组。将订金标为预授权商品，与普通销售分开。

控制员工权限

在设置 › 安全中设置管理员 PIN，保护设置和商品管理，并选择自动重新锁定时间。可另设经理 PIN，用于批准退款、取消、扣款、金额调整和小费录入。请先设置管理员 PIN；移除它也会移除经理 PIN。多次输错会暂时锁定 PIN 输入。

PIN 问题请参阅权限故障排查。

销售收款

  1. 在首页点击新建销售，选择商品、扫描条形码或添加自定义商品。
  2. 点击收款，核对商品、税费和合计，填写业务已启用的识别号或邮箱字段。
  3. 点击支付并遵循终端或 Payments 应用提示。等待结果后再开始其他付款。
  4. 在结果界面发送收据，或使用自动打印或邮件发送。

新安装的应用只要求付款；识别号、保存卡片和小费均可选。顾客要在自己的手机上付款时，可使用支付链接。

结果未知不表示付款失败。再次收款前，请查询原付款。

为付款退款

  1. 点击首页的退款并扫描收据的退款二维码，或从交易记录打开原销售。
  2. 选择全额、指定金额或按商品退款。按商品退款要求本设备保留原销售；其他设备的收据支持全额或指定金额退款。
  3. 确认退款，已配置经理 PIN 时取得批准。

退款必须关联原付款，不支持无原付款的退款。已扣款的付款可退款；未扣款的订金应取消预授权。已支付的支付链接必须在商户后台退款。

已请求退款表示 Adyen 已收到请求，不表示顾客已收到款项。请在商户后台确认最终结果；Mini mPOS 没有接收 webhook 的服务器。

退款结果未知时，重试前请查询原退款。

查询付款和每日合计

交易记录按日显示付款和退款。使用筛选项查看销售、待填写小费、预授权、退款或需处理，也可用付款方式菜单筛选卡品牌或钱包。

可按商家或 PSP 识别号、授权码、购物者识别号或邮箱、卡号后四位、品牌、钱包或确切金额搜索。小屏幕先点击搜索图标。每个词都需匹配：visa 34 可查找显示币种下金额为 34 的 Visa 付款。原销售的购物者和卡片信息也能匹配退款。

每日合计仅包含当前显示的记录，受搜索和筛选影响。未支付链接不计入合计；未扣款订金为冻结金额，不是销售收入。交易记录仅覆盖本设备保留的记录，不是整个 Adyen 账户。

打印、发送电子收据或分享

从结果或交易记录使用打印收据或发送电子收据。平板和手机还可分享收据，通过 Android 分享面板发送图片。打印需要已连接、配有实体打印机的终端；Tap to Pay 没有打印机。

自定义和测试

在设置 › 收据中填写商家信息、抬头、页脚、识别号和退款二维码，选择自动打印及商家联打印时机。预览可辅助排版，仍请用打印测试收据检查实体打印效果。

显示税额与按税率显示应税金额可分别开关。要标记特定税率的商品，设置标记的税率（%）、商品标记及说明；税率留空则不标记。这些选项适用于所有语言和币种。

语言和收据文字

应用支持英语、简体中文和日语。Android 12 及更早版本跟随设备语言；Android 13 及更高版本使用系统的单应用语言设置。Adyen 的付款收据行跟随终端的收据语言，并按原样保留。请测试打印布局，特别是中日文文字。

设置电子邮件

打开设置 › 电子邮件，选择服务商或填写 SMTP 服务器、发件人和凭据。使用 STARTTLS 或 SSL，并发送测试邮件。在设置 › 支付 › 电子收据中选择询问邮箱的时机以及是否自动发送。

服务商按钮只填写服务器信息，不会授权账户。SMTP 访问和所需密码请遵循服务商说明：

  • Gmail
  • Microsoft 365
  • iCloud Mail
  • Yahoo Mail
  • Fastmail
  • Zoho Mail
  • Proton Mail

应用使用基于密码的 SMTP，不支持 OAuth。即使服务器信息正确，服务商或组织政策也可能阻止连接。

发送问题请参阅收据和邮件故障排查。

识别号和保存卡片

员工需记录预订或订单号时，在设置 › 支付启用交易识别号。另行选择购物者识别号：无、结账输入的客户识别号或顾客邮箱。无论是否保存卡片，每笔付款都会向 Adyen 发送该购物者识别号。邮箱默认经过哈希处理；跨设备使用相同盐值以保持识别号一致。

配置购物者识别号后，提供保存卡片选项可在结账时提供保存卡片。取得顾客同意，并选择符合 Adyen 集成的循环扣款模式。保存卡片不会在 Mini mPOS 中提供使用已保存卡片扣款的界面。

让顾客通过链接付款

Adyen Pay by Link让顾客在 Adyen 支付页面付款，而不使用终端。LIVE 使用前请检查账户的 Pay by Link 要求，包括条款和条件。

  1. 开启设置 › 支付 › 提供支付链接并选择有效期。
  2. 销售结账时点击创建支付链接。展示二维码、通过邮件发送链接并附上未支付收据、打印链接，或在平板和手机上分享链接。
  3. 保持链接界面打开以自动查询，或以后从交易记录点击查询支付状态。不再需要时使用取消链接。

链接被支付、过期或取消前，交易记录显示待支付。已支付链接计入合计，未支付链接不计入。链接包含商品及已填写的购物者信息、保存卡片选择，适用 Adyen 账户的线上风险和扣款设置。

链接仅用于销售，不用于订金或收据小费，需要真实 Checkout API，不支持模拟。有效期内任何持有链接的人均可付款。请在商户后台 › Payments › Payment list为已支付链接退款；应用无法获取其 PSP 识别号。

链接未显示或不更新时，请参阅支付链接故障排查。

冻结并收取订金

预授权在卡上冻结金额，不立即扣款。请 Adyen 支持团队为付款方式开通；能否使用取决于卡片和业务。参见 Adyen 的预授权指南。无需将整个账户改为手动扣款：Mini mPOS 仅对此类付款请求手动扣款。

  1. 在首页点击新建预授权，选择预授权商品、扫描条形码或输入自定义金额。每笔预授权包含一个商品。
  2. 结账时点击预授权，收据显示冻结金额。
  3. 准备收取或释放金额时，从交易记录打开该记录。
扣款
收取应付金额。较少金额会释放剩余部分；较多金额会先请求发卡行增加授权。请求扣款后即可提供退款操作。
调整金额
更改冻结金额，不扣款。提交相同金额会请求续期授权。
取消预授权
释放冻结金额。如果已在商户后台扣款，Adyen 会改为全额退款。

扣款和调整使用 Checkout API。已请求扣款不是最终确认，请检查商户后台。要立即获取授权调整结果，请按 Adyen 的调整指南启用 Return adjust authorisation data；否则确认是异步的。

冻结金额会到期。请检查预授权筛选，及时扣款或取消。失败或未知操作请遵循恢复说明。

收取顾客在收据上填写的小费

此流程需要实体打印机和 Adyen 的收据小费配置。请 Adyen 支持团队为付款方式启用预授权和超额扣款（overcapture）。部分借记卡和钱包不支持。

  1. 销售结账时开启在收据上填写小费并支付。账单金额只冻结，不扣款。
  2. 打印带空白小费及合计栏的收据，商家联包含签名栏。
  3. 顾客填写后，从结果或交易记录的待填写小费筛选选择输入小费。输入小费或合计，或选择无小费并确认。

应用请求扣款账单加小费的总额。不超过 20% 的小费使用超额扣款，较大的小费先增加授权。若发卡行拒绝增加授权，小费不会保存，可填写较少金额或无小费。保存后不能更改小费。录入前应取消冻结付款，而不是退款；录入后的退款包括小费。

及时录入小费，包括零小费，以便在冻结到期前扣款。扣款请求仍需在商户后台确认最终结果。

扣款失败或结果未知时，请参阅扣款和调整恢复说明。

设置更多设备并管理本地数据

  1. 在已配置设备打开设置 › 数据 › 共享至另一台设备或商品菜单，选择商品目录、设置和／或密码与密钥，点击显示二维码。
  2. 接收设备选择从另一台设备设置，按任意顺序扫描所有二维码，选择合并或替换商品目录。
  3. 要导入秘密信息，请输入发送设备的传输码。留空会跳过秘密信息，错误的传输码不会导入任何内容。点击导入。
  4. 检查价格和税费，在设置 › 终端测试连接，并测试收据。

设置会替换接收设备的共享设置，但支付目标、终端地址和 ID、Tap to Pay 安装、检测环境和模拟器仍保留本地值。秘密信息包括 API 密钥、共享密钥口令、SMTP 密码及两种 PIN。共享密钥只有在 Adyen 为另一终端分配相同密钥时才可用；设备专用凭据可能需要替换。

检查导入的币种警告：商品价格不会按汇率换算。设置助手有所不同，仅导入填写的连接字段，不更改无关设置。

这是复制，不是同步，也不是交易记录备份。未来更改和各设备的付款仍留在本地。在“设置 › 数据”选择交易保留时长，并按需清除已完成记录。常规清理保护未解决付款。清除 Android 应用数据会删除全部本地商品、设置和交易记录。

保持使用最新版本。更新时使用原安装方式和签名来源，参见安装。

导入问题请参阅PIN 和传输故障排查。
