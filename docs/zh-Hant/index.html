免費開源 · 直接運行在 Adyen Android 支付終端上

完整收銀流程，就在支付終端上。

Mini mPOS 直接運行在 Adyen Android 支付終端上，一台設備即可選購商品、收款、列印或發送電子收據，並通過掃描收據完成退款。無需單獨的收銀機、平板或應用程式訂閱。更喜歡用平板電腦或手機？Mini mPOS 同樣可以在上面運行，配合您的終端或 Tap to Pay 收款。

內置於 Adyen 支付終端

安裝在終端上後，Mini mPOS 無需其他硬件，也無需運行後端。在平板電腦或手機上，它可配合您的終端或 Tap to Pay 使用。

  • 卡資料留在 Adyen。Mini mPOS 僅接收遮蔽卡資訊和支付參考編號。
  • 您的業務，就在您的設備上。在設備上管理商品、設定和交易紀錄，無需雲端帳戶。
  • 櫃台內外都適用。適配 AMS1 等小型終端、內置打印機的機型，以及平板電腦和手機。

常見問題

哪種設定適合我？

直接在 Adyen Android 終端完成整個收銀流程，或用 Android 平板、手機搭配網絡終端、雲端終端或 Tap to Pay。參閱要求和設定選擇。列印需要打印機，掃描需要相機。

費用是多少？

應用程式免費，採用 MIT 授權條款開源。Adyen 的支付處理費用仍適用。

這是 Adyen 的產品嗎？

不是。Mini mPOS 並非 Adyen 製作、認可或支援的產品。正式上線前請在 Adyen TEST 環境測試。應用程式和 Adyen 問題參見取得幫助。

設備共享後台嗎？

不共享。商品、設定和交易紀錄儲存在各設備上。二維碼傳輸複製商品和設定，不複製交易紀錄或持續同步更改。參見設備和資料。

需要伺服器或 API 密鑰嗎？

無需伺服器，但所有真實付款設定都需要 Checkout API 憑據。其他密鑰取決於支付目標。密鑰加密儲存在設備上，這與 Adyen 的伺服器端建議存在取捨。請按連接設定及其中的安全建議操作。
