準備網絡

請店舖的網絡管理員放行以下連接：

互聯網
允許設備和終端通過 TCP 443 向 *.adyen.com 和 *.adyenpayments.com 發起 HTTPS 出站連接。請 按域名放行，而不是按 IP 地址，因為 Adyen 的 IP 地址會變化。
區域網絡（適用於網絡終端）
平板或手機必須能通過 TCP 8443 存取終端的 IP 地址。請將兩者連接到同一網絡，並確保 Wi-Fi 用戶端隔離（訪客網絡常見）不會隔開它們。

請在路由器中為每台網絡終端設定 DHCP 保留，固定其 IP 地址。雲端和 Tap to Pay 設定中的平板或手機可使用移動資料，但搭配網絡終端時不行。終端本身的網絡要求請參閱 Adyen 網絡設定指南。

安裝應用程式

  1. 在裝置上打開直接下載連結，或用相機掃描此二維碼：
  2. 在設備上打開 APK，按 Android 提示允許瀏覽器或檔案管理器安裝應用程式。
  3. 打開 Mini mPOS，選擇連接 Adyen，點按繼續。

重要

每次更新都要使用同一簽名來源。終端會拒絕以不同密鑰簽名的更新。自行構建和簽名請參閱 貢獻者指南。

綁定同一網絡中的終端

設定助手（建議）
打開設定助手，選擇終端的 TEST 或 LIVE 環境，保持自動，輸入 API 密鑰，然後掃描二維碼。找到多台終端時，請選擇您的終端。
手動
  1. 在設定 › 終端中，將支付目標設為同一網絡中的終端。在環境 中選擇與終端一致的 TEST 或 LIVE。
  2. 在 Adyen API 中輸入 Adyen API 密鑰和商戶帳戶，LIVE 還需輸入 LIVE URL 前置字元。點按尋找終端設定 以測試 API 存取並選擇終端。手動補充缺失的資料。
  3. 檢查或輸入終端的 IP 地址和終端 ID（POIID）。兩者都顯示在終端的“Device info”畫面。
  4. 檢查或輸入共享密鑰，點按測試連接。
