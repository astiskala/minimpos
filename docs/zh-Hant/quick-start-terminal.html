安裝應用程式

從最新發佈版本下載已簽名的 minimpos-<version>.apk。

  1. 在商戶後台打開 Devices › Terminal apps，上傳 APK，並等待狀態變為 Ready；參見Adyen 上傳指南。用戶需要 Merchant POS Terminal Management Admin 角色。
  2. 選擇應用程式，然後選擇 Install。選擇版本和 Schedule now，選擇您的終端並確認 Schedule installation。參見Adyen 排程安裝指南。
  3. 保持終端開機並連線。它會在下一次維護呼叫時安裝應用程式，預設三小時內。若想盡快取得，請嘗試在終端上打開 Settings › Configuration，輸入密碼並選擇 Update。
  4. 在終端上打開 Mini mPOS，選擇掃描設定二維碼，點按繼續。

重要

每次更新都要使用同一簽名來源。終端會拒絕以不同密鑰簽名的更新。自行構建和簽名請參閱 貢獻者指南。

設定助手（建議）
打開設定助手，選擇終端的 TEST 或 LIVE 環境，保持自動，輸入 API 密鑰，然後掃描二維碼。
手動
  1. 在設定 › 終端 › Adyen API中輸入 Adyen API 密鑰和商戶帳戶，LIVE 還需輸入 LIVE URL 前置字元。點按尋找終端設定 以測試 API 存取並自動補充共享密鑰。
  2. 檢查或輸入共享密鑰，點按測試連接。
