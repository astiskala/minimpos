設定助手

在電腦上設定設備

在終端鍵盤上輸入冗長的 API 密鑰既費時又容易出錯。請在這裡對照商戶後台填寫，再以二維碼形式掃描到 Mini mPOS 中。

初次使用 Mini mPOS？填寫前請先選擇設定方式並準備憑據。

商戶後台連結會在新分頁中打開，方便保留此表單。

設定助手需要 JavaScript。請為此頁面啟用 JavaScript，或按照快速入門指南在應用程式中輸入。

Mini mPOS 在哪裡運行，支付發往哪裡？
使用哪個 Adyen 環境？

對於網絡或雲端終端，此選項會作為應用程式環境匯入。在 Adyen 終端上運行或使用 Tap to Pay 時，環境由本設備或已安裝的 Payments 應用程式決定。

如何設定？

請先遵循Tap to Pay 準備步驟並安裝 Payments 應用程式。輸入商戶帳戶和獨立的 Payments 應用程式 API 密鑰進行註冊。請在此輸入共享密鑰；Mini mPOS 不會查詢共享密鑰。匯入完成前，手機會要求明確執行註冊操作。無需複製註冊代碼。

Adyen API 密鑰

在 Developers › API credentials 中建立憑據並生成 API 密鑰。雲端付款需新增 Cloud Device API role。此密鑰用於 Checkout 操作，而非 Payments 應用程式註冊。此主憑據需要特定角色；參見憑據要求。

商戶帳戶
同一網絡中的終端

兩者都可在終端的 Device info（設備資訊）畫面查看。

雲端終端

可在終端的 Device info 畫面或商戶後台的 Devices › Terminals 中查看。

共享密鑰

在商戶後台的 Devices › Device settings › Terminal API 中的 Encryption key 下（點按鉛筆圖示查看）。

LIVE URL 前置字元

見 Developers › API URLs。

Tap to Pay

用於手機註冊的獨立 API 憑據，僅具有 Adyen Payments app role；參見 Adyen Payments 應用程式指南。

如只為一家店舖設定本手機：填寫 Devices › Stores 中該店舖的 ID（不是其 reference）。

收據資訊（可選）

關閉時，不匯入收據文字或 Adyen 商戶資訊。

收據資訊

每項商戶資訊均可選擇從 Adyen 匯入或手動輸入。

只有已填寫的手動文字會更改已儲存值，留空會保留原文字。稅務編號、標題和頁尾需手動輸入，不從 Adyen 匯入。參見收據設定。

電子收據（可選）

請先檢查郵件設定及服務商要求；設定助手無法測試伺服器。

SMTP 伺服器

只更改已填寫欄位。可選項留空會保留已儲存值；如需清除，請在“設定 › 電子郵件”中操作。密碼與其他秘密資訊一同加密。

用設備掃描這些二維碼

傳輸碼

  1. 在 Mini mPOS 中打開設定 › 終端，點按快速設定下的掃描設定二維碼，或右上角的二維碼掃描圖示。無需先選擇支付目標或環境。
  2. 用相機掃描二維碼。有多個二維碼時會自動輪換。
  3. 檢查支付目標和環境，尤其是 LIVE。輸入必需的傳輸碼，再點按驗證並匯入。
  4. 按照驗證後匯入的步驟操作。

如包含 SMTP 設定，請檢查設定 › 電子郵件併發送測試郵件。

匯入後請完成第一筆 TEST 付款。

匯入問題？ · 連接問題？

須知

  • 資料不會離開此頁面。二維碼在您的瀏覽器中生成；頁面不會發送或儲存任何內容。完成後請關閉頁面。
  • 密鑰經過加密。二維碼中的密碼和密鑰使用傳輸碼加密，傳輸碼只在這裡顯示，因此僅拍攝二維碼不會洩露它們。
  • 請保密傳輸碼。同時持有二維碼和傳輸碼的人可解密密鑰。按需生成新傳輸，完成後關閉頁面。
  • 需要完整說明？參閱快速入門；匯入或連接問題參見疑難排解。
