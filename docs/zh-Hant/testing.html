驗證 TEST 設定

  1. 在設定 › 終端中，確認環境為 TEST。完成最後的測試連接步驟，驗證 API 存取和受支援的連接檢查。
    • 實體終端：運行測試連接並確認通過。
    • Tap to Pay：確認手機已在 Adyen Payments Test 中註冊。連接檢查只驗證設定，不支援終端診斷。使用下方測試付款檢查付款行為。
  2. 在設定 › 支付中檢查貨幣，在設定 › 稅中檢查稅率和價格是否含稅。
  3. 在首頁點按新建銷售，新增自訂商品，然後點按收款。 將自訂商品命名為「測試銷售」，輸入測試卡情境要求的金額。
  4. 點按支付，按照 Adyen POS 測試指南完成一筆成功付款。
  5. 確認結果為批准，且收據上的金額、貨幣和稅額正確。在交易紀錄中打開銷售紀錄，用其 PSP 參考編號核對 TEST 商戶後台中的付款。
  6. 為該付款退款，並在 TEST 商戶後台確認最終退款結果。已請求退款並非最終確認。
  7. 按照 Adyen POS 測試指南的拒付場景再次測試銷售。確認 Mini mPOS 顯示付款被拒絕；參見付款被拒絕。

警告

如果結果未知，請勿再次付款。請先按恢復步驟處理。

為 LIVE 收款做好準備

  • 設定商品價格前，確認幣別和稅率。
  • 核對商戶資料，並測試計劃使用的每種收據提供方式。
  • 設定員工 PIN，並確認需要經理批准的操作。
  • 只啟用並測試計劃使用的選用付款功能。

正式上線

警告

在 TEST、LIVE 和模擬器之間切換會刪除設備上的全部交易紀錄，包括未完成付款的恢複資料。請先處理需處理中的所有付款。

  1. 改用 LIVE 終端或 LIVE 版 Payments 應用程式及 LIVE 憑據。網絡或雲端終端及 Tap to Pay 請在環境中選擇 LIVE。輸入 LIVE URL 前置字元；參見 Adyen LIVE 端點指南。Tap to Pay 需要在所選環境中重新註冊。
  2. 在設定 › 終端中，確認環境為 LIVE。完成最後的測試連接步驟，驗證 API 存取和受支援的連接檢查。
    • 實體終端：運行測試連接並確認通過。
    • Tap to Pay：確認手機已在 LIVE 版 Adyen Payments 應用程式中註冊。連接檢查只驗證設定，不支援終端診斷。

日常檢查和對帳請參閱日終結算。

驗證首筆 LIVE 付款

請使用實際付款目標和收據提供方式，按照 Adyen 的 LIVE 測試指南驗證。在 LIVE Customer Area 中核對金額、幣別、收據和付款。僅通過連線檢查並不能證明付款功能正常。
