付款或退款顯示“結果未知”

警告

不要僅因應用程式沒有回應就再次收款或退款。請求可能已到達 Adyen。

  1. 打開交易紀錄，篩選需處理，打開原付款或退款。
  2. 點按重新查詢結果。對於終端，應用程式會向終端查詢該交易的結果。
  3. 如果結果仍未知，請按參考編號、時間和金額在商戶後台 › Payments › Payment list中查找該付款。確認後再決定下一步。

崩潰或重啟後，中斷的操作會以未知狀態保留在交易紀錄中。不要通過清除應用程式資料來移除它。

使用 Tap to Pay 時，重新查詢結果先使用已收到的延遲回覆，再向所選 Payments 應用程式查詢原始結果。狀態查詢需要 1.8.0 或以上版本；請向 Adyen 確認測試版使用權限。未收到回調或傳回 NotFound 時，結果仍未知。再次收款前，請檢查商戶後台 › 「Payments」 › 「Payment list」。

付款被拒絕或未處理

結果畫面會顯示狀態、Adyen 給出的原因和建議。請按建議操作：

“請勿使用此卡重試。請顧客使用其他卡或付款方式。”

解決請顧客改用其他卡或付款方式。顧客的銀行可以說明拒絕原因； Adyen 拒絕原因解釋了顯示的原因。

原因

發卡行因不會改變的原因拒絕了此卡（如卡被凍結、受限或疑似欺詐），或此卡不允許用於本次付款。

“可以重試。”

解決點按重試，或請顧客換一張卡。

原因

付款被取消、PIN 輸入錯誤，或卡因可能不會重復的原因被拒絕（如餘額不足）。

“終端正在處理其他交易或顯示管理選單。”

解決完成另一筆付款或退出選單後重試。如果畫面提供取消終端目前交易，僅在確實要停止該交易時使用，並在重試前查詢其結果。

原因

終端正在處理另一筆付款或顯示管理選單。

“終端暫時不可用。”

解決稍候，確認終端已開機並已連接，然後重試。參見網絡中斷。

原因

終端或其讀卡器暫時不可用。

“終端未接受請求。重試前，請檢查終端設定。”

解決在設定 › 終端中運行測試；參見終端綁定和設定。如果測試通過，請聯繫 Adyen 檢查終端設定。

原因

終端拒絕了所發送的請求，通常是設定問題。

“終端或您的 Adyen 帳戶不支援此請求。請聯絡 Adyen 支援團隊確認已開通，然後重試。”

解決請聯絡 Adyen 支援團隊確認商戶帳戶已開通該功能。如使用 Tap to Pay，請確認除 Adyen Payments App role 外，亦已開通 Tap to Pay on Android。然後重試。

原因

終端或 Adyen 不提供此付款所需的功能，通常是因為帳戶尚未開通。

“請勿再次收款：此次支付已成功。”

解決請勿再次收款。如果顧客不應付款，請為其退款。

原因

雖然終端報告了取消，但付款已獲批准。

可選終端功能不可用或總額存在差異

終端功能未顯示或被拒絕

檢查收款目標和 Adyen 功能，重新整理終端設定，並確認 API 角色和 Adyen 帳戶設定。本地結帳開關不會在 Adyen 開通服務。Tap to Pay 不提供實體終端流程。小費請比較終端小費和 收據小費。

只有部分金額獲批

從結果頁面按部分付款流程操作。不要再次收取原合計金額。若後續付款結果未知，請先 查詢結果再繼續收款。

終端總額與 Mini mPOS 不符

按終端對帳 說明檢查終端週期、使用同一終端的其他設備、本地保留紀錄和未解決交易。結束週期不會修復差異，也不代表結算完成。

離線銷售缺少 PSP 參考編號或仍有未確認批次

按離線付款檢查步驟操作。恢復終端與 Adyen 的連接，並在商戶後台核對上傳的付款。不要僅因缺少 PSP 參考編號就再次收取已批准的付款。

返回目錄

沒有掃描錢包按鈕或掃描失敗

沒有掃描錢包按鈕

打開設定 › 終端，點按重新整理掃碼錢包。成功查詢後沒有符合條件的 POS 錢包時，按鈕會保持隱藏。核對終端店舖、目前貨幣和API 密鑰角色。Tap to Pay 和預授權不提供此功能。

錢包查詢報錯

錯誤僅顯示在設定中，不會阻止普通支付。請檢查憑據、環境和只讀存取權限。設定未變時，臨時重新整理錯誤會保留最近驗證的錢包列表；成功查詢到空列表或存取失敗會移除它。只在啟動、設定改變或手動重新整理時查詢，不會在每筆銷售前查詢。

付款碼無效或未收到付款碼

請使用顧客的付款碼，而非個人資料、設定轉移或收據二維碼，並選擇正確的錢包。終端掃描最多持續 30 秒，之後點按重新掃描 或使用相機。相機提示時請授予權限。應用程式從後台返回後需重新開始掃描。

儲存被拒絕或未建立代碼

請以支付結果為準。沒有儲存代碼的已批准付款仍然有效。僅在明確被拒絕後，如需重試，返回結帳，關閉儲存卡 並明確開始新掃描。應用程式不會自動重新付款。結果未知時應查詢原交易。

請參閱錢包支付步驟。交易紀錄中的請求錢包僅表示支付意圖，不證明付款成功或 Adyen 使用了該方式。

返回目錄

終端綁定或設定失敗

先查看首頁的提示，再開啟設定 › 終端，完成最後的測試連接步驟，驗證 API 存取和此整合支援的連接檢查。網絡和雲端設定使用 尋找要設定的終端測試 API 存取並列出終端；裝置本機終端和 Tap to Pay 提供測試 API。完整步驟請參閱 連接 Adyen。

所有整合都可開啟設定 › 說明與疑難排解 › 疑難排解詳情。結果包括設定缺失項、API 存取、受支援的連接檢查、時間和裝置資料，並標明不支援的檢查。這些檢查不保證付款、退款或列印成功，也不會發起付款、註冊手機或更改密鑰。使用分享已隱去敏感資料的報告 分享顯示的詳情：保留商戶、終端、安裝實例和憑據 ID；排除秘密值、非結構化訊息和顧客資料。

首頁提示“尚未完成收款設定”

解決點按完成收款設定。在設定 › 終端中填寫缺少的資訊或重新輸入密鑰，然後點按測試連接。

原因

必填欄位為空、本設備無法讀取已儲存的密鑰，或設定更改後尚未通過連線測試。在此之前，支付、退款、列印和其他 Adyen 操作會顯示此說明，而不會執行。

API 測試失敗，或設定提示存取問題

解決按照憑據要求檢查憑據的角色和存取範圍。LIVE 請檢查 LIVE URL 前置字元。

原因

API 密鑰、商戶帳戶或 LIVE URL 前置字元有誤，缺少角色，或憑據屬於其他 Company 帳戶或環境。

“商戶帳戶與終端目前分配的帳戶不一致。”

解決輸入終端所分配的商戶帳戶，或在商戶後台重新分配終端。

原因

終端在 Adyen 中被分配到其他商戶帳戶。

Adyen 終端或網絡終端的連接測試失敗

解決將共享密鑰的識別碼、口令和版本與商戶後台核對。網絡終端還需在終端的“Device info”畫面核對 IP 地址和 POIID。

原因

共享密鑰不一致，或 IP 地址、終端 ID（POIID）已過時。

連接因環境不一致被拒絕

解決網絡或雲端終端及 Tap to Pay 請在設定 › 終端中檢查環境。在 Adyen 終端上運行時，請使用正確環境的設備。

原因

混用了 TEST 和 LIVE：終端、帳戶和 API 密鑰必須屬於同一環境。

無法連接雲端終端

解決確認終端已開機並已連線，再檢查 POIID 和憑據的角色。

原因

終端離線、POIID 有誤，或 API 密鑰缺少 Cloud Device API role。

未安裝所選環境的 Payments 應用程式

解決檢查設定 › 終端 › 環境，從 Google Play 安裝對應應用程式。兩者可以同時安裝。完成註冊，輸入對應的共享密鑰，再完成一筆 TEST 付款。

原因

未安裝所選 TEST 或 LIVE 環境的 Payments 應用程式。

Tap to Pay 在出示卡片前傳回 UnavailableService

Payments 應用程式無法完成請求。此通用錯誤不能證明 Adyen 服務中斷或缺少客戶端密鑰。

在設定 › 終端中執行測試連接。如需查看簡潔的檢查結果表格或分享已隱去敏感資料的報告，請展開設定 › 說明與疑難排解 › 疑難排解詳情。

設定 Tap to Pay會使用主 API 密鑰自動建立註冊憑據和客戶端密鑰。如遭拒絕，請檢查 所需角色。新密鑰需要數分鐘生效，然後再次測試連接。如仍無法恢復，請稍後重試或請 Adyen 支援團隊檢查對應的 TEST Customer Area 或 LIVE Customer Area。參見 Adyen Payments 應用程式要求 。

客戶端密鑰必須屬於註冊所用的同一憑據。

分享已隱去敏感資料的報告只分享顯示的各行：應用程式版本、API 存取和連接檢查結果及其 UTC 時間、整合方式和環境、帳戶/店舖/安裝實例/共享密鑰 ID、Android/裝置/Payments 應用程式版本；使用 Tap to Pay 時亦包括客戶端密鑰和註冊檢查結果及已驗證憑據身份。

“新密鑰已儲存。請更新此終端的設定”

解決在終端上打開 Admin menu › Config › Update，然後返回 Mini mPOS 點按再次檢查。如果建立中斷，請點按繼續密鑰設定，不會建立第二個密鑰。參見密鑰建立及 Adyen 設定更新指南。

原因

加密密鑰已在 Adyen 建立，但終端尚未載入。

舊付款的操作被阻止

解決恢復處理該付款時的設定，或在商戶後台處理。不要用另一個帳戶處理它。

原因

該付款之後更換了商戶帳戶、環境或終端。

返回目錄

連接中斷或終端未回應

重要

如果連接中斷時有付款正在進行，再次收款前請查詢其結果。

“終端未回應”，或網絡終端時好時壞

解決

  1. 在終端的“Device info”畫面查看 IP 地址，並在設定 › 終端中更新。
  2. 將設備和終端連接到同一網絡。避免使用訪客 Wi-Fi，它通常會隔離設備。
  3. 請網絡管理員放行兩者之間的 TCP 8443，並為終端保留 IP 地址；參見網絡要求。
原因

終端的 IP 地址已變化、設備換到了其他網絡，或網絡阻止了連接。

所有設定的付款或 API 測試都失敗

解決檢查互聯網連接，並確認已放行到 Adyen 域名的 TCP 443 HTTPS 連接。

原因

設備或終端無法存取互聯網，或防火牆阻止了 Adyen。

雲端付款逾時

解決檢查終端的 Wi-Fi、以太網或移動資料，然後運行測試連接。

原因

終端失去了互聯網連接。

返回目錄

扣款或調整失敗或結果未知

在交易紀錄中打開原紀錄並查看原因。如果缺少 Checkout API 設定，請補全；如果帳戶或環境已更改，請恢復原設定。

扣款失敗或扣款結果未知

解決點按重試扣款。它會安全地重新發送同一扣款請求；不要建立新的付款。

金額調整未解決

解決使用相同金額重試。不同金額是獨立請求，可能需先解決第一個請求。

小費未儲存

解決輸入較少的小費，或點按無小費。

原因

小費超過 20% 時，發卡行拒絕增加凍結金額。

已請求扣款或已請求退款一直不變

解決請在商戶後台確認最終結果。

原因

這表示 Adyen 已接受請求。Mini mPOS 沒有伺服器，無法收到最終確認。

凍結金額會到期，請及時處理。正常步驟請參閱訂金和收據小費。

返回目錄

付款連結未顯示或不更新

結帳時沒有建立付款連結

解決在設定 › 終端中完成 Checkout API 設定。連結僅用於銷售。離線演示請參閱 付款連結。

原因

Checkout API 設定未完成，或本次結帳是預授權或收據小費。

已支付的連結仍顯示待支付

解決在交易紀錄中打開該紀錄，點按查詢支付狀態。

原因

應用程式僅在連結畫面打開時查詢。

建立連結時中斷

解決打開原紀錄並點按查詢支付狀態，會使用原請求重試；不要僅為取得連結建立另一筆銷售。

已支付的連結請在商戶後台 › Payments › Payment list中退款。

返回目錄

打印機或電子收據無法使用

無法列印，或沒有列印收據

解決

  1. 在設定 › 關於中確認打印機顯示可用。否則請在設定 › 終端中運行測試連接。
  2. 在設定 › 收據中將打印機設為自動檢測，並檢查自動列印。
  3. 點按列印測試收據。如果仍無法列印，請檢查終端的收據紙捲。
原因

終端沒有打印機、未檢測到打印機，或連接中斷。AMS1 終端和 Tap to Pay 手機沒有打印機。

排版被截斷或換行異常

解決在設定 › 收據中更改每行字元寬度，然後列印測試收據。

測試郵件發送失敗

解決在設定 › 電郵收據中檢查伺服器、連接埠、STARTTLS 或 SSL/TLS、用戶名稱和密碼。服務商可能要求開通 SMTP 或使用應用程式密碼；參見郵件設定。

原因

伺服器、連接埠、安全方式或密碼有誤，或服務商禁止 SMTP 或密碼登入。

測試郵件正常，但顧客收不到收據

解決在設定 › 電郵收據中檢查何時詢問電郵以及是否自動發送收據。

返回目錄

PIN 和設定傳輸問題

員工忘記了經理 PIN

解決管理員可在設定 › 安全中更換或移除。管理員 PIN 和經理 PIN 保護不同的操作，其中一個不會解鎖另一個。

忘記了管理員 PIN

原因沒有 PIN 恢復功能。

如需在沒有管理員 PIN 的情況下重新開始，請按照儲存空間復原步驟操作。重設前請閱讀資料遺失警告。

傳輸碼被拒絕，或匯入後缺少密鑰

解決使用與這些二維碼一起顯示的傳輸碼，而不是新生成的碼。每次傳輸都需要傳輸碼。錯誤的碼或留空都不會匯入任何內容。複製後，請檢查新設備的支付目標和憑據；參見 更多設備。

原因

傳輸碼與這些二維碼不相符，或未填寫。

各 PIN 保護的操作請參閱員工 PIN。

無法讀取或儲存已儲存的設定或憑證

Mini mPOS 會停止運作，而不會取代無法讀取的設定或憑證，以保留檔案，包括未完成設定或付款的復原紀錄。

警告

清除儲存空間或解除安裝會刪除全部本機商品、設定、憑證、PIN、交易紀錄及未完成操作的復原紀錄。設定傳輸無法還原交易紀錄或這些復原紀錄。重設不會撤銷已發送至 Adyen 的付款、退款或請款。

  1. 重新啟動裝置並再次開啟 Mini mPOS。如裝置儲存空間已滿，請先清理 Mini mPOS 以外的空間。只清除應用程式快取不會重設已儲存的設定。
  2. 重設前，請保留所需紀錄，並處理未完成的付款、退款、請款和調整。如無法開啟應用程式，請在 Customer Area 確認結果；參見結果未知 。如結果仍不確定，請保留應用程式資料，並先與 Adyen 核對。不要因為無法開啟應用程式就再次發送操作。
  3. 如問題持續，而您接受遺失全部本機資料，可重設 Mini mPOS。在手機或平板電腦上，開啟 Android 設定 › 應用程式 › Mini mPOS › 儲存空間和快取 › 清除儲存空間 （名稱因裝置而異），或解除安裝 Mini mPOS 並從最新版本 重新安裝。在 Adyen 終端上，請由終端應用程式管理員安排重設或移除後重新安裝；參見 Adyen 應用程式部署指南。
  4. 重新設定 Mini mPOS，或匯入可信的設定傳輸，然後完成測試連接，再進行真實付款。參見連接 Adyen 。

覆蓋安裝更新不會重設應用程式儲存空間。如錯誤再次出現，請在 GitHub 報告應用程式問題，不要附上已儲存的設定檔或憑證。

出現錯誤訊息

每條訊息都會說明問題及需要檢查的內容。括號中的詳細資料（如 IP 地址、HTTP 狀態或 Adyen 的原文）有助 Adyen 支援團隊排查，尋求協助時請一併提供。如果有付款正在進行，請先 查詢其結果，再處理其他問題。

錯誤訊息
“無法連接終端。請確認終端已開機、位於同一網絡，且 IP 地址正確。”

解決請參閱連接中斷。

原因

Mini mPOS 無法連接到所儲存 IP 地址上的網絡終端。

“此地址不是所選環境中的 Adyen 終端。請檢查 IP 地址以及 TEST 或 LIVE。”

解決在終端的“Device info”畫面上核對 IP 地址，並檢查設定 › 終端中的環境。

原因

該地址有設備回應，但不是所選環境中的 Adyen 終端：該地址已分配給其他設備，或混用了 TEST 和 LIVE。

“終端拒絕了共享密鑰。請在終端設定中檢查密鑰識別碼、版本及密碼短語。”

解決與商戶後台中的設定進行核對，或重新設定密鑰。

原因

共享密鑰的識別碼、版本或密碼短語與終端上的不一致。

“無法驗證終端的回覆。請在終端設定中檢查共享密鑰。”

解決再次收款前請先查詢結果，然後修正共享密鑰。

原因

終端使用了不同的共享密鑰回覆，因此請求可能已送達終端。

“終端未連接到 Adyen。請確認終端已開機並已連線。”

解決檢查終端的 Wi-Fi、以太網或流動數據，然後執行測試連接。

原因

雲端終端已關機或沒有互聯網連接。

“Adyen 未接受 API 密鑰。請在終端設定中檢查。”

解決重新輸入密鑰，並對照憑證要求檢查。

原因

API 密鑰有誤、已被撤銷，或屬於另一個環境。

“此 API 密鑰缺少所需角色或對此商戶帳戶的存取權限。請在商戶後台檢查 API 憑證。”

解決在商戶後台中新增該角色或帳戶存取權限；請參閱憑證要求。

原因

憑證缺少某個角色或對此商戶帳戶的存取權限。已知缺少的角色時，括號中會註明。

“Adyen 繁忙或暫時無法使用。”

解決稍候片刻再重試。如果是付款、扣款或付款連結，請先查詢其結果。

原因

Adyen 正在限制請求，或暫時無法使用。

“未能在限定時間內收到回應。”

解決請查詢結果。在確認結果前，請勿再次收款。

原因

請求已發出，但未收到回應，因此結果未知。

“Payments 應用程式的結果仍未知。請更新所選 Payments 應用程式，向 Adyen 確認狀態查詢權限，並在再次收款前檢查商戶後台。”

解決再次收款前，請在商戶後台中查找此次付款。

原因

Tap to Pay 結果恢復.

“無法開啟 Adyen Payments 應用程式。請確認已安裝該應用程式。”

解決安裝與您的環境對應的 Payments 應用程式，然後重試。請參閱連接 Adyen。

原因

Payments 應用程式未安裝或已被移除。

“郵件伺服器未接受用戶名稱或密碼。請在“設定 › 電郵收據”中檢查。”

解決更正後傳送一封測試郵件。

原因

SMTP 用戶名稱或密碼有誤，或郵件服務供應商要求使用應用程式專用密碼。

“此設備的安全儲存空間無法使用。請重試或重啟設備。”

解決如果重新啟動後問題仍然存在，請重新輸入密鑰及密碼。

原因

Android 金鑰庫無法加密或讀取已儲存的密鑰資料。
