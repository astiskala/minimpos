準備商品、稅費和員工權限

真實收款前，請完成連接 Adyen 的設定。需要支付終端或 Adyen Payments 應用程式。然後一次性準備商品、稅費和員工權限。

設定貨幣和稅費

  1. 在設定 › 支付中選擇商戶帳戶接受實體店付款的貨幣。
  2. 在設定 › 稅中檢查稅率、價格含稅還是結帳時加稅，以及新商品的預設稅率。

每個商品都有稅率，不徵稅的商品使用 0% 稅率。關閉收取稅費會停止徵稅，但保留稅率。

重要

更改貨幣會保留價格中的數值，不會按匯率換算。更改後請檢查商品價格。

新增商品

  1. 打開商品，點按 +。
  2. 輸入名稱、價格和稅率。可選新增分類和條碼（輸入或掃描）。
  3. 訂金商品請開啟預授權商品，使其只出現在預授權中。

設定員工 PIN

  1. 在設定 › 安全中點按設定管理員 PIN。它保護設定和商品管理。選擇應用程式多久後重新鎖定。
  2. 可選：點按設定經理 PIN。之後退款、取消、扣款、金額調整和錄入小費都需要輸入它。

如需更換或移除管理員 PIN，請使用更改管理員 PIN或移除管理員 PIN；移除它也會移除經理 PIN。多次輸錯會暫時鎖定 PIN 輸入。忘記 PIN 時請參閱 PIN 問題。

銀行卡收款

  1. 在首頁點按新建銷售。點按商品、點按掃描條碼，或新增自訂商品。
  2. 點按收款。核對商品、稅費和總計，並填寫參考編號或郵箱欄位。
  3. 點按支付。終端（或 Tap to Pay 的 Adyen Payments 應用程式）會提示顧客付款。
  4. 等待結果。結果顯示前請勿開始另一筆付款。
  5. 通過列印收據、發送電子收據或分享收據向顧客提供收據（已自動發送時除外）。

說明

銀行卡由終端讀取，Mini mPOS 不會獲得完整卡號資訊。根據終端和商戶帳戶的不同，顧客可插卡、揮卡，或用手機、手錶感應付款。非接觸式（NFC）付款時，卡或手機須保持靠近非接觸標誌，直到終端確認。使用 Tap to Pay 時，請按 Adyen Payments 應用程式中的說明操作。

警告

結果未知不表示付款失敗。再次收款前，請查詢原付款。

顧客參考編號、儲存卡和小費均可選；參見參考編號和儲存卡。如需讓顧客在自己的手機上付款，請使用支付連結。付款被拒絕時，請參閱付款被拒絕。

掃描顧客的錢包付款碼

在銷售結帳時使用掃描錢包讀取顧客錢包應用程式中的付款碼。這與掃描商品條碼或退款收據不同。此功能需要實體支付終端，不適用於 Tap to Pay；錢包查詢需要只讀權限。

  1. 核對總計和結帳欄位後點按掃描錢包。若已選擇收據小費，請確認不使用該選項：錢包會立即收取總計，而不是進行預授權。
  2. 選擇顧客的錢包。只有一個可用錢包時會自動選擇。僅顯示單獨設定的錢包；Alipay+ 不代表 GCash、DANA、Kakao Pay 或 TrueMoney 已分別啟用。
  3. 終端確認配備內置掃描器時，按下該終端的掃描按鈕。它可能是網絡或雲端終端，而非運行 Mini mPOS 的設備。要改用設備相機，請點按使用相機。
  4. 掃描顧客的付款二維碼或付款條碼。一個有效掃描會立即開始支付。等待普通支付結果並提供收據。

取消會保留購物車和結帳欄位。無效碼不會付款：請重新掃描或更換錢包。終端掃描最多持續 30 秒；之後可點按重新掃描或使用相機。離開應用程式會停止掃描，返回後需明確重新開始。不能手動輸入或貼上付款碼。

顧客參考編號和授權允許時，儲存卡會嘗試儲存支付資訊，是否支援取決於錢包。只有返回儲存的支付代碼才表示成功儲存；沒有代碼的已批准付款仍然有效。請參閱錢包查詢和支付問題；不要通過再次掃碼替代結果未知的原付款。

請使用 Adyen 錢包指南和 Adyen PayPal 和 Venmo 指南核對錢包開通情況和 TEST 行為。

錢包掃描的英文模擬器演示。

退款或撤銷付款

退款
適用於已扣款的付款，退還全部或部分金額。
撤銷（取消）
適用於尚未扣款的凍結付款：訂金點按取消預授權，待填寫小費的銷售點按取消支付。這會釋放凍結金額。

退款步驟：

  1. 在首頁點按退款並掃描收據上的退款二維碼，或在交易紀錄中打開原銷售。
  2. 選擇全額、指定金額或按商品退款。按商品退款要求本設備保留原銷售。
  3. 確認退款，如有提示則輸入經理 PIN。

每筆退款都關聯原付款，不支援無原付款的退款。已支付的支付連結請在商戶後台退款。

重要

已請求退款表示 Adyen 已收到請求，不表示顧客已收到款項。請在商戶後台確認最終結果。退款結果未知時，重試前請先查詢。

列印、發送電子收據或分享收據

在付款結果或交易紀錄中點按列印收據或發送電子收據。平板和手機還可點按分享收據，通過 Android 分享選單發送圖片。列印需要配有打印機的終端。

自訂並測試收據

  1. 在設定 › 收據中填寫商戶資訊、抬頭和頁尾。也可點按從 Adyen 匯入商戶資訊，從 Adyen 店舖補充空白欄位。
  2. 選擇支付後自動列印、何時列印商戶副本，以及是否顯示退款二維碼。
  3. 點按列印測試收據並檢查列印效果。螢幕預覽無法顯示打印機的確切排版。

其他選項：

顯示稅額
顯示總額中包含或另行加收的稅額，不改變實際收取的稅額。
顯示稅額明細
按稅率列出稅額。價格含稅時，顯示所含稅額需要開啟此項。
按稅率顯示應稅金額
按稅率彙總商品金額，包括 0%。
顯示參考編號
預設開啟。列印商戶參考編號及已輸入的顧客參考編號，便於將收據與付款對應。
標記的稅率（%）
用商品標記及其說明標出該稅率的商品。留空則不標記。
每行字元寬度
預設為 32，適用於較窄的收據紙捲。請通過測試列印選擇適合打印機的寬度。

設定語言

應用程式支援英語、簡體中文、繁體中文和日語。在設定 › 語言中選擇此裝置的應用程式語言。應用程式文字和應用程式產生的收據標籤會立即更改；已儲存的商戶文字、商品名稱、貨幣和稅設定保持不變。跟隨裝置在 Android 12 及更早版本使用裝置語言，在 Android 13 及更高版本使用 Android 的個別應用程式語言選擇。Adyen 的銀行卡收據行跟隨終端自身的收據語言。

設定電子收據

  1. 打開設定 › 電子郵件（SMTP）。選擇服務商，或填寫 SMTP 伺服器、連接埠、寄件人和登入資訊。使用 STARTTLS 或 SSL/TLS。
  2. 發送測試郵件。
  3. 在設定 › 支付 › 電子收據中選擇何時詢問顧客郵箱，以及是否自動發送收據。

請按服務商說明開通 SMTP 並取得正確的密碼：

  • Gmail
  • Microsoft 365
  • iCloud Mail
  • Yahoo Mail
  • Fastmail
  • Zoho Mail
  • Proton Mail

收據無法列印或發送時，請參閱打印機和郵件問題。

查詢付款並完成每日對帳

交易紀錄按日列出付款和退款，並顯示每日總計。

  • 按銷售、待填寫小費、預授權、退款或需處理篩選，並用付款方式篩選卡品牌或錢包。
  • 可按參考編號、授權碼、顧客參考編號或郵箱、卡號後四位、品牌、錢包或確切金額搜尋。每個詞都需相符：visa 34 可查找金額為 34 的 Visa 付款。

螢幕上的總計受搜尋和篩選影響。凍結的付款（如訂金和收據小費）在扣款被受理當日計入銷售。

每日對帳

  1. 打開交易紀錄，篩選需處理並逐一處理；參見結果未知。
  2. 檢查待填寫小費和預授權篩選。錄入小費，並在凍結到期前為訂金扣款或取消。
  3. 點按日期旁的列印圖示，列印本地每日摘要。
  4. 與商戶後台中的 Adyen 報告對帳；參見 Adyen 結算對帳指南。

摘要忽略篩選，涵蓋整日的銷售、已含小費、已受理退款、淨額、新增凍結和未解決操作，按貨幣分列。TEST 和模擬器活動會標明。已支付的支付連結和日期未知的扣款會作為無日期活動單獨列出。

重要

本地每日摘要只包含本設備儲存的付款，不是 Adyen 的最終結算，也不包含其他設備。以商戶後台為準。

警告

在 LIVE、TEST 和模擬器之間切換會永久刪除本設備上的所有交易紀錄和報告資料。存在未完成付款時，應用程式會再次警告：Adyen 上的任何操作都不會被取消，但本地恢復和安全重試資料將遺失。商品和設定保留。

使用參考編號並儲存卡

商戶交易參考編號
如需紀錄預訂或訂單號，請開啟設定 › 支付 › 要求輸入商戶交易參考編號。此號碼用於在 Adyen 中識別付款。留空時會生成唯一參考編號。
購物者參考編號
在設定 › 支付中選擇購物者參考編號：結帳時輸入的顧客參考編號（預設）、顧客郵箱或無。它會隨每筆付款發送給 Adyen。郵箱參考編號預設經過雜湊處理；所有設備請使用相同的鹽值。
儲存卡
設定購物者參考編號後，開啟提供儲存卡選項，並選擇適合您 Adyen 設定的循環扣款模式。勾選儲存卡以供今後支付前須取得顧客同意。Mini mPOS 無法使用已儲存的卡扣款。

通過連結收款

前提條件

  • LIVE 使用前，商戶帳戶已滿足 Adyen Pay by Link 要求，包括條款和條件
  1. 在銷售結帳時點按建立支付連結。
  2. 展示二維碼，或點按通過郵件發送連結、列印連結，在平板或手機上還可點按分享連結。
  3. 保持連結畫面打開以查看付款結果，或稍後在交易紀錄中點按查詢支付狀態。
  4. 不再需要連結時，點按取消連結。

連結被支付、過期或取消前，紀錄顯示待支付。在設定 › 支付 › 支付連結中設定連結有效時長。連結僅用於銷售，不用於訂金或收據小費。

重要

有效期內任何持有真實連結的人均可付款。已支付的連結請在商戶後台 › Payments › Payment list中退款，應用程式無法為其退款。

連結未顯示或不更新時，請參閱支付連結問題。

凍結並收取訂金

前提條件

  • Adyen 支援團隊已為您的付款方式開通預授權；參見 Adyen 預授權指南

預授權在卡上凍結金額，不立即扣款。無需將整個帳戶改為手動扣款：Mini mPOS 僅對此類付款請求手動扣款。

  1. 在首頁點按新建預授權。選擇預授權商品、掃描其條碼或輸入金額。每筆預授權包含一個商品。
  2. 結帳時點按預授權。收據會顯示凍結金額。
  3. 準備好後，在交易紀錄中打開該紀錄並選擇操作：
扣款
收取應付金額。較少金額會釋放剩餘部分；較多金額會先請求發卡行增加凍結金額。請求扣款後即可退款。
調整金額
更改凍結金額，不扣款。提交相同金額會續期授權。
取消預授權
釋放凍結金額。如果已在商戶後台扣款，Adyen 會改為全額退款。

已請求扣款不是最終確認，請檢查商戶後台。如需立即獲得金額調整結果，請按 Adyen 授權調整指南啟用 Return adjust authorisation data。

警告

凍結金額會到期。請每天檢查預授權篩選，並及時扣款或取消。操作失敗或結果未知時，請參閱扣款問題。

收取顧客在收據上填寫的小費

前提條件

  • 配有打印機的終端
  • Adyen 支援團隊已開通預授權和超額扣款（overcapture）；參見 Adyen 收據小費指南

在設定 › 支付 › 小費中選擇啟用（預設關閉）或啟用（預設開啟），決定結帳開關的初始狀態。預設的停用會隱藏該開關。部分借記卡和錢包不支援此流程。

  1. 在銷售結帳時開啟在收據上填寫小費，點按支付。帳單金額只凍結，不扣款。
  2. 列印收據。收據有空白的小費和總計欄，商戶副本有簽名欄。
  3. 顧客填寫後，在結果畫面或交易紀錄的待填寫小費篩選中點按輸入小費。
  4. 輸入小費或總計，或點按無小費，然後確認。

應用程式會扣款帳單加小費的總額。超過 20% 的小費需要發卡行先增加凍結金額；若被拒絕，請輸入較少的小費或不加小費。小費儲存後不能更改。錄入小費前應取消付款而不是退款；錄入後的退款包括小費。

警告

請及時錄入每筆小費（包括零小費），以便在凍結到期前完成扣款。扣款失敗或結果未知時，請參閱扣款問題。

設定更多設備並管理資料

  1. 在已設定的設備上打開設定 › 資料 › 共享至另一台設備。選擇商品目錄、設定和／或密碼與密鑰，然後點按顯示二維碼。
  2. 在新設備上選擇從另一台設備設定，按任意順序掃描所有二維碼。選擇合併或替換其商品目錄。
  3. 如需複製密碼和密鑰，請輸入第一台設備顯示的傳輸碼。點按匯入。
  4. 檢查價格和稅費，在設定 › 終端中測試連接，並列印測試收據。

新設備保留自己的支付目標、終端、環境和 Tap to Pay 註冊。只有 Adyen 為另一台終端分配了相同密鑰時，共享密鑰才可用於該終端。

重要

這是一次性複製，不是同步，也不是交易紀錄備份。各設備保留各自的付款。在 Android 中清除應用程式資料會刪除設備上的全部商品、設定和交易紀錄。

在設定 › 資料中設定交易保留時長或點按清除已完成的交易紀錄；未解決的付款始終保留。請從最新發佈版本安裝更新，方式與原安裝相同。

匯入問題請參閱 PIN 和傳輸問題。
